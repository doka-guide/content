## Кратко

[Глобальное свойство](/a11y/aria-attrs/#globalnye-atributy) из [WAI-ARIA](/a11y/aria-intro/#specifikaciya). Атрибут задаёт описание роли элемента специально для [дисплеев Брайля](https://ru.wikipedia.org/wiki/%D0%91%D1%80%D0%B0%D0%B9%D0%BB%D0%B5%D0%B2%D1%81%D0%BA%D0%B8%D0%B9_%D0%B4%D0%B8%D1%81%D0%BF%D0%BB%D0%B5%D0%B9).

На этот атрибут похож [`aria-roledescription`](/a11y/aria-roledescription/). Главная разница в том, что `aria-roledescription` описывает роль для всех вспомогательных технологий, а `aria-brailleroledescription` — только для дисплеев Брайля. Обычно это сокращённая версия `aria-roledescription`, которая лучше помещается в строку дисплея.

## Пример

[Скринридер](/a11y/screenreaders/) скажет «слайд», а дисплей Брайля покажет короткое «слд»:

```html
<section
  aria-roledescription="слайд"
  aria-brailleroledescription="слд"
  aria-label="Итоги года"
>
  …
</section>
```

Здесь нужен [`aria-label`](/a11y/aria-label/). Без [доступного имени](/a11y/accessible-names-and-descs/) у [`<section>`](/html/section/) роль `generic`, а не [`region`](/a11y/role-region/), и атрибуты не сработают.

## Как пишется

Добавьте `aria-brailleroledescription` к элементу, у которого уже есть `aria-roledescription`. Без `aria-roledescription` спецификация запрещает использовать атрибут. Не все браузеры в таком случае его игнорируют, поэтому следите за этим сами.

Значение — обычный текст на языке страницы. Готовые [знаки Брайля из Юникода](https://en.wikipedia.org/wiki/Braille_Patterns), например `⠎⠇⠙`, спецификация использовать не советует. Обычный текст скринридер переводит в шрифт Брайля по правилам, которые пользователь выбрал в настройках, например в полный шрифт или в сокращённый, где один знак заменяет частое слово или сочетание букв. А готовые знаки он выводит как есть.

Не оставляйте значение пустым и не повторяйте в нём `aria-roledescription` или название роли: тогда атрибут ничего не добавляет.

Атрибут не работает на элементах с [ролью `generic`](/a11y/role-generic/), которая по умолчанию есть у [`<div>`](/html/div/) и [`<span>`](/html/span/). Сначала задайте элементу подходящую роль.

## Как понять

Описание роли вспомогательная технология сообщает пользователю вместе с доступным именем элемента, например из `aria-label`. Скринридер произносит его вслух и выводит на дисплей Брайля. С `aria-brailleroledescription` дисплей Брайля показывает другое описание, а голосом звучит прежнее.

Используйте атрибут редко: только когда `aria-roledescription` неудобно читать на дисплее Брайля. Сокращение должно быть понятным для пользователя. Если оно непривычное, расскажите о нём, например в справке сайта.

Браузеры поддерживают атрибут: Chrome, Edge, Firefox и Safari передают его вспомогательным технологиям. Firefox на macOS делает это с версии 150.

Скринридеры выводят атрибут на дисплей Брайля по-разному. NVDA поддерживает его с версии 2023.2. VoiceOver на macOS показывает его в Safari, Chromium-браузерах и Firefox.

Проверьте атрибут на тех скринридерах, на которые рассчитан сайт.

Атрибут появился в [черновике ARIA 1.3](https://w3c.github.io/aria/).
