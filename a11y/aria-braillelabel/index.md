## Кратко

[Глобальное свойство](/a11y/aria-attrs/#globalnye-atributy) из [WAI-ARIA](/a11y/aria-intro/#specifikaciya). Атрибут задаёт отдельное имя элемента для [дисплея Брайля](https://ru.wikipedia.org/wiki/%D0%91%D1%80%D0%B0%D0%B9%D0%BB%D0%B5%D0%B2%D1%81%D0%BA%D0%B8%D0%B9_%D0%B4%D0%B8%D1%81%D0%BF%D0%BB%D0%B5%D0%B9). [Скринридер](/a11y/screenreaders/) по-прежнему читает вслух обычное [доступное имя](/a11y/accessible-names-and-descs/).

На этот атрибут похож [`aria-label`](/a11y/aria-label/). Но `aria-label` задаёт имя сразу и для голоса, и для дисплея Брайля.

## Пример

Скринридер прочитает «Рейтинг товара: 4 звезды из 5», а на дисплей Брайля попадёт короткое «Рейтинг 4/5». Короткая запись занимает меньше символов на строке дисплея, и её быстрее прочитать пальцами:

```html
<div
  role="img"
  aria-label="Рейтинг товара: 4 звезды из 5"
  aria-braillelabel="Рейтинг 4/5"
>
  ★★★★☆
</div>
```

## Как понять

_Доступное имя_ или просто _имя элемента_ — это краткое название элемента, которое вспомогательная технология сообщает пользователю. Скринридер произносит его вслух и выводит на дисплей Брайля.

Атрибут появился в [черновике ARIA 1.3](https://w3c.github.io/aria/). Chrome, Edge, Firefox и Safari передают его вспомогательным технологиям. А скринридеры выводят его на дисплей Брайля по-разному:

- VoiceOver на macOS показывает его в Safari и в Firefox с версии 151;
- по сторонним тестам, атрибут работает с VoiceOver в Chrome и с JAWS в Edge и Firefox;
- NVDA атрибут пока не поддерживает.

Если используете атрибут, проверьте его на тех скринридерах, на которые рассчитан сайт.

## Как пишется

Используйте `aria-braillelabel` только тогда, когда доступное имя неудобно читать на дисплее Брайля. Например, оно слишком длинное для строки дисплея, а у элемента есть понятное короткое обозначение.

Добавляйте `aria-braillelabel` только к элементу, у которого уже есть доступное имя. Автоматические проверки доступности, например библиотека [axe](https://github.com/dequelabs/axe-core), считают атрибут без имени ошибкой.

Атрибут нельзя задавать элементам с некоторыми ролями, например [`generic`](/a11y/role-generic/), [`paragraph`](/a11y/role-paragraph/), [`code`](/a11y/role-code/) и [`tooltip`](/a11y/role-tooltip/).

Роль `generic` по умолчанию есть у [`<div>`](/html/div/) и [`<span>`](/html/span/). Поэтому в примере у `<div>` стоит [роль `img`](/a11y/role-img-image/).

Значение — обычный текст на языке страницы. Скринридер сам переведёт его по правилам Брайля, которые пользователь выбрал в настройках.

Спецификация не советует писать в значении [готовые символы Брайля из Юникода](https://en.wikipedia.org/wiki/Braille_Patterns), например ⠗. Если в значении есть хоть один такой символ, скринридер выведет всё значение как есть, без перевода. Поэтому не смешивайте в одном значении символы Брайля и обычный текст.

Не оставляйте значение пустым и не повторяйте в нём доступное имя: тогда атрибут ничего не добавляет.

Расскажите пользователям, что сайт задаёт отдельные имена для дисплея Брайля, например в справке. Иначе пользователь запутается: на дисплее один текст, а голосом и на экране другой.
