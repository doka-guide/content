## Кратко

[Глобальное свойство](/a11y/aria-attrs/) из [WAI-ARIA](/a11y/aria-intro/) для описания горячих клавиш, с помощью которых можно выполнить команду или перевести фокус на элемент.

<aside>

🚧 Атрибут поддерживают все современные браузеры, Firefox — с версии 140. Но сообщают о нём не все [скринридеры](/a11y/screenreaders/), поэтому дублируйте сочетание клавиш в видимом тексте.

</aside>

## Пример

```html
<button aria-keyshortcuts="Alt+Shift+F">
  Развернуть
</button>
```

<iframe title="Сочетание клавиш для кнопки" src="demos/button-with-shortcut/" height="260"></iframe>

NVDA при фокусе на кнопке озвучит её примерно так: «Развернуть, кнопка. Alt плюс Shift плюс F». Другие скринридеры могут прочитать сочетание иначе или промолчать.

На macOS вместо <kbd>Alt</kbd> нажимают <kbd>Option</kbd>. В значении атрибута эта клавиша всё равно называется `Alt`.

## Как пишется

Добавьте к тегу атрибут `aria-keyshortcuts` с нужным сочетанием клавиш в виде строки текста. `aria-keyshortcuts` можно использовать для всех ролей.

Лучше добавлять сочетания клавиш для элементов, с которыми взаимодействуют пользователи. Например, для кнопок паузы, воспроизведения или включения субтитров в плеере, якорных ссылок и похожих элементов.

Названия клавиш из одного сочетания разделяйте знаком `+`.

```html
<button aria-keyshortcuts="Alt+Shift+D">
  Загрузить документ
</button>
```

В сочетании на первом месте должны стоять [клавиши-модификаторы](https://www.w3.org/TR/uievents-key/#keys-modifier). Например, <kbd>Alt</kbd>, <kbd>Shift</kbd> или <kbd>Control</kbd>. Их нельзя использовать без обычной клавиши: буквы, цифры, знака или, например, <kbd>Enter</kbd>, <kbd>Escape</kbd>, <kbd>F1</kbd>.

```html
<!-- ⛔ Неправильные сочетания клавиш -->
<button aria-keyshortcuts="S+Alt+Shift">
  Покричать в лесу
</button>
<button aria-keyshortcuts="Alt">
  Покричать в лесу
</button>

<!-- ✅ Правильные сочетания клавиш -->
<button aria-keyshortcuts="Alt+Shift+S">
  Покричать в лесу
</button>
<button aria-keyshortcuts="Shift+Alt+S">
  Покричать в лесу
</button>
```

Буквы в сочетаниях могут быть маленькими и большими.

```html
<!-- ✅ Оба варианта правильные -->
<button aria-keyshortcuts="Alt+Shift+s">
  Покричать в лесу
</button>
<button aria-keyshortcuts="Alt+Shift+E">
  Покричать про себя
</button>
```

Когда указываете несколько сочетаний клавиш, разделяйте их пробелами.

```html
<button aria-keyshortcuts="Alt+Shift+S Alt+Shift+D">
  Скачать файл
</button>
```

Записывайте клавиши, которые человек нажимает физически. Например, на американской раскладке знак <kbd>%</kbd> набирают через <kbd>Shift</kbd> и <kbd>5</kbd>, поэтому в атрибуте пишут `Alt+Shift+5`, а не `Alt+%`:

```html
<a href="#main" aria-keyshortcuts="Alt+Shift+5">
  К основному содержимому
</a>
```

На многих раскладках цифрам и знакам нужны модификаторы. Например, во французской раскладке цифру вводят с зажатым <kbd>Shift</kbd>. Поэтому надёжнее использовать буквы латинского алфавита.

Пробел записывают как `Space`. Список стандартных значений клавиш найдёте в [спецификации UI Events KeyboardEvent](https://www.w3.org/TR/uievents-key/).

Не забывайте слушать нажатия на клавиши с помощью [`addEventListener()`](/js/element-addeventlistener/). Благодаря `aria-keyshortcuts` пользователи скринридеров узнают, что с элементом можно взаимодействовать как-то ещё. Атрибут не добавляет нужную функциональность.

Несколько важных правил при работе с `aria-keyshortcuts`:

- Не перезаписывайте сочетания клавиш, которые уже есть в браузерах, вспомогательных технологиях и операционных системах. Например, <kbd>Control</kbd> + <kbd>C</kbd> копирует выделенный текст.
- Отключайте сочетание вместе с элементом. Если элемент отключён атрибутом [`disabled`](/html/disabled/) или [`aria-disabled`](/a11y/aria-disabled/), сочетание тоже должно перестать работать.
- Лучше рассказывать о сочетаниях клавиш всем людям, не только пользователям вспомогательных технологий. К примеру, в тексте на странице или во [всплывающей подсказке](/recipes/tooltip/).
- Не используйте много сочетаний клавиш: это только усложнит взаимодействие с элементами на странице.

Подробнее про выбор сочетаний клавиш узнаете из [Developing a Keyboard Interface](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/).

## Как понять

Сочетание клавиш, горячие клавиши или шорткат — это способ выполнить команду, зажав одну или несколько клавиш на клавиатуре.

Горячие клавиши ускоряют работу пользователей клавиатуры и даже тех, кто в основном пользуется мышкой и другими указателями.

`aria-keyshortcuts` пригодится, когда нужно рассказать пользователям вспомогательных технологий, что с элементом можно взаимодействовать определённым сочетанием клавиш. К примеру, видео часто разворачивается на весь экран при нажатии на <kbd>F</kbd>.

Осторожнее с сочетаниями из одной буквы или из <kbd>Shift</kbd> и буквы. Скринридеры используют такие клавиши для навигации. А у пользователей голосового ввода буквы из продиктованных слов могут случайно запустить сочетание.

По критерию 2.1.4 «[Горячие клавиши из одного символа](https://www.w3.org/WAI/WCAG22/Understanding/character-key-shortcuts.html)» из [WCAG](/a11y/wcag/) (Руководства по доступности веб-контента) нужен один из вариантов:

- пользователь может отключить сочетание;
- пользователь может переназначить его на сочетание с <kbd>Control</kbd> или <kbd>Alt</kbd>;
- сочетание работает только при фокусе на элементе.

## Подсказки

💡 `aria-keyshortcuts` похож на HTML-атрибут `accesskey`, но работает по-другому. `accesskey` сам назначает элементу клавишу, но модификаторы для неё выбирает браузер, и они отличаются в разных браузерах и системах. `aria-keyshortcuts` ничего не назначает: он только сообщает о сочетании, которое вы обработали в JavaScript.

💡 Не назначайте одну и ту же букву в `accesskey` и в сочетании <kbd>Alt</kbd> + <kbd>Shift</kbd> из `aria-keyshortcuts`. В Firefox на Windows и Linux `accesskey` срабатывает как раз по <kbd>Alt</kbd> + <kbd>Shift</kbd>, и сочетания совпадут.

💡 Если символ клавиши совпадает с кавычкой, в которую взято значение атрибута, замените его на HTML-сущность. Например, апостроф в значении с одинарными кавычками записывают как `&#39;`.
