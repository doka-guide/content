# Проверка орфографии

Обе проверки запускаются на каждый пулреквест и смотрят только изменённые файлы.

## Орфография

Незнакомые слова показываются с подсказками:

```
Незнакомые слова:
  css/grid/index.md:196:45  расчитывает  похоже на: рассчитывает, раскатывает

Всего: 1. Почините опечатки, а термины добавьте в .yaspeller.json.
```

Запустить у себя:

```bash
node .github/scripts/check-spelling.mjs css/grid/index.md
```

### Словарь

Термины, сленг и имена собственные живут в _.yaspeller.json_. Запись — это слово целиком, вариативное окончание в скобках через прямую черту:

```json
"dictionary": [
  "контрибьютор(а|ов)",
  "ховер(у|)"
]
```

Второй записью в словарь попали и «ховер», и «ховеру»: одиночный разделитель означает нулевое окончание. Регистр не важен — «адаптив» покрывает и «Адаптив».

👆 Прежде чем добавить слово, проверьте, что оно действительно так пишется — например, на портале «[Грамота](http://gramota.ru/)». Если это переводной термин и его нет в [словаре терминов по фронтенду](https://github.com/web-standards-ru/dictionary/blob/main/dictionary.md), посмотрите по выдаче поисковика, распространён ли выбранный вариант.

⛔️ Не добавляйте все окончания сразу — только те, что есть в вашей статье.

## Буква «ё»

Запускается на каждый пулреквест, смотрит изменённые файлы. Находки делятся надвое:

- **бесспорные** — проверка падает, пока их не поправят;
- **спорные** — показываются списком, но проверку не валят.

<!-- eyo-disable-next-line -->
Спорные — это слова, которые существуют в обоих написаниях: «берет» — головной убор, «берёт» — форма глагола. Что имелось в виду, видно только из текста, поэтому решает автор.

### Как запустить у себя

```bash
node .github/scripts/check-yo.mjs css/grid/index.md                       # проверить статью
node .github/scripts/check-yo.mjs $(git diff --name-only main -- '*.md')  # всё изменённое
node .github/scripts/check-yo.mjs --fix css/grid/index.md                 # починить
```

`--fix` правит только бесспорное.

### Что не проверяется

Блоки и вставки кода — иначе правится и текст внутри них, вплоть до символьных классов регулярок.

### Как запретить замену в конкретном месте

```markdown
<!-- eyo-disable-next-line -->
Здесь остается как есть — это цитата.

<!-- eyo-disable -->
Целый кусок под защитой.
<!-- eyo-enable -->
```

### Словарь исключений

В _.yo-ignore_ — слова, которые в наших текстах не бывают с «ё»: «маркеры» списка, «разметка» страницы. Если проверка раз за разом предлагает одну и ту же ненужную замену, допишите слово туда, по слову на строку.

⛔️ Не добавляйте слова, где обе формы осмысленны — «все», «чем», «нем». Их и нужно смотреть глазами.
