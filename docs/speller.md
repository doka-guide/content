# Инструкция по проверке орфографии

Сейчас в Доке автоматически проверяется одно — **буква «ё»**. Полная проверка орфографии выключена, почему — [в конце страницы](#почему-полная-проверка-орфографии-выключена).

## Как это работает

Проверка запускается сама на каждый пулреквест, джоба называется «Буква ё». Смотрит только те файлы, которые вы меняли.

Находки делятся на две части:

<!-- eyo-disable -->

- **бесспорные** — «остается» → «остаётся», «имен» → «имён». Тут двух мнений нет, проверка падает, пока их не поправят;
- **спорные** — «берет» → «берёт», «все» → «всё», «разметку» → «размётку». Их проверка показывает отдельным списком, но **не валит**: без контекста тут не решить, и решать вам.

<!-- eyo-enable -->

<!-- eyo-disable-next-line -->
Спорные места — это подсказка «посмотрите глазами», а не требование. «Он берет шляпу» и «он берёт шляпу» — разные предложения, и машина не знает, какое из них ваше.

Кстати, эти самые примеры на странице закрыты служебными комментариями — иначе проверка ругалась бы на собственную документацию.

## Как проверить и починить у себя

Понадобится только [Node.js](https://nodejs.org/en/) — ничего устанавливать не нужно, `eyo` приезжает через `npx` сам.

Проверить одну статью:

```bash
node .github/scripts/check-yo.mjs css/grid/index.md
```

Проверить всё, что вы поменяли в ветке:

```bash
node .github/scripts/check-yo.mjs $(git diff --name-only main -- '*.md')
```

Починить найденное:

```bash
node .github/scripts/check-yo.mjs --fix css/grid/index.md
```

`--fix` правит **только бесспорные** случаи. Спорные он не трогает никогда — их вы решаете сами.

## Что проверка не трогает

Блоки кода и вставки кода в строке пропускаются всегда. Это не удобство, а необходимость: инструмент ничего не знает про Markdown и однажды уже испортил в нашем рецепте символьный класс регулярки — `[а-яА-ЯЁё]` превратилось в `[а-яА-ЯЕё]`, и проверка русских имён перестала пропускать букву Ё.

## Словарь слов, которые не бывают с «ё»

Некоторые слова в наших текстах не становятся «ё»-словами никогда: «маркеры» списка, «разметка» страницы, «перед» как предлог. Чтобы они не засоряли список спорных мест, они перечислены в файле _.yo-ignore_ в корне репозитория — по слову на строку.

Если проверка раз за разом предлагает вам одну и ту же ненужную замену, допишите слово туда.

⛔️ Не добавляйте слова, где обе формы осмысленны — «все», «чем», «нем». Их и нужно смотреть глазами, ради этого список спорных мест и существует.

## Как запретить замену в конкретном месте

Иногда «е» стоит намеренно: цитата в старой орфографии, имя собственное, разбор ошибки. Закройте такое место служебным комментарием.

Одна строка:

```markdown
<!-- eyo-disable-next-line -->
Здесь остается как есть — это цитата.
```

Кусок текста:

```markdown
<!-- eyo-disable -->
Здесь ничего не трогаем,
и здесь тоже.
<!-- eyo-enable -->
```

Комментарии не видны на сайте — это обычные комментарии Markdown.

## Почему полная проверка орфографии выключена

Раньше Дока проверяла орфографию через [yaspeller](https://www.npmjs.com/package/yaspeller) — обёртку над API Яндекс.Спеллера. Проверку выключили в декабре 2023 года, а сам yaspeller с тех пор перевели в архив: последний релиз в ноябре 2023, репозиторий доступен только для чтения.

У самого API нашлась неприятная особенность: **типографское тире обнуляет проверку предложения**.

```
"Грид — это олгоритм раскладки."   → ошибка не найдена
"Грид - это олгоритм раскладки."   → олгоритм → алгоритм
```

Длинное «—» и среднее «–» ломают проверку целиком, включая слова до тире. В текстах Доки тире есть в 12% абзацев, а в них — 28% всего текста.

Словарь исключений _.yaspeller.json_ мы **не удалили**: в нём 628 записей, собранных за годы, и он пригодится, если вернём полную проверку на другом движке.

## Как добавлять слова в словарь исключений

Пока полная проверка выключена, словарь ни на что не влияет — но если вы правите его вместе со статьёй, формат такой.

👆 Прежде чем добавить исключение, проверьте, что слово действительно так пишется — например, на портале «[Грамота](http://gramota.ru/)». Если это переводной термин и его нет в [словаре терминов по фронтенду](https://github.com/web-standards-ru/dictionary/blob/main/dictionary.md), посмотрите по выдаче поисковика, распространён ли выбранный вами вариант.

В файле _.yaspeller.json_ есть блок _dictionary_:

```json
"dictionary": [
  "ааа",
  "автодополнение",
]
```

Вариативное окончание берётся в скобки, варианты разделяются прямой чертой:

```json
"dictionary": [
  "контрибьютор(а|ов)",
]
```

Нулевое окончание указывается одиночным разделителем — так в исключения попадут и «ховер», и «ховеру»:

```json
"dictionary": [
  "ховер(у|)",
]
```

⛔️ Не добавляйте сразу все окончания, которые придут в голову, — только те, что есть в вашей статье.
