# Проверка буквы «ё»

Запускается на каждый пулреквест, смотрит изменённые файлы. Находки делятся надвое:

- **бесспорные** — проверка падает, пока их не поправят;
- **спорные** — показываются списком, но проверку не валят.

<!-- eyo-disable-next-line -->
Спорные — это слова, которые существуют в обоих написаниях: «берет» — головной убор, «берёт» — форма глагола. Что имелось в виду, видно только из текста, поэтому решает автор.

## Как запустить у себя

Нужен только [Node.js](https://nodejs.org/en/), ставить ничего не надо.

```bash
node .github/scripts/check-yo.mjs css/grid/index.md                       # проверить статью
node .github/scripts/check-yo.mjs $(git diff --name-only main -- '*.md')  # всё изменённое
node .github/scripts/check-yo.mjs --fix css/grid/index.md                 # починить
```

`--fix` правит только бесспорное.

## Что не проверяется

Блоки и вставки кода — иначе правится и текст внутри них, вплоть до символьных классов регулярок.

## Как запретить замену в конкретном месте

```markdown
<!-- eyo-disable-next-line -->
Здесь остается как есть — это цитата.

<!-- eyo-disable -->
Целый кусок под защитой.
<!-- eyo-enable -->
```

## Словарь исключений

В _.yo-ignore_ — слова, которые в наших текстах не бывают с «ё»: «маркеры» списка, «разметка» страницы. Если проверка раз за разом предлагает одну и ту же ненужную замену, допишите слово туда, по слову на строку.

⛔️ Не добавляйте слова, где обе формы осмысленны — «все», «чем», «нем». Их и нужно смотреть глазами.
