🛠 При сборке образа Docker ищет файл исключений по имени `Dockerfile`. Например, команда `docker build -f myapp.Dockerfile .` будет в первую очередь искать файл исключений по пути `myapp.Dockerfile.dockerignore`. Если такого файла нет, Docker возьмёт обычный `.dockerignore`.

🛠 Давайте образам имена. Образ без имени в выводе `docker image ls` показан как `<none>`, и обращаться к нему приходится по ID. В Docker 29 и новее такие образы по умолчанию скрыты, их показывает флаг `--all`.

К имени через двоеточие можно добавить тег. Например, соберём образ с именем и тегом:

```bash
docker build -t vieux/apache:2.0 .
```

Образы с одним именем и разными тегами образуют репозиторий образов.

Имя образа `vieux/apache` использует принятое в терминологии Docker соглашение. До слэша `/` пишут имя пользователя, после — имя образа. Обычно это имя пользователя в реестре образов. Первый и самый крупный реестр — официальный [Docker Hub](https://hub.docker.com) от компании Docker.

В примере тег `2.0` обозначает версию сборки, но теги могут указывать и на вариант образа, например на основе Alpine Linux или Ubuntu. Тег `latest` обычно указывает на последнюю версию образа. Но если такой образ уже есть на компьютере, Docker возьмёт его. Свежую версию скачает флаг `--pull`: `docker build --pull .`.

🛠 Важно отслеживать размер образа и пользоваться образами с умом. Загрузить образ можно командой `docker pull`. Например, для образа Node.js:

```bash
docker pull node
```

Уже при скачивании вы увидите размер каждого слоя образа. После скачивания также можно получить информацию об образе с помощью команды:

```bash
docker image inspect node
```

В терминале появится информация об образе в формате JSON. Размер образа в байтах — в ключе `"Size"`.

Выбирайте наименьший базовый образ, в котором есть всё нужное приложению. Часто это образ на Alpine Linux. Например, у Node.js есть `node:lts-alpine`.

Учтите, что в Alpine другая системная библиотека языка C: musl вместо привычной glibc. Пакеты npm с кодом на C или C++ могут в Alpine не заработать.
