## Кратко

Бандлер — программа, которая упаковывает сложный проект со многими файлами и внешними зависимостями в один или несколько файлов, которые получит браузер.

Два самых популярных бандлера — **[Webpack](/tools/webpack/)** и **[Vite](https://vite.dev)**. Webpack используют в сложных проектах, где нужна тонкая настройка сборки. Vite быстро запускается, почти не требует настройки, его часто выбирают для новых проектов. Ещё один простой в использовании бандлер — **[Parcel](https://parceljs.org)**, он хорошо подходит для небольших проектов без особенных требований.

## Как понять

Современные проекты могут быть огромными (100 тысяч строк или даже больше). Писать такие объёмы кода в одном файле совершенно невозможно. К тому же часто нужно использовать [готовые библиотеки](/tools/package-managers/), которые написал кто-то другой.

Браузеры умеют загружать [модули](/js/modules/), но не знают, где искать пакеты из npm. Ещё браузер узнаёт о вложенном `import`, только когда скачает модуль, в котором тот записан. Например, браузер скачал `index.js`, нашёл в нём `import './cart.js'` и только потом начал качать `cart.js`. Если модули импортируют друг друга в несколько уровней, каждый уровень ждёт предыдущий. Файлы загружаются цепочкой.

Поэтому придумали **системы сборки** (их ещё называют бандлерами или сборщиками). Они находят пакеты из npm и склеивают все модули в один или несколько файлов. Браузеру больше не нужно качать модули цепочкой. Заодно бандлеры сжимают код.

## Как пользоваться

Большинство бандлеров распространяются через npm. Чтобы начать ими пользоваться, достаточно установить пакет бандлера.

```bash
npm init
npm install --save-dev parcel
```

Теперь нужно создать HTML-файл и указать в нём относительный путь до JavaScript-файла.

```html
<!-- index.html -->
<!DOCTYPE html>
<html lang="ru">
  <head>
    <title>Hello, bundler!</title>
  </head>
  <body>
    <h1 id="title">Hello, bundler!</h1>

    <script type="module" src="./index.js"></script>
  </body>
</html>
```

Рядом положите JavaScript-файл:

```js
// index.js

document.getElementById('title').innerText = 'Hello from JS!'
```

Теперь можно запустить бандлер и посмотреть на результат в браузере. Для этого нужно указать в `package.json` входной файл и добавить скрипты.

```json
{
  "source": "index.html",
  "scripts": {
    "dev": "parcel",
    "build": "parcel build"
  }
}
```

Поле `main`, которое добавила команда `npm init`, удалите. Увидев его, Parcel решит, что вы собираете библиотеку, и сборка упадёт.

Запустите режим разработки:

```bash
npm run dev
```

Parcel запустит сервер разработки и напишет в терминале его адрес, обычно `http://localhost:1234`. Откройте его: на странице появится заголовок «Hello from JS!».

Теперь в JS-файлах можно импортировать и свои файлы, и пакеты, установленные через npm. Parcel сам найдёт их и добавит в сборку.

Готовую сборку для публикации на сайте сделает команда `npm run build`. Она положит файлы в папку `dist`. Именно эту папку выкладывают на хостинг.

Vite устроен немного иначе. В режиме разработки он не склеивает ваш код, а отдаёт файлы браузеру по отдельности, как обычные JS-модули. Поэтому сервер разработки запускается почти мгновенно. Цепочка загрузок здесь обычно не мешает: сервер работает на вашем компьютере, и задержки сети почти нет.

При запуске сервера Vite упаковывает только пакеты из npm. Весь код он упаковывает при сборке для публикации. С 8-й версии для этого он использует бандлер Rolldown.

Новый проект с Vite проще всего создать командой `npm create vite@latest`. Она спросит, какой фреймворк использовать, и подготовит все файлы.

Кроме Webpack, Vite и Parcel есть и другие бандлеры. Например:

- [Rollup](/tools/rollup/);
- Rspack, быстрая замена Webpack, которая поддерживает большинство его настроек и плагинов;
- Turbopack, который встроен в Next.js.
