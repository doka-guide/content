Обычно бандлеры, кроме сборки кода, умеют преобразовывать его. Например, можно писать приложение на современном JavaScript, а бандлер превратит его в понятный для старых браузеров код. Parcel делает это через [SWC](https://swc.rs), более быструю замену [Babel](https://babeljs.io).

Но сначала Parcel должен узнать, какие браузеры поддерживать. Без этого списка он синтаксис не преобразует. Список задают полем `browserslist` в `package.json`:

```json
{
  "browserslist": "> 0.5%, last 2 versions, not dead"
}
```

При такой конфигурации Parcel перепишет синтаксис так, чтобы его поняли версии браузеров с долей больше 0,5% в мире и две последние версии каждого браузера. Условие `not dead` убирает браузеры, которые больше не обновляются, например Internet Explorer.

Список браузеров влияет только на синтаксис. Новые методы, например `Array.prototype.at()`, в старых браузерах так и не появятся. Для них нужны полифилы. Это код, который добавляет недостающие методы. Полифилы подключают отдельно.

В режиме разработки Parcel собирает код для современных браузеров и не смотрит на этот список. Parcel применяет его только при `parcel build`.
