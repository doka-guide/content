## Кратко

`<button>` создаёт кнопку: она отправляет форму или запускает действие на странице, например открывает диалог.

## Пример

Кнопка открывает [диалог](/html/dialog/) без JavaScript:

```html
<button type="button" commandfor="greeting" command="show-modal">
  Открыть диалог
</button>

<dialog id="greeting" aria-labelledby="greeting-title">
  <h2 id="greeting-title">Привет!</h2>
  <button type="button" commandfor="greeting" command="close">
    Закрыть
  </button>
</dialog>
```

`commandfor` указывает `id` диалога, а `command` — что с ним сделать.

## Как понять

С помощью CSS можно настроить внешний вид кнопки `<button>` и текста на ней: шрифт, размер, цвет фона и другие параметры. А если ничего не менять, то `<button>` будет выглядеть как стандартная браузерная кнопка.

Внутрь кнопки можно поместить текст, картинку и другие строчные элементы, кроме интерактивных: ссылок, полей и других кнопок. Элементы с атрибутом `tabindex` внутри кнопки тоже запрещены.

Внутри формы кнопка без атрибута `type` отправляет форму, если у неё нет атрибутов `command` и `commandfor`. Если кнопка должна делать что-то другое, укажите `type="button"`.

## Как пишется

Подпись кнопки пишут между открывающим и закрывающим тегом:

```html
<button type="submit">Отправить</button>
```

## Атрибуты

К тегу `<button>` можно применить любой [глобальный атрибут](/html/global-attrs/), а также специфические атрибуты кнопок:

- `autofocus` — кнопка получит фокус сразу после загрузки страницы или открытия диалога, и её можно будет нажать клавишей <kbd>Enter</kbd> или <kbd>Пробел</kbd>. Используйте осторожно: пользователь скринридера пропустит всё, что стоит на странице перед кнопкой.
- `disabled` — делает кнопку недоступной: нажать на неё нельзя, а браузер по умолчанию красит её серым.
- `form` — связывает кнопку с любой формой в документе через её `id`. Без этого атрибута кнопка относится к форме, внутри которой стоит. Если значение пустое или формы с таким `id` нет, кнопка не связана ни с одной формой, даже с той, внутри которой стоит.
- `formaction` — задаёт URL-адрес, куда браузер отправит данные формы.
- `formenctype` — задаёт, как браузер закодирует данные формы перед отправкой. При методе `get` атрибут не действует: данные всегда попадают в адрес. У него есть три значения:
  - `application/x-www-form-urlencoded` — значение по умолчанию. Браузер ставит `+` вместо пробелов и кодирует символы вроде русских букв их шестнадцатеричными значениями (например, `%D0%9F%D0%B5%D1%82%D1%8F` вместо `Петя` 🤡).
  - `multipart/form-data` — нужно, чтобы отправлять файлы. Браузер отправляет каждое поле отдельной частью и не заменяет символы кодами вида `%D0`.
  - `text/plain` — браузер не кодирует буквы, пробелы и другие символы, каждая пара «имя=значение» идёт с новой строки. Такой формат удобен для отладки, но сервер не сможет надёжно его разобрать.
- `formmethod` — сообщает браузеру, каким HTTP-методом нужно передавать данные на сервер. Когда форму отправляет эта кнопка, атрибут заменяет `method` формы. Есть три значения:
  - `post` — упаковывает данные формы в тело запроса и передаёт их на сервер, объём данных зависит от настроек сервера.
  - `get` — добавляет данные из формы прямо в URL-адрес после знака «?», например `https://example.com/doc/?name=Ivan&age=27`. Длину адреса ограничивают сервер, прокси и браузер. Стандарт HTTP советует поддерживать адреса хотя бы до 8000 символов, но реальные пределы бывают меньше. Поэтому большие объёмы данных так не отправляют. Пароли и личные данные через `get` тоже не отправляйте: они останутся в адресе, истории браузера и логах сервера.
  - `dialog` — не отправляет данные, а закрывает `<dialog>`, внутри которого стоит форма. Если у кнопки есть `value`, это значение станет свойством `returnValue` диалога.
- `formnovalidate` — отключает проверку полей, когда форму отправляет эта кнопка. Пригодится, например, для кнопки «Сохранить черновик». Работает от одного присутствия, без значения, как `novalidate` для тега [`<form>`](/html/form/).
- `formtarget` — задаёт, где браузер покажет ответ сервера после отправки формы. Без атрибута браузер возьмёт `target` формы. Значение — имя [фрейма](/html/iframe/) или вкладки, или одно из ключевых слов:
  - `_self` — показывает ответ в текущем окне.
  - `_blank` — показывает ответ в новой вкладке или новом окне браузера.
  - `_parent` — показывает ответ в окне или фрейме, куда встроен текущий фрейм. Если такого нет, загружает в текущем окне.
  - `_top` — загружает ответ в окно верхнего уровня вместо текущей страницы со всеми фреймами. Если родительских фреймов нет, показывает ответ в текущем окне.
- `name` — имя кнопки. Если форму отправила эта кнопка, браузер добавит к данным формы пару из её `name` и `value`.
- `popovertarget` — связывает кнопку с [поповером](/html/popover/) через его `id`. По нажатию кнопка показывает или прячет поповер без JavaScript. Внутри формы такой кнопке нужен `type="button"`, иначе она отправит форму. Что именно делать, задаёт `popovertargetaction`: `toggle` (по умолчанию), `show` или `hide`.
- `commandfor` и `command` — связывают кнопку с элементом по его `id` и задают команду, которую кнопка выполнит. Например, `command="show-modal"` открывает диалог как модальное окно, а `command="close"` закрывает его. Внутри формы таким кнопкам всегда пишите `type="button"`: без него кнопка не отправит форму и не выполнит команду. В браузерах без поддержки кнопка с `type="button"` ничего не делает. Проверить поддержку можно так: `'command' in HTMLButtonElement.prototype`.
- `type` — задаёт действие кнопки при нажатии:
  - `submit` — отправляет данные формы на сервер. Кнопка без атрибута `type` внутри формы делает то же самое, если у неё нет атрибутов `command` и `commandfor`.
  - `reset` — возвращает полям формы начальные значения.
  - `button` — просто кнопка. Действие для неё задают через скрипты или атрибуты `commandfor` и `popovertarget`.
- `value` — значение кнопки. Уходит на сервер вместе с `name`, только если форму отправила эта кнопка.

Атрибуты `formaction`, `formenctype`, `formmethod`, `formnovalidate` и `formtarget` работают только у кнопки, которая отправляет форму.

## Подсказки

💡 Чтобы кнопка отправила данные на сервер, поставьте её внутрь `<form>`. Или свяжите их через атрибут `form` со значением `id` формы:

```html
<form id="login" method="post">
  <label>
    Введите ваш email
    <input type="email" name="email" placeholder="Ваш email">
  </label>
</form>
<button type="submit" form="login">Отправить</button>
```

💡 Тег [`<input>`](/html/input/) с `type="button"`, `"reset"` или `"submit"` тоже создаёт кнопку. Но `<button>` проще стилизовать: внутрь можно добавить разметку, например [`<em>`](/html/em/), [`<strong>`](/html/strong/) или [`<img>`](/html/img/).
