## Кратко

Глобальные атрибуты можно задать любому или почти любому HTML-тегу.

## Пример

Пример глобального атрибута, с которым вы точно работаете постоянно, — [`class`](/html/class/). Его можно задать абсолютно любому тегу. Что очень круто, иначе нам было бы гораздо сложнее стилизовать страницу.

```html
<div class="parent">Простой div</div>

<span class="parent">Простой span</span>

<h1 class="parent">Простой h1</h1>
```

## Как пишется

Здесь собраны самые полезные глобальные атрибуты. Почти все они работают во всех современных браузерах, исключения отмечены. Полный список — [в спецификации HTML](https://html.spec.whatwg.org/multipage/dom.html#global-attributes).

### `class`

Позволяет выбирать конкретный элемент (или несколько) при помощи CSS или JavaScript. Значение: один или несколько классов через пробел.

### `contenteditable`

Делает любой элемент на странице редактируемым. Значения: `true`, `false` и `plaintext-only`. С `plaintext-only` пользователь может менять только текст: жирный, курсив и другое оформление при вставке и горячими клавишами не появятся. Можно записать атрибут совсем без значения, тогда он работает как `contenteditable="true"`.

```html
<!-- Можно так -->
<div contenteditable></div>

<!-- Или так -->
<div contenteditable="true"></div>
```

### `data-*`

[`data-*`](/html/data-attributes/) — группа атрибутов, в которых хранят свои данные прямо в HTML и читают их через [DOM](/js/dom/). Часто их используют, чтобы работать с HTML из JavaScript. Если не нужно менять внешний вид элемента, то это удобнее, чем переключать классы.

### `hidden`

[`hidden`](/html/hidden/) прячет со страницы любой HTML-элемент. Причём элемент невидим не только для глаз пользователя, но и для [скринридеров](/a11y/screenreaders/). Обычно атрибут пишут без значения. Браузер прячет элемент через `display: none` в своих стилях. Поэтому `display` из ваших стилей перебьёт атрибут, и элемент снова появится.

Значение `until-found` прячет содержимое элемента. Браузер покажет его, если пользователь найдёт текст из элемента поиском по странице или перейдёт к нему по якорю. В Safari это значение пока работает частично.

### `id`

Задаёт элементу идентификатор. По нему создают якоря — ссылки на части страницы — и выбирают элемент при помощи CSS или JavaScript. Значение: одно слово или набор символов, не может содержать пробелы. Значение должно быть уникальным на странице.

### `lang`

Определяет, на каком языке написан текст внутри элемента, для которого задан этот атрибут. Удобно, если в вашем тексте есть цитаты или выдержки из документа на другом языке. От языка зависят произношение в скринридере, переносы слов и кавычки у [`<q>`](/html/q/). Значение: код языка, например `en` или `ru`. Как задать язык всей страницы, читайте в статье про [`<html>`](/html/html/).

### `dir`

[`dir`](/html/dir/) определяет направление письма — слева направо, как в английском, или справа налево, как в иврите. Значение: `ltr` — направление слева направо, `rtl` — справа налево и `auto` — направление выбирает браузер.

### `spellcheck`

Подсказывает браузеру, нужно ли проверять правописание в редактируемом элементе: в `<input>`, `<textarea>` или элементе с `contenteditable`. Значение: `true` или пустая строка — проверять, `false` — не проверять.

### `translate`

Подсказывает машинным переводчикам, например встроенному в браузер, нужно ли переводить текст элемента. Пригодится для названий брендов и кода. Значение: пустая строка или `yes` — переводить, `no` — не переводить.

### `style`

Позволяет прописывать стили прямо внутри HTML-разметки. Оформление так лучше не задавать: такие стили трудно переопределить и поддерживать. Но атрибут удобен, чтобы передать в CSS значение из разметки, например `style="--progress: 40%"`. Значение: объявления CSS вида `свойство: значение` через точку с запятой.

Учтите, что атрибут может не сработать из-за политики безопасности контента (CSP). CSP — это правила, по которым браузер решает, какие скрипты и стили применять. Если в CSP запрещены встроенные стили, браузер проигнорирует атрибут `style`. Тогда задайте значение из JavaScript: `el.style.setProperty('--progress', '40%')`. Такой способ CSP не блокирует.

### `tabindex`

[`tabindex`](/html/tabindex/) указывает браузеру, может ли элемент получить фокус при навигации по странице с клавиатуры. Например, с `tabindex="-1"` можно поставить фокус на заголовок из JavaScript.

Значение: целое число.

- Отрицательное число: элемент может получить фокус из JavaScript или по клику, но не участвует в навигации клавишей <kbd>Tab</kbd>.
- `0`: элемент участвует в навигации клавишей <kbd>Tab</kbd> в порядке следования в HTML, после элементов с положительными значениями.
- Положительное число: элемент участвует в навигации клавишей <kbd>Tab</kbd> раньше остальных. Элементы с меньшим значением идут первыми: `1` раньше `2`. Элементы с одинаковыми значениями идут по порядку следования в HTML.

Положительные значения лучше не использовать: порядок фокуса перестаёт совпадать с порядком на странице, и пользователю клавиатуры трудно ориентироваться.

Кнопку из [`<div>`](/html/div/) с `tabindex` не сделать: элемент получит фокус, но не роль и поведение кнопки. Для этого есть [`<button>`](/html/button/).

### `title`

Позволяет добавить любому элементу _подсказку_ с дополнительной информацией. Браузер может показать её тултипом при наведении курсора, но не обязан. На практике его используют редко: тултип нельзя стилизовать. Его не увидят пользователи сенсорных экранов и клавиатуры, а скринридеры зачитывают `title` не всегда. Поэтому важную информацию в `title` не кладите. Исключение — [`<iframe>`](/html/iframe/): `title` даёт ему название для скринридеров.

### `role`

Добавляет к тегу явную роль. Благодаря атрибуту даже у семантически нейтральных `<div>` и [`<span>`](/html/span/) появляется смысл для скринридеров и других вспомогательных технологий. Значение: [ARIA-роль](/a11y/aria-roles/), которая подходит этому тегу. Роль меняет только то, как элемент видят скринридеры. У `<div role="button">` не появятся фокус и реакция на клавиши, их добавляют отдельно.

### `inert`

[`inert`](/html/inert/) делает элементы неактивными. По ним нельзя кликнуть, на них нельзя поставить фокус с клавиатуры и в них нельзя ввести данные. А ещё атрибут скрывает элементы от скринридеров. Его можно задать даже группе элементов, например всей форме [`<form>`](/html/form/). Этим он похож на атрибут [`disabled`](/html/disabled/).

### `accesskey`

Назначает элементу горячую клавишу: при её нажатии браузер переводит фокус на элемент или нажимает на него. Значение: символ, например `s`. Через пробел можно указать запасные символы на случай, если первый занят. Сочетание с клавишей-модификатором зависит от браузера и системы, например <kbd>Alt</kbd> в Chrome на Windows или <kbd>Control</kbd> + <kbd>Option</kbd> на macOS.

Пользуйтесь `accesskey` осторожно: сочетание может совпасть с горячими клавишами браузера, системы или скринридера, а пользователь о нём обычно не знает.

В [ARIA](/a11y/aria-intro/) есть похожий атрибут [`aria-keyshortcuts`](/a11y/aria-keyshortcuts/). Но он только сообщает о сочетании скринридеру, а само сочетание нужно обработать в JavaScript.

### `enterkeyhint`

[`enterkeyhint`](/html/enterkeyhint/) меняет подпись или иконку клавиши ввода на экранной клавиатуре, пока фокус в поле. Само действие по нажатию клавиши атрибут не меняет. Значения: `enter`, `done`, `go`, `next`, `previous`, `search` или `send`.

### `draggable`

Означает, что элемент можно перетаскивать. Значение: `true` или `false`.

### `itemscope`

Микроразметка описывает данные на странице, например книгу, товар или событие, так, чтобы их понимали программы. Браузеры её никак не обрабатывают, её читают поисковики и другие программы. Например, поисковики берут из неё рейтинг и цену для выдачи.

`itemscope` создаёт объект микроразметки. Его свойства задают элементы внутри с атрибутом `itemprop`:

```html
<div itemscope itemtype="https://schema.org/Book">
  <h3 itemprop="name">Название книги</h3>
  <a itemprop="url" href="https://example.com/book">Страница книги</a>
</div>
```

Если свойство лежит во вложенном `itemscope`, оно относится к вложенному объекту.

### `itemprop`

Задаёт имя свойства объекта `itemscope`. Значение свойства программа берёт из содержимого элемента или из атрибута, например `href` у ссылки. Значение атрибута: имя свойства, например `name` или `price`.

### `itemtype`

Тип объекта микроразметки. Значение: один или несколько URL типов из словаря, чаще всего из [Schema.org](https://schema.org/), например `https://schema.org/Book`.

### `itemid`

Задаёт объекту глобальный идентификатор. Атрибут ставят на элемент с `itemscope` и `itemtype`. Значение: URL, например `urn:isbn:0-330-34032-8` для книги.

### `itemref`

Подключает к объекту свойства, которые лежат вне его элемента. Атрибут ставят на элемент с `itemscope`. Значение: один или несколько `id` элементов со свойствами через пробел.

### `popover`

[`popover`](/html/popover/) превращает элемент в поповер — всплывающий слой поверх страницы. Открыть его можно кнопкой с атрибутом `popovertarget` без JavaScript. Значения:

- `auto` или пустая строка: поповер закрывается кликом мимо него и клавишей <kbd>Esc</kbd>;
- `manual`: закрыть его можно только кнопкой или из кода;
- `hint`: для подсказок вроде тултипа, закрывается так же, как `auto`, но не закрывает открытые поповеры `auto`.

Значение `hint` появилось в браузерах недавно.

### `autofocus`

[`autofocus`](/html/autofocus/) ставит фокус на элемент после загрузки страницы или при открытии [диалога](/html/dialog/) и поповера, внутри которого стоит элемент. Значение не нужно.

Атрибут сработает, только если:

- это первый такой элемент на странице;
- фокус ещё нигде не стоит;
- в адресе нет якоря на элемент страницы.

Используйте его осторожно: пользователь скринридера может пропустить всё, что стоит до элемента.

### `inputmode`

[`inputmode`](/html/inputmode/) подсказывает, какую экранную клавиатуру показать для редактируемого элемента. Значения: `none`, `text`, `decimal`, `numeric`, `tel`, `search`, `email` и `url`.

### `autocapitalize`

Подсказывает экранной клавиатуре, когда сделать букву заглавной. Работает на мобильных устройствах. На компьютере с обычной клавиатурой атрибут ни на что не влияет.

Значения:

- `off` или `none`: не делать заглавных букв;
- `on` или `sentences`: первая буква каждого предложения;
- `words`: первая буква каждого слова;
- `characters`: все буквы.

### `nonce`

Одноразовый токен для политики безопасности контента (CSP). Значение: случайная строка не короче 128 бит в base64, которую сервер генерирует заново для каждого ответа.

Если в CSP указан источник `'nonce-…'`, браузер выполнит встроенный [`<script>`](/html/script/) или применит [`<style>`](/html/style/) только с тем же значением `nonce`. Внешний скрипт с таким `nonce` браузер загрузит, даже если его сервера нет в списке разрешённых. `nonce` не действует на атрибут `style` и обработчики вроде `onclick`.
