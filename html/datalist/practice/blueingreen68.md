🛠 Сам выпадающий список `<datalist>` стилизовать не получится. Но можно поменять иконку стрелки, календаря или циферблата.

Так как браузеры по-разному отображают поля, разберём пример для Chrome и других браузеров на Chromium. В них за иконку со стрелкой, календарём и циферблатом отвечает псевдоэлемент `::-webkit-calendar-picker-indicator`. В Safari стрелку у `<datalist>` рисует другой псевдоэлемент — `::-webkit-list-button`.

Вот как можно изменить вид стрелки.

Скроем псевдоэлемент `::-webkit-calendar-picker-indicator` через свойство `display: none`:

```css
:is(
  :not([type]),
  [type="text"],
  [type="search"],
  [type="url"],
  [type="email"],
  [type="tel"],
  [type="number"]
)[list]::-webkit-calendar-picker-indicator {
  display: none !important;
}
```

Chrome задаёт стрелке `display` в инлайновом стиле, поэтому без [`!important`](/css/important/) правило не применится.

<aside>

⚠️ Не скрывайте иконку у полей `date`, `month`, `week`, `time` и `datetime-local`. Без календаря или циферблата пользователь не сможет выбрать вариант из списка. Поэтому селектор выше перечисляет только текстовые типы.

</aside>

После того как скрыли псевдоэлемент, можно использовать свою иконку. Хороший пример можно посмотреть в разделе «[На практике](/html/select/#na-praktike)» статьи про `<select>`. Такая иконка — только подсказка: по клику она список не откроет.

У поля с типом `color` иконку со стрелкой изменить не получится.

🛠 Иконки с циферблатом и календарём у полей с типом `date`, `month`, `week`, `time` и `datetime-local` в светлой теме тёмные. На тёмном фоне их почти не видно. Чтобы браузер взял светлые иконки, укажите элементу тёмную цветовую схему через свойство [`color-scheme`](/css/color-scheme/):

```css
input[list] {
  color-scheme: dark;
}
```

Не перекрашивайте иконку через свойство [`filter`](/css/filter/) со значением `invert(1)`. Если у страницы уже стоит `color-scheme: dark`, иконка и так светлая, и фильтр снова сделает её тёмной.
