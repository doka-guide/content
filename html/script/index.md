## Кратко

Скрипт — это фрагмент кода, который позволяет совершать действия, включать анимацию и создавать другие эффекты на странице. Чтобы добавить скрипты, используйте тег `<script>`.

Как и CSS-стили, скрипты можно прописать внутри кода страницы или подключить как внешний файл по ссылке.

Теги `<script>` можно располагать в любом месте внутри [`<head>`](/html/head/) или [`<body>`](/html/body/) HTML-документа. Внешние скрипты удобнее всего подключать в `<head>` с атрибутом `defer` или как модули с `type="module"`. Тогда браузер начнёт скачивать файл сразу, а разбирать разметку продолжит, не дожидаясь скрипта.

## Пример

В этом примере мы подключим скрипт из внешнего файла. Атрибут `src` указывает путь к файлу, а `defer` просит браузер выполнить скрипт, когда закончит разбирать разметку.

```html
<head>
  <script src="external.js" defer></script>
</head>
```

## Как понять

HTML создаёт структуру веб-страницы, CSS-стили — её внешний вид, а скрипты на JavaScript определяют поведение страницы. С помощью скриптов можно «оживить» страницу, добавить анимацию и другие эффекты.

Лучше добавлять скрипты из внешнего файла. Это поможет быстро добавлять одинаковое поведение на разные страницы, а также редактировать и контролировать всё в одном месте. Пользователю это ускорит загрузку: браузер сохранит файл в кеш и не будет скачивать его заново на каждой странице сайта.

## Как пишется

Тег `<script>` — парный, его всегда нужно закрывать с помощью `</script>`. Если вы подключаете внешние скрипты по ссылке, то внутри тега ничего писать не надо. Но закрыть тег всё равно придётся.

Если добавить скрипты в код, то выглядеть это будет так:

```html
<script>
  window.alert('Добавили вот какой-то JavaScript-код');
</script>
```

## Атрибуты

- `async` — браузер скачивает скрипт параллельно с разбором разметки и запускает его сразу, как только файл загрузится. На время запуска браузер приостанавливает разбор разметки. Порядок выполнения не гарантирован: какой скрипт загрузился первым, тот и выполнится. Подходит для независимых скриптов, например, счётчиков аналитики. Работает для внешних скриптов и для модулей.
- `defer` — браузер скачивает скрипт параллельно с разбором разметки, а запускает, когда вся разметка разобрана, но до события [`DOMContentLoaded`](/js/event-domcontentloaded/). Скрипты с `defer` выполняются в том порядке, в котором стоят в разметке. Работает только для внешних скриптов. Модули ведут себя так по умолчанию.
- `src` — указывает путь к файлу со скриптами. Это может быть полный URL-адрес файла или относительный адрес, например, `src="/scripts/browser.js"`. Когда указываете `src`, не пишите ничего внутри `<script>...</script>`.
- `type` — задаёт тип содержимого скрипта. Для обычного JavaScript атрибут не нужен. Значение `module` подключает скрипт как [ES-модуль](/js/modules/). Значение `importmap` превращает содержимое тега в карту импорта, о ней — в разделе ниже. Если указать неизвестный браузеру тип, он не выполнит содержимое тега и сочтёт его блоком данных.

Если ни `async`, ни `defer` нет, браузер останавливает разбор разметки. Он скачивает и выполняет скрипт и только после этого идёт дальше.

Такой скрипт видит только элементы над собой. Поэтому в `<head>` без `defer` он не найдёт элементы страницы: [`getElementById()`](/js/getelementbyid/) вернёт `null`.

## Карта импорта

Без карты импорта браузер понимает в `import` только полные URL-адреса и пути, которые начинаются с `/`, `./` или `../`. Короткое имя пакета, как в [Node.js](/tools/nodejs/), вызовет ошибку. Чтобы объяснить браузеру, куда ведёт имя, перед модульными скриптами добавляют `<script type="importmap">` с JSON-картой соответствий:

```html
<script type="importmap">
{
  "imports": {
    "lodash": "https://cdn.jsdelivr.net/npm/lodash-es@4.18.1/+esm"
  }
}
</script>

<script type="module">
  import _ from 'lodash';
  console.log(_.chunk([1, 2, 3, 4], 2));
  // [[1, 2], [3, 4]]
</script>
```

Адрес в карте должен вести на ES-модуль, например, на сборку с CDN — сети серверов, которая раздаёт файлы. Пакет, который отдаёт код через `module.exports` (формат CommonJS), так не подключить.

Ставьте карту импорта в разметке раньше всех `<script type="module">`. Модуль, который загрузился до карты, её не увидит, а некоторые браузеры позднюю карту вообще игнорируют. Атрибут `src` у карты не работает: JSON пишут только внутри тега.

Если [сборщик](/tools/bundlers/) вроде [Webpack](/tools/webpack/) или Vite нужен только ради коротких имён пакетов, карта импорта его заменит. Минифицировать код или компилировать TypeScript она не умеет.

## Подсказки

💡 Расширение файла браузеру не важно: `.js` — просто традиция. Важен MIME-тип, который сервер указывает в заголовке `Content-Type`. Для JavaScript это `text/javascript`. Браузер проверяет тип так:

- модуль выполнится, только если тип — JavaScript;
- обычный скрипт выполнится почти с любым типом, кроме `image/*`, `audio/*`, `video/*` и `text/csv`;
- если сервер прислал заголовок `X-Content-Type-Options: nosniff`, обычному скрипту тоже нужен тип JavaScript.

💡 Скрипт со стороннего CDN можно защитить от подмены. Добавьте атрибут `integrity` с хешем — «отпечатком» содержимого файла. Если файл на CDN изменится, браузер не станет его выполнять. Хеш обычно выдаёт сам CDN рядом со ссылкой на файл.

Вместе с `integrity` добавьте атрибут `crossorigin="anonymous"`. Без него браузер не сможет сверить хеш файла с чужого домена и заблокирует скрипт, даже если файл не менялся. Сервер CDN при этом должен присылать заголовок `Access-Control-Allow-Origin`.

## Ещё примеры

Попробуем с помощью скрипта сделать так, чтобы текст увеличивался и уменьшался через каждую пару секунд:

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="utf-8">
    <title>Подключение скриптов</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Подключение скриптов</h1>
    <p id="blinking">
      Скрипты можно подключить разными способами. Например,
      описать их прямо внутри HTML-страницы. Но лучше всё же
      в отдельном файле.
    </p>
    <script>
      const paragraph = document.getElementById('blinking');
      setInterval(function () {
        if (paragraph.style.fontSize !== '10px') {
          paragraph.style.fontSize = '10px';
        } else {
          paragraph.style.fontSize = '20px';
        }
      }, 2000);
    </script>
  </body>
</html>
```

Это учебный пример, код в статье сокращён. В демке есть кнопка паузы.

На реальном сайте у текста, который сам меняется дольше пяти секунд, должен быть способ его остановить, например, кнопка паузы. Такого требуют правила доступности [WCAG](/a11y/wcag/). Мигающий и движущийся текст отвлекает людей с нарушениями внимания и мешает тем, кому трудно читать или следить за движением.
