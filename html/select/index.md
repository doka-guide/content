## Кратко

Тег `<select>` показывает выпадающий список, из которого пользователь выбирает одну или несколько опций.

## Пример

```html
<form>
  <label for="city-select">Ваш город</label>
  <select name="city" id="city-select">
    <option value="">-- Выберите город --</option>
    <option value="petersburg">Санкт-Петербург</option>
    <option value="samara">Самара</option>
    <option value="perm">Пермь</option>
    <option value="novosibirsk">Новосибирск</option>
  </select>
</form>
```

## Как пишется

Тег `<select>` — обёртка над списком опций, которые задаются тегом [`<option>`](/html/option/). Ещё внутри могут стоять [`<optgroup>`](/html/optgroup/) и [`<hr>`](/html/hr/).

Чтобы отправить выбранное значение на сервер, задайте тегу `<select>` атрибут `name`. Каждому тегу `<option>` лучше задать атрибут [`value`](/html/value/): его значение и уйдёт на сервер. Если `value` не задан, браузер отправит текстовое содержимое опции.

Чтобы изначально выбрать опцию, задайте ей атрибут `selected`.

В настраиваемом режиме внутри списка можно ставить и другие теги. Подробнее — в разделе о настраиваемом списке.

## Атрибуты

У тега `<select>` есть несколько своих атрибутов, а ещё он понимает большинство атрибутов элементов форм.

### `autocomplete`

Подсказывает браузеру, какую опцию выбрать по сохранённым данным пользователя. Например, значение `country` — страну, `address-level2` — город. Значение `off` просит браузер не выбирать опцию самому.

### `autofocus`

Атрибут булевого типа: у него нет значения, атрибут или есть в теге, или его нет совсем. Если он указан, то при загрузке страницы браузер поставит фокус на список. Используйте его осторожно: скринридер начнёт чтение с этого списка, и пользователь пропустит всё, что выше.

### `disabled`

Атрибут булевого типа. Если задан, то выпадающий список отключается для взаимодействия с пользователем. Список отключится и тогда, когда он стоит внутри отключённого контейнера [`<fieldset disabled>`](/html/fieldset/).

### `form`

Атрибут указывает на элемент [`<form>`](/html/form/), с которым связан выпадающий список. Значением атрибута должен быть `id` формы в пределах текущего документа. Если атрибут не задан, `<select>` связан с формой, внутри которой стоит. Если задать атрибут, `<select>` может стоять в любом месте страницы.

### `multiple`

Атрибут булевого типа. Разрешает выбрать сразу несколько опций. Если атрибут задан, то внешний вид списка поменяется с однострочного на многострочный с прокруткой. На телефонах браузеры обычно показывают вместо этого системное окно выбора.

### `name`

Имя выпадающего списка. При отправке формы значение атрибута `name` станет именем поля в данных формы.

### `required`

Атрибут булевого типа. Указывает, что пользователь обязательно должен что-то выбрать. Браузер проверяет атрибут перед отправкой формы и показывает ошибку, если ничего не выбрано.

В однострочном списке первая опция выбрана сразу, поэтому атрибуту нужна заглушка: первая опция с пустым `value`, вроде `<option value="">-- Выберите город --</option>`. Её выбор не считается ответом. Без заглушки проверка проходит всегда.

### `size`

Числовой атрибут, который задаёт количество видимых опций. Если значение больше 1, список показывается не выпадающим, а открытым блоком с прокруткой. Работает и с `multiple`, и без него.

## Настраиваемый выпадающий список

Долгое время выпадающий список почти не поддавался стилизации: панель с опциями рисовала операционная система или браузер по своим правилам. Теперь браузеры умеют переключать `<select>` в настраиваемый режим. Для этого самому списку и его панели задают значение `base-select` у свойства [`appearance`](/css/appearance/):

```css
select,
::picker(select) {
  appearance: base-select;
}
```

В этом режиме браузер рисует панель сам, и её можно стилизовать как обычный блок.

Внутри `<option>` можно ставить картинки, иконки, [`<span>`](/html/span/) и [`<div>`](/html/div/). Интерактивные элементы вроде ссылок и полей ввода ставить нельзя.

Чтобы оформить сам список, поставьте первым дочерним элементом однострочного `<select>` тег [`<button>`](/html/button/). Внутрь кнопки положите `<selectedcontent>`. В него браузер копирует содержимое выбранной опции вместе с картинками:

```html
<label for="status">Статус задачи</label>
<select id="status" name="status">
  <button>
    <selectedcontent></selectedcontent>
  </button>
  <option value="new">
    <span class="dot new"></span>
    Новая
  </option>
  <option value="in-progress">
    <span class="dot in-progress"></span>
    В работе
  </option>
</select>
```

Для частей списка есть отдельные псевдоэлементы:

- `::picker(select)` — выпадающая панель с опциями;
- `::picker-icon` — стрелка в самом списке;
- `::checkmark` — галочка у выбранной опции.

Панель открывается в верхнем слое страницы, поверх всех элементов, как [поповер](/html/popover/). Поэтому её не обрежет [`overflow: hidden`](/css/overflow/) у родителя. Рядом со списком панель ставит [якорное позиционирование](/css/anchor-positioning-guide/).

Настраиваемый `<select>` работает в Chrome и Edge 135+ и в Safari 27+. В Firefox он пока включается только в экспериментальных настройках браузера.

Браузеры без поддержки игнорируют `appearance: base-select` и показывают обычный `<select>` с текстом опций. Кнопку, картинки и другие лишние теги внутри списка они не рисуют. Поэтому новый режим можно добавлять уже сейчас.

Оставляйте в каждой опции текст: иконка должна дополнять подпись, а не заменять её. Опция из одной картинки в старом браузере станет пустой строкой, и скринридер тоже ничего не прочитает.

## Подсказки

💡 Выбрать несколько опций в списке с атрибутом `multiple` помогают клавиши:

- <kbd>Ctrl</kbd> (Windows, Linux) или <kbd>Cmd</kbd> (macOS). Зажмите клавишу и кликайте по нужным опциям. Так можно выбрать опции, которые стоят далеко друг от друга.
- <kbd>Shift</kbd>. Выберите опцию, зажмите клавишу и выберите другую. Выберутся все опции между ними.
