🛠 Иногда всё же может понадобиться «отключить» ссылку. На это должна быть веская причина: временная «заглушка», требование специалиста по продвижению сайта и так далее. Если ссылка ведёт на текущую страницу и блокировать её не нужно, хватит [`aria-current="page"`](/a11y/aria-current/).

Как заблокировать ссылку?

Лучше всего убрать атрибут `href`, спецификация это разрешает. Такая ссылка ведёт себя как «заглушка» и не интерактивна:

- в контекстном меню по правому клику не будет пунктов для ссылки;
- вид курсора при наведении не изменится;
- при навигации с клавиатуры не возникнет фокус.

```html
<a>Текст ссылки</a>
```

Вспомогательные технологии не считают этот элемент ссылкой с ролью [`link`](/a11y/role-link/). Это не совсем корректно с точки зрения семантики. Лучше показать, что это именно ссылка и что её отключили умышленно, а не по ошибке. Роль вернёт атрибут `role="link"`, а обозначить ссылку как отключённую поможет атрибут [`aria-disabled="true"`](/a11y/aria-disabled/).

```html
<a role="link" aria-disabled="true">Текст ссылки</a>
```

Если на сайте есть или могут появиться ссылки-«заглушки», пропишите состояния (например, [`:hover`](/css/hover/)) с учётом `href`, чтобы заблокированные ссылки не выглядели интерактивными. Например, так:

```css
a[href]:hover {
  background-color: #FF8630;
}
```
