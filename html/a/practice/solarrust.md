🛠 Ссылку нельзя вкладывать в ссылки 🤷‍♀️ Также в ссылку не обернуть:

- другие интерактивные элементы, например [`<button>`](/html/button/), [`<details>`](/html/details/), [`<label>`](/html/label/);
- элементы с атрибутом [`tabindex`](/html/tabindex/).

При этом спецификация разрешает вкладывать в ссылку абзацы, списки, таблицы и даже целые секции, если в них нет собственного интерактивного содержимого. Но сама ссылка должна стоять там, где такие элементы разрешены. Например, `<div>` в ссылке внутри [`<p>`](/html/p/) — ошибка.

🛠 Если ссылкой должен быть только заголовок, вкладывайте ссылку в заголовок, а не наоборот. Обе записи валидны, но ссылка вокруг заголовка делает кликабельной всю ширину блока, а не только текст.

```html
<!-- Кликабельна вся ширина блока -->
<a href="#">
  <h2>Заголовок, он же ссылка</h2>
</a>

<!-- Кликабелен только текст заголовка -->
<h2>
  <a href="#">Заголовок, он же ссылка</a>
</h2>
```
