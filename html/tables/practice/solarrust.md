🛠 Частый дизайнерский приём — подсветка строк таблицы через одну. Это помогает считывать длинные таблицы, глазу есть за что зацепиться.

Например, сделаем каждую нечётную строку с коричневым фоном. Для этого понадобится всего одно CSS-правило с псевдоклассом [`:nth-child()`](/css/child/):

```css
tr:nth-child(odd) {
  background-color: #663613;
}
```

На всякий случай подстрахуемся и ограничим область _раскрашивания_ только телом таблицы, исключим шапку и подвал.

```css
tbody tr:nth-child(odd) {
  background-color: #663613;
}
```

🛠 Можно сделать так, чтобы строка с заголовками колонок **прилипала** при прокрутке длинной таблицы. Это удобно, если данных много и пользователь может просто забыть, в какой колонке какие данные.

Это довольно просто сделать при помощи [`position: sticky`](/css/position/). Свойство работает на ячейках `<th>` и на всём `<thead>` (в Chrome — с 91-й версии). Применим его к ячейкам шапки, чтобы не задеть заголовки строк в `<tbody>`.

```css
thead th {
  position: sticky;
  top: 0;
  z-index: 1;
}
```

Задайте ячейкам шапки фон, чтобы под ней не просвечивали строки при прокрутке. А чтобы контент не просвечивал сквозь зазоры между ячейками, зададим для всей таблицы свойство `border-collapse: collapse`:

```css
table {
  border-collapse: collapse;
}

thead th {
  position: sticky;
  top: 0;
  z-index: 1;
  background-color: #FF8630;
}
```

Учтите две особенности:

- Шапка прилипает к ближайшему предку с `overflow: hidden`, `scroll` или `auto`, даже если он сам не прокручивается. Обёртка с `overflow-x: auto` для горизонтальной прокрутки — как раз такой предок: у неё `overflow-y` тоже становится `auto`. Поэтому шапка прилипнет к верху обёртки, а не окна. Ограничьте обёртке высоту, и таблица будет прокручиваться внутри неё в обе стороны.
- При `border-collapse: collapse` границы рисует таблица, а не ячейка. Поэтому у прилипшей ячейки они остаются на старом месте и уезжают вместе с контентом. Так ведут себя все браузеры. В демке нижняя граница шапки нарисована псевдоэлементом [`::after`](/css/after/) внутри ячейки, поэтому она едет вместе с шапкой. Половина толстой верхней границы таблицы тоже уезжает и оставляет над шапкой щель. Её закрывает сдвиг `top: -4px`.
