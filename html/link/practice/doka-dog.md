🛠 `<link rel="canonical">` указывает главную страницу среди дублей. Это нужно для качественной индексации в поисковиках.

Например, мобильная версия сайта живёт на поддомене m.example.ru. На её страницах пишут:

```html
<link rel="canonical" href="https://example.ru/">
```

А на десктопных страницах ссылаются на мобильную версию через `rel="alternate"`:

```html
<link
  rel="alternate"
  media="only screen and (max-width: 640px)"
  href="https://m.example.ru/"
>
```

🛠 Для CSS не нужен атрибут `type="text/css"`: это значение по умолчанию.

🛠 Помните о порядке в [каскаде](/css/cascade/): если у правил одинаковая [специфичность](/css/specificity/), браузер применит то, что описано ниже. Поэтому правка в одном файле может не сработать: тот же стиль переопределён в файле, подключённом ниже.
