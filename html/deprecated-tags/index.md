По мере развития веб-технологий одни теги появляются, а другие устаревают. Некоторые из них браузеры уже не поддерживают, а некоторые спецификация HTML никогда не разрешала. Разберём, чем их заменить, если они встретились в проекте.

Список всех устаревших тегов и свойств [в спецификации HTML](https://html.spec.whatwg.org/multipage/obsolete.html).

## Разметка текста

### `<acronym>` — акронимы и аббревиатуры

Акроним — аббревиатура из начальных звуков, которую читают как обычное слово: вуз, НАТО. Другие аббревиатуры произносят по буквам: СНГ — [эс-эн-гэ], МВД — [эм-вэ-дэ].

#### Когда использовалось

Для расшифровки аббревиатуры. Расшифровку пишут в атрибуте `title`, и браузер показывает её в подсказке при наведении курсора.

#### Пример

```html
<acronym title="Graphics Interchange Format">
  GIF
</acronym> — устаревший формат графики
```

GIF — как раз акроним: его произносят одним словом «гиф», а не по буквам «джи-ай-эф», даже в английском.

#### Чем заменить

Для `<acronym>` есть современная альтернатива — [`<abbr>`](/html/abbr/).

### `<blink>` — мигающий текст

#### Когда использовалось

Чтобы привлечь внимание к тексту: тег заставлял его мигать.

#### Пример

```html
<blink>Зачем кому-либо так делать? Выглядит негуманно.</blink>
```

#### Чем заменить

Мигание почти всегда отвлекает. Если оно всё же нужно, повторите его на CSS:

```css
.blink {
  animation: 2s linear 2 condemned_blink_effect;
}

@media (prefers-reduced-motion: reduce) {
  .blink {
    animation: none;
  }
}

@keyframes condemned_blink_effect {
  0% {
    visibility: hidden;
  }
  50% {
    visibility: hidden;
  }
  100% {
    visibility: visible;
  }
}
```

Класс `.blink` повесьте на обычный элемент, например на [`<span>`](/html/span/). Анимация повторяется два раза и длится 4 секунды.

Короткое мигание не нарушает критерий 2.2.2 [Руководства по доступности веб-контента (WCAG)](/a11y/wcag/). Если мигание начинается само и длится дольше 5 секунд, пользователь должен суметь поставить его на паузу, остановить или скрыть.

Медиазапрос [`prefers-reduced-motion`](/a11y/prefers-reduced-motion/) отключает мигание совсем, если пользователь попросил систему уменьшить движение. Но способ остановить мигание он не заменяет.

### `<font>` — стилизация текста

#### Когда использовалось

Пока браузеры не умели оформлять текст через CSS, это был единственный способ изменить цвет, шрифт или размер. В вёрстке писем его иногда используют до сих пор как запасной вариант для почтовых клиентов со слабой поддержкой CSS.

#### Пример

```html
Летели два <font size="+1">крокодила</font>.
Один — <font color="green">зелёный</font>, а другой — в Африку.
```

#### Чем заменить

Вместо атрибутов `<font>` используйте CSS-свойства: [`color`](/css/color/) вместо атрибута `color`, [`font-size`](/css/font-size/) вместо `size`, [`font-family`](/css/font-family/) вместо `face`. Свойств для оформления текста в CSS гораздо больше:

```css
h1 {
  font-family: Arial, Helvetica, sans-serif; /* Гарнитура шрифта */
  font-size: 150%; /* Размер текста */
  font-weight: lighter; /* Светлое начертание */
}

.text_color_green {
  color: green; /* Цвет текста */
}

.text_style_italic {
  font-style: italic; /* Курсив */
}

.text_transform_uppercase {
  text-transform: uppercase; /* Все буквы — заглавные */
}

.text_emphasis {
  letter-spacing: .5em; /* Межбуквенный интервал (трекинг) */
  word-spacing: 2em; /* Расстояние между словами (ширина пробела) */
  text-shadow: 3px 5px 6px #6C9; /* Тень */
}
```

### `<nobr>` — неразрывный текст

Тег `<nobr>` запрещал переносить текст на новую строку. По умолчанию, если текст не помещается по ширине, браузер переносит его на новую строку там, где перенос разрешён, обычно на пробеле. Текст внутри `<nobr>` остаётся в одну строку и может вызвать полосу прокрутки.

Спецификация HTML никогда не разрешала этот тег, но браузеры его поддерживают и обязаны поддерживать дальше.

#### Когда использовалось

Им приклеивали союзы, предлоги и единицы измерения к соседнему слову.

#### Пример

```html
Современные технологии достигли
<nobr>такого уровня…</nobr>
кластеризации усилий.
```

<iframe title="Тег nobr" src="demos/nobr/" height="320"></iframe>

#### Чем заменить

Для коротких текстов, когда нужно соединить пару слов или символов, можно использовать неразрывный пробел `&nbsp;` или узкий неразрывный пробел `&#8239;`:

```html
В&nbsp;вашей корзине товаров на&nbsp;12&#8239;000&nbsp;₽
```

Мнемоника `&thinsp;` для склейки не подходит. Она даёт обычный узкий пробел, и на нём браузер может перенести строку. У узкого неразрывного пробела мнемоники нет, поэтому его записывают кодом `&#8239;`.

Для остальных случаев есть свойство [`white-space`](/css/white-space/) со значением `nowrap`:

```html
Современные технологии достигли
<span style="white-space: nowrap">такого уровня…</span>
кластеризации усилий.
```

Для больших объёмов текста удобнее программы-типографы. Они сами расставляют неразрывные пробелы. Например, [типограф Артемия Лебедева](https://www.artlebedev.ru/typograf/) или [другой онлайн-типограф](https://www.typograf.ru).

### `<strike>` — зачёркнутый текст

#### Когда использовалось

Чтобы показать, что текст больше не актуален, например старую цену.

#### Пример

```html
Распродажа: <strike>1200</strike> 990 ₽
```

#### Чем заменить

Для текста, который больше не актуален, есть тег [`<s>`](/html/s/). Старая цена — как раз такой случай:

```html
Распродажа: <s>1200 ₽</s> 990 ₽
```

Также можно отметить купленное в списке покупок:

```html
Список покупок:
<ol>
  <li><s>Молоко</s></li>
  <li><s>Хлеб</s></li>
  <li><s>Яйца</s></li>
  <li>Сыр</li>
</ol>
```

Список покупок:

1. ~~Молоко~~
2. ~~Хлеб~~
3. ~~Яйца~~
4. Сыр

Скринридеры обычно не сообщают, что текст зачёркнут. Если это важно, добавьте пояснение, например [визуально скрытый](/a11y/content-hidden/) текст «старая цена».

Если же нужно показать правку документа, то есть что из текста удалили и что добавили, подойдут теги [`<del>`](/html/del/) и [`<ins>`](/html/ins/):

```html
<p>Встреча пройдёт <del>в среду</del> <ins>в четверг</ins>.</p>
```

## Блочные элементы

### `<applet>` — встраиваемый Java-апплет

#### Когда использовалось

В 90-е и нулевые браузер почти не умел исполнять сложные программы. Тег `<applet>` позволял встроить в страницу целую программу со своим интерфейсом, написанную на Java.

#### Пример

```html
<applet code="game.class" archive="game.zip" height="250" width="350">
  <param name="difficulty" value="easy">
  <p>Извините, у вас не установлена Java,
    или ваш браузер не поддерживает встраиваемые Java-апплеты.</p>
</applet>
```

#### Чем заменить

Ни один современный браузер не запускает Java-апплеты. Плагины, через которые работала Java, браузеры удалили к концу 2018 года. Только Internet Explorer 11 запускал их дольше. Тег `<applet>` браузеры теперь считают неизвестным элементом и показывают его содержимое как обычную разметку.

Прямой замены нет: Java-апплет нельзя запустить ни через `<applet>`, ни через [`<object>`](/html/object/). Программу придётся переписать на JavaScript или запускать в [эмуляторе Java на WebAssembly](https://cheerpj.com/).

### `<bgsound>` — фоновая музыка

#### Когда использовалось

Чтобы музыка играла сама при открытии страницы. Тег поддерживали только Internet Explorer и старая Opera.

В отличие от [`<audio>`](/html/audio/), `<bgsound>` не показывал кнопок управления: стоп, пауза, громкость. Этим злоупотребляли: музыка играла сразу, и выключить её было нечем.

#### Пример

```html
<bgsound src="sound2.mid" loop="infinite">
```

#### Чем заменить

Используйте `<audio>` с атрибутом `controls`. Включить звук сразу при загрузке, как делал `<bgsound>`, скорее всего, не получится. Браузеры обычно блокируют автозапуск со звуком, пока пользователь не взаимодействовал с сайтом, например не кликнул по странице.

### `<center>` — центрирование контента

Тег до сих пор популярен в вёрстке писем. Почтовые клиенты могут не поддерживать стили или вырезать их. Тогда содержимое центрируют тегом `<center>` или атрибутом `align` у ячеек таблицы.

#### Когда использовалось

Для выравнивания содержимого по центру родительского блока.

#### Пример

```html
<center>Мама, смотри — я в центре!</center>
```

#### Чем заменить

Текст центрирует свойство [`text-align`](/css/text-align/) со значением `center`, а блок фиксированной ширины — [`margin`](/css/margin/) со значением `0 auto`.

```html
<div class="title-center">Мама, смотри — я в центре!</div>

<div class="parent">
  <div class="child">
    Этот вложенный блок отцентрирован по горизонтали.
  </div>
</div>
```

```css
.title-center {
  text-align: center;
}

.parent {
  width: 500px;
  border: solid;
}

.child {
  margin: 0 auto;
  width: 400px;
  height: 400px;
  border: solid;
}
```

### `<marquee>` — бегущая строка

Внутри `<marquee>` содержимое бесконечно движется: по горизонтали, по вертикали или отскакивая от краёв. Спецификация HTML так и не разрешила этот тег, хотя браузеры обязаны его показывать.

#### Когда использовалось

Для бегущих новостей, объявлений и рекламных баннеров.

#### Пример

```html
<marquee>Этот текст будет двигаться справа налево</marquee>

<marquee direction="up">
  Этот текст будет двигаться снизу вверх
</marquee>

<marquee
  direction="down"
  width="250"
  height="200"
  behavior="alternate"
  style="border: solid"
>
  <marquee behavior="alternate">
    Этот текст будет отражаться от стенок
  </marquee>
</marquee>
```

<iframe title="Тег marquee" src="demos/marquee/" height="340"></iframe>

#### Чем заменить

Современных аналогов нет, но анимацию можно сымитировать на CSS.

```html
<div class="marquee">
  <div class="marquee__inner">
    <span class="marquee__content">Showreel</span>
    <span class="marquee__content" aria-hidden="true">Showreel</span>
    <span class="marquee__content" aria-hidden="true">Showreel</span>
    <span class="marquee__content" aria-hidden="true">Showreel</span>
  </div>
</div>
```

Копии нужны, чтобы за уходящим за край текстом сразу ехал следующий и в строке не было пустого места. Скринридер прочитает только первую: у остальных стоит [`aria-hidden="true"`](/a11y/aria-hidden/).

```css
.marquee {
  position: relative;
  overflow: hidden;
  --offset: 20vw;
  --move-initial: calc(-25% + var(--offset));
  --move-final: calc(-50% + var(--offset));
}

.marquee__inner {
  width: fit-content;
  display: flex;
  position: relative;
  transform: translate3d(var(--move-initial), 0, 0);
  animation: marquee 5s linear infinite;
  animation-play-state: paused;
}

.marquee__content {
  font-size: 10vw;
  padding: 0 2vw;
}

.marquee:hover .marquee__inner {
  animation-play-state: running;
}

@keyframes marquee {
  0% {
    transform: translate3d(var(--move-initial), 0, 0);
  }

  100% {
    transform: translate3d(var(--move-final), 0, 0);
  }
}

@media (prefers-reduced-motion: reduce) {
  .marquee:hover .marquee__inner {
    animation-play-state: paused;
  }
}
```

Анимация воспроизводится при наведении курсора. Если запустить её сразу, понадобится кнопка паузы: этого требует тот же критерий 2.2.2 WCAG.

### `<param>` — параметры для вложенных объектов

Тег `<param>` передавал настройки плагину, который встраивали через `<object>`: имя файла, автозапуск, цвет фона.

#### Когда использовалось

Во времена популярности плагинов вроде Flash, Java-апплетов и ActiveX-компонентов.

#### Пример

```html
<object
  data="movie.swf"
  type="application/x-shockwave-flash"
  width="400"
  height="300"
>
  <param name="autoplay" value="true">
  <param name="loop" value="false">
  <param name="quality" value="high">
</object>
```

#### Чем заменить

Плагинов в браузерах больше нет, и спецификация HTML перенесла `<param>` в список устаревших элементов. Сам `<object>` остался: им всё ещё встраивают картинки, PDF и HTML-страницы.

Для задач, которые раньше решали плагины, есть другие инструменты:

- для видео — [`<video>`](/html/video/) с атрибутами `controls` и `loop`, а чтобы видео запускалось само, — `autoplay` вместе с `muted` и `playsinline`;
- для встраивания другого HTML — [`<iframe>`](/html/iframe/);
- для сложных плееров — библиотеки на JavaScript, например [Video.js](https://videojs.com/).

Если вы не встраиваете музейный Flash или Java-апплет в архивной версии Internet Explorer 6, `<param>` вам не нужен.

## Вывод

Устаревшие теги ведут себя по-разному:

- `<applet>`, `<blink>` и `<bgsound>` браузеры сейчас считают неизвестными элементами;
- `<marquee>`, `<center>`, `<font>` и `<nobr>` браузеры по-прежнему обязаны показывать, но разметка с ними не проходит валидацию.

В новом коде их использовать нельзя. Для оформления есть CSS, а для смысла — семантические теги, например `<s>` вместо `<strike>`. Если встретили такой тег в проекте, замените его на современный аналог или подумайте, нужен ли этот эффект вообще.
