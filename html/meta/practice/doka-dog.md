🛠 Мобильные браузеры находят в тексте номера телефонов, адреса почты и даты и превращают их в ссылки: позвонить, написать письмо, добавить событие в календарь. Иногда они ошибаются и делают ссылкой артикул, номер заказа или длинное число.

Номера телефонов отключает отдельный метатег:

```html
<meta name="format-detection" content="telephone=no">
```

В сети встречаются советы дописать сюда `email=no` и `date=no`. Это не поможет: WebKit, движок Safari, разбирает в этом теге только `telephone`, а Chrome не читает его вовсе.

Ссылки, которые расставил WebKit, получают атрибут `x-apple-data-detectors`. По нему их можно вернуть к виду обычного текста:

```css
a[x-apple-data-detectors] {
  color: inherit;
  text-decoration: none;
}
```
