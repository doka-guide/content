## Кратко

`<html>` — корневой элемент документа. Внутри него лежит всё содержимое страницы: элементы [`<head>`](/html/head/) и [`<body>`](/html/body/).

## Пример

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    ...
  </head>
  <body>
    ...
  </body>
</html>
```

## Как пишется

Тег `<html>` ставят сразу после [`<!DOCTYPE>`](/html/doctype/).

### Атрибуты

Своих атрибутов в стандарте HTML у `<html>` нет, но можно использовать любые [глобальные атрибуты](/html/global-attrs/). Самый важный из них — `lang`.

Ещё у `<html>` встречаются два атрибута, но обычной странице они не нужны:

- `xmlns` — атрибут для XHTML-документов. В обычном HTML он ни на что не влияет.
- `prefix` — атрибут не из стандарта HTML, а из RDFa. Это расширение, которое размечает данные на странице для программ. Его ставят ради Open Graph: `<html lang="ru" prefix="og: https://ogp.me/ns#">`. Заголовок и картинку для репостов задают [метатеги](/html/meta/) Open Graph в `<head>`. Соцсети читают их и без `prefix`.

## Подсказки

💡 Атрибут `lang` сообщает язык текста на странице. По нему скринридер выбирает голос и произношение, а браузер — шрифт и правила [переносов](/css/hyphens/).

От `lang` зависят и кавычки, которые браузер рисует сам, например вокруг [`<q>`](/html/q/): в английском тексте `“”`, в русском `«»`. Кавычки, набранные в тексте, браузер не меняет.

Ещё `lang` помогает браузеру решить, предлагать ли перевод страницы. Chrome сверяет `lang` с языком, который сам определил по тексту. Если `lang` указан неверно, например `de` на русской странице, браузер может не предложить перевод.

`lang` не меняет направление текста. Для арабского, иврита и других языков, на которых пишут справа налево, добавьте атрибут [`dir="rtl"`](/html/global-attrs/#dir).
