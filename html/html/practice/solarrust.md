🛠 Программисты не пишут базовую разметку страницы руками. Чаще всего её разворачивают из сокращения в [Emmet](https://emmet.io/). Он встроен в VS Code и WebStorm.

Напишите `!` и нажмите <kbd>Tab</kbd>. Вместо восклицательного знака можно написать `html:5`.

В базовой разметке «от Emmet» есть и тег `<html lang="en">`. Для русскоязычной страницы поменяйте значение на `ru`. В VS Code язык по умолчанию задаёт настройка `"emmet.variables": { "lang": "ru" }`.

🛠 Тегу `<html>` можно добавить атрибут `class`. Через JS удобно ставить на `<html>` класс, который описывает состояние всей страницы. От этого класса уже зависят стили.

Например, на всех сайтах с попапами я подключаю скрипт. Он ставит тегу `<html>` класс `_popup-opened`, пока попап открыт. Страница под попапом не должна прокручиваться, поэтому я пишу такой код:

```css
html._popup-opened body {
  overflow: hidden;
}
```

Попап открывается → скрипт добавляет класс `_popup-opened` для `<html>` → срабатывает стиль для `<body>` → попап закрывается → скрипт убирает класс → страница снова прокручивается.

Если попап сделан на [`<dialog>`](/html/dialog/) и открывается через `showModal()`, класс не нужен. Тот же стиль задают селекторы [`:has()`](/css/has/) и `:modal`:

```css
html:has(dialog:modal) body {
  overflow: hidden;
}
```
