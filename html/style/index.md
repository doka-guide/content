## Кратко

Внутри тега `<style>` пишут CSS-правила для страницы. Тут вы описываете, как будут выглядеть заголовки, ссылки, обычный текст и другие элементы страницы.

## Пример

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      p {
        color: red;
      }
    </style>
  </head>
  <body>
    <p>This is my paragraph.</p>
  </body>
</html>
```

## Как пишется

Тег `<style>` ставят в [`<head>`](/html/head/), где находится информация, которую не видит пользователь.

```html
<head>
  <style>
    /* Стили */
  </style>
</head>
```

Ещё `<style>` можно поставить первым дочерним элементом блока внутри [`<body>`](/html/body/). Чтобы стили действовали только внутри родителя `<style>`, оберните правила в [`@scope`](/css/scope/) без селектора:

```html
<div class="card">
  <style>
    @scope {
      p {
        color: #FF8630;
      }
    }
  </style>
  <p>Этот абзац станет оранжевым, а абзацы вне карточки — нет.</p>
</div>
```

Без `@scope` стили из `<body>` всё равно сработают, но на весь документ. Правило [`@import`](/css/import/) в таком `<style>` использовать нельзя.

Во всех браузерах `@scope` появился только в 2026 году, в Firefox — с версии 146. В старых браузерах правила внутри `@scope` не сработают.

## Атрибуты

- `media` — укажите этот атрибут, чтобы стили из тега применялись только при определённых условиях. Значение — [медиазапрос](/css/media/), как в правиле `@media`. Например, `media="print"` включит стили только при печати, а `media="(width <= 500px)"` — только когда окно браузера не шире 500 пикселей. Если атрибута нет, стили применяются везде, как с `media="all"`.

  Тип устройства в медиазапросе может быть одним из трёх:
  - `all` — все устройства;
  - `print` — принтер и режим предпросмотра печати;
  - `screen` — все устройства, кроме принтера: экраны компьютеров, телефонов, планшетов.

  ⚠️ Типы `aural`, `braille`, `embossed`, `handheld`, `projection`, `speech`, `tty` и `tv` устарели. Браузеры их распознают, но такие медиазапросы никогда не срабатывают. Вместо типа устройства проверяйте возможности: ширину окна — `(width <= 500px)`, наведение курсора — `(hover: hover)`, тёмную тему — `(prefers-color-scheme: dark)`.
- `nonce` — случайная строка. Она разрешает стили из тега при строгой политике безопасности контента (CSP). Сервер генерирует новое значение для каждого ответа и повторяет его в заголовке `Content-Security-Policy`: `style-src 'nonce-…'`. Если вписать в HTML постоянное значение, защита перестанет работать.
- `blocking` — со значением `render` браузер не отрисует страницу, пока не загрузит файлы, которые тег подключает через `@import`. Тег `<style>` из HTML-кода и так задерживает отрисовку. Атрибут нужен, когда `<style>` в `<head>` вставляет скрипт. Работает в Chrome, Edge и Safari.
- `type` — устаревший атрибут. Раньше писали `type="text/css"`, сейчас его можно не указывать.

## Ещё примеры

Попробуем сделать основной заголовок на странице ещё крупнее, зададим шрифт Roboto и чёрный цвет:

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>Кулинарный блог Марфы</title>
    <style>
      h1 {
        font-size: 40px;
        font-family: "Roboto", sans-serif;
        color: #000000;
      }
    </style>
  </head>
  <body>
    <h1>Как испечь настоящие круассаны?</h1>
  </body>
</html>
```

А в этом примере цвет и фон текста в абзаце будут меняться в зависимости от ширины окна:

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      p {
        background-color: #FFFFFF;
        color: #663613;
      }
    </style>
    <!-- Будет работать, когда окно не шире 500px -->
    <style media="(width <= 500px)">
      p {
        background-color: #FF8630;
        color: #000000;
      }
    </style>
  </head>
  <body>
    <p>Чтобы испечь настоящие круассаны...</p>
  </body>
</html>
```

Чтобы увидеть смену цвета на компьютере, откройте демку в отдельной вкладке и сузьте окно.
