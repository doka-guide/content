🛠 Лайфхак: вставьте стили для верхней части сайта прямо в `<head>`, в тег `<style>`. Так браузер быстрее покажет первый экран, особенно на телефоне или при медленном интернете.

То есть туда можно встроить стили шапки сайта, верхних баннеров, заголовков — то, что видно сразу при открытии. Так мы сразу показываем пользователю контент, а остальная часть сайта догружается.

Остальные стили подключим отдельным файлом. Обычный [`<link rel="stylesheet">`](/html/link/) в `<head>` задерживает отрисовку, пока файл не загрузится. Поэтому подключим файл с `media="print"`: браузер не ждёт стили для печати. Когда файл загрузится, `onload` поменяет значение на `all`, и стили применятся:

```html
<link
  rel="stylesheet"
  href="styles.css"
  media="print"
  onload="this.media='all'"
>
<noscript>
  <link rel="stylesheet" href="styles.css">
</noscript>
```

Обработчик `onload` — это JavaScript. Если JavaScript выключен, стили подключит запасной `<link>` из [`<noscript>`](/html/noscript/).

При строгой политике безопасности контента (CSP) браузер не запустит обработчик из атрибута. Тогда стили останутся только для печати, и `media` нужно менять из подключённого скрипта.
