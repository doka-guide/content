🛠 Поскольку картинка — строчный элемент, под ней остаётся немного пустого места. Картинка стоит на базовой линии строки, а под базовой линией строка оставляет место для свисающих частей букв, например у «р» и «у». Иногда это место сильно мешает.

Убрать это место просто:

- сделай картинку блочной ([`display: block`](/css/display/));
- если картинка выше строки, выровняй её по другой линии строки: [`vertical-align`](/css/vertical-align/) со значением `top`, `middle` или `bottom`.

У маленьких картинок вроде иконок блок всё равно останется высотой со строку. С `top` и `middle` лишнее место останется снизу, с `bottom` — сверху. Убрать его поможет только `display: block`.

🛠 Частый дизайнерский приём — наложение поверх картинки цветного оверлея. И если для фоновой картинки это можно сделать при помощи псевдоэлемента, то с тегом `<img>` этот приём не сработает. Пока картинка показывается, браузеры не рисуют у неё [`::before`](/css/before/) и [`::after`](/css/after/). Так уж устроены _замещаемые_ элементы, вроде `<iframe>`, `<video>`, `<img>` и других.

Чтобы сделать оверлей, заверни картинку в блок-обёртку и задай псевдоэлемент обёртке.

```html
<div class="image-wrapper">
  <img
    class="image"
    src="sleeping-dogs.png"
    alt="Три собаки, все закрыли глаза и спят"
  >
</div>
```

```css
.image-wrapper {
  position: relative;
  width: 50%;
}

.image-wrapper::after {
  content: "";
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background-color: rgb(46 154 255 / 20%);
}

.image {
  display: block;
  width: 100%;
}
```
