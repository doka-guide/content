## Кратко

Атрибут `hidden` прячет элемент, который сейчас не нужен на странице. Например, сообщение об ошибке, пока ошибки нет, или форму входа, когда пользователь уже вошёл.

Браузер прячет такой элемент через [`display: none`](/css/display/) в своих стилях по умолчанию. Элемент пропадает из раскладки и для скринридеров. Другие способы работают иначе:

- [`visibility: hidden`](/css/visibility/) оставляет место под элементом;
- при [`opacity: 0`](/css/opacity/) элемент остаётся доступным для скринридеров и кликов.

## Пример

```html
<p hidden>
  Этот текст будет не виден на странице.
  Хотя элемент в разметке будет!
</p>
```

## Как пишется

Атрибут `hidden` [глобальный](/html/global-attrs/), его можно добавить к любому тегу. Обычно его пишут без значения.

У атрибута три состояния:

- `hidden` без значения, `hidden=""` или любое другое значение — элемент спрятан;
- `hidden="until-found"` — элемент спрятан, но браузер покажет его, если пользователь найдёт текст из него поиском по странице или перейдёт к нему по якорю;
- атрибута нет — элемент виден.

Значений `true` и `false` у атрибута нет, поэтому `hidden="false"` тоже прячет элемент. Чтобы показать элемент из JavaScript, удалите атрибут или задайте [`element.hidden = false`](/js/element-hidden/).

Не прячьте атрибутом `hidden` то, что должно быть доступно хотя бы [скринридерам](/a11y/screenreaders/). Исключение — подсказки, на которые ссылается [`aria-describedby`](/a11y/aria-describedby/): скринридер их прочитает. Другие способы скрыть содержимое и их разницу разбираем в статье «[Как скрыть содержимое от скринридеров](/a11y/content-hidden/)».

## Как понять

Атрибут говорит браузеру, что содержимое сейчас не относится к странице. Не используйте его, чтобы просто спрятать элемент на одном размере экрана: для этого есть [медиазапросы](/css/media/).

`hidden="until-found"` удобен для блоков, которые раскрываются по клику: поиск по странице находит текст даже в свёрнутых разделах. Когда пользователь находит текст или переходит по якорю, браузер удаляет атрибут и показывает содержимое.

Браузер прячет не весь элемент, а только его содержимое: вместо `display: none` он ставит `content-visibility: hidden`. Поэтому отступы, рамка и фон элемента остаются на странице. В отличие от обычного `content-visibility: hidden`, такое содержимое поиск по странице находит.

На строчные элементы `content-visibility` не действует. Поэтому `<span hidden="until-found">` не прячется, его текст остаётся на виду. Чтобы спрятать так строчный элемент, задайте ему `display: block` или `display: inline-block`.

Перед тем как показать содержимое, браузер запускает на элементе событие `beforematch`. Слушайте его, чтобы обновить состояние кнопки, которая раскрывает блок. Например, поставить ей [`aria-expanded="true"`](/a11y/aria-expanded/):

```html
<button id="toggle" aria-expanded="false" aria-controls="answer">
  Показать ответ
</button>
<div id="answer" hidden="until-found">
  Ответ, который найдёт поиск по странице.
</div>
```

```js
const toggle = document.getElementById('toggle');
const answer = document.getElementById('answer');

answer.addEventListener('beforematch', () => {
  toggle.setAttribute('aria-expanded', 'true');
});
```

Если хватает [`<details>`](/html/details/), берите его: он раскрывается при поиске сам, без JavaScript.

`until-found` работает в Chrome 102 и Firefox 148 и новее. В Safari 26.2 поддержка частичная: браузер раскрывает элемент, но прокручивает страницу к найденному тексту с ошибками. В браузерах без поддержки элемент просто спрятан.

## Подсказки

💡 Ваши стили сильнее встроенных стилей браузера. Если задать элементу `display: flex` через класс, атрибут `hidden` перестанет его прятать. Чтобы этого не было, добавьте в стили правило:

```css
[hidden] {
  display: none !important;
}
```

Учтите, что это правило сломает `hidden="until-found"`: такой элемент спрятан не через `display`. Если используете `until-found`, исключите его из селектора: `[hidden]:not([hidden="until-found" i])`. Флаг `i` нужен, потому что браузер не различает регистр в значении атрибута.

💡 Появление и скрытие элемента можно анимировать. Понадобятся три вещи:

- начальные стили появления в [`@starting-style`](/css/starting-style/);
- конечные стили скрытия у `[hidden]`;
- значение `allow-discrete` для `display` в [`transition`](/css/transition/): оно оставляет элемент видимым на время перехода и переключает `display` на `none` в конце.

```css
.toast {
  transition: opacity 0.3s, display 0.3s allow-discrete;
}

.toast[hidden] {
  opacity: 0;
}

@starting-style {
  .toast {
    opacity: 0;
  }
}
```

Скрытие так анимируется в Chrome 117 и Safari 18 и новее. Firefox пока прячет элемент сразу.

💡 Содержимое спрятанного элемента остаётся в HTML-коде страницы. Его видят поисковые роботы, и его может прочитать любой, кто откроет код. Не прячьте так секретные данные.
