## Кратко

`<iframe>` — это контейнер, который позволяет вставить на страницу другой HTML-документ, со своего сайта или с чужого. Часто этот документ интерактивный — например, карта, видео или пост из соцсети. Сайт может запретить встраивать себя, тогда вместо содержимого во фрейме будет ошибка или пустое место.

Этот контейнер обычно называют фреймом. Внешний вид фрейма и его положение на странице можно задать через CSS.

## Пример

С помощью такого нехитрого кода можно встроить карту размером 560 на 400 пикселей на любую страницу:

```html
<iframe
  title="Карта с адресом офиса"
  width="560"
  height="400"
  loading="lazy"
  allow="fullscreen"
  src="https://yandex.ru/map-widget/v1/-/CBFkaYSE0A"
>
</iframe>
```

## Как понять

`<iframe>` можно представить как «окно», через которое на вашей странице можно увидеть любое содержимое, в том числе с других сайтов. Это значит, что если карту, видео, пост или другой элемент удалят с оригинального сайта, он пропадёт и с вашей страницы. Останется только пустое место или надпись вроде «Контент недоступен».

Встроить документ можно по ссылке через атрибут `src` или целиком его HTML-кодом через `srcdoc`.

## Как пишется

Часто сервисы, например карты или соцсети, сами генерируют код `<iframe>`. Его останется только добавить в свой код.

Контейнер `<iframe>...</iframe>` нужно всегда закрывать.

## Атрибуты

`src` — URL-адрес документа, который вы встраиваете.

`srcdoc` — позволяет встроить HTML-код целиком, так что браузеру не придётся загружать сам документ по ссылке. Картинки, стили и скрипты внутри него браузер всё равно загрузит. С этим атрибутом браузер не смотрит на `src`.

Документ из `srcdoc` получает источник вашей страницы. Источник — это протокол, домен и порт, подробнее в статье «[CORS](/tools/cors/)».

`sandbox` — ограничивает действия и функции встраиваемого документа. Если просто указать атрибут `sandbox`, браузер включит сразу все ограничения. Значения снимают их. Значения перечисляют через пробел в любом порядке: `sandbox="allow-scripts allow-forms"`.

<details>
  <summary>Возможные значения атрибута <code>sandbox</code></summary>

- `allow-forms` — позволяет отправлять формы внутри `<iframe>`.
- `allow-downloads` — позволяет скачивать файлы, например по ссылке с атрибутом `download`.
- `allow-modals` — позволяет показывать системные окна браузера: [`alert()`](/js/alert/), [`confirm()`](/js/confirm/), [`prompt()`](/js/prompt/), окно печати и вопрос перед уходом со страницы.
- `allow-orientation-lock` — позволяет фиксировать горизонтальное или вертикальное положение экрана.
- `allow-pointer-lock` — позволяет захватывать курсор через Pointer Lock API: курсор пропадает, а страница получает движения мыши. Так управляют камерой в играх.
- `allow-popups` — разрешает открывать новые окна и вкладки через [`window.open()`](/js/window-open/) или ссылки с `target="_blank"`.
- `allow-popups-to-escape-sandbox` — работает вместе с `allow-popups`: новые окна, которые открыл фрейм, не получают ограничений `sandbox`.
- `allow-presentation` — разрешает показывать содержимое на втором экране, например на проекторе, через Presentation API.
- `allow-same-origin` — оставляет документу во фрейме его настоящий источник. Без этого значения источник у документа особый, ни с чем не совпадающий. Скрипты фрейма не могут прочитать куки и [`localStorage`](/js/local-storage/), а запросы к своему серверу браузер считает запросами на чужой сайт.
- `allow-scripts` — позволяет выполнять скрипты. Новые окна при этом всё равно запрещены, если нет `allow-popups`.
- `allow-top-navigation` — позволяет фрейму открыть другую страницу во всём окне, вместо вашей.
- `allow-top-navigation-by-user-activation` — то же, что `allow-top-navigation`, но только после действия пользователя, например клика.
- `allow-top-navigation-to-custom-protocols` — разрешает открывать адреса, которые браузер передаёт другим программам, например `mailto:` или `tg:`.

</details>

`name` — имя фрейма. Пригодится, чтобы создать ссылку, по которой новая страница будет открываться в нужном фрейме.

`allow` — даёт фрейму разрешения на возможности браузера: например, `fullscreen` для полноэкранного режима, `camera`, `microphone` или `geolocation`. Несколько разрешений перечисляют через точку с запятой: `allow="fullscreen; camera"`.

`allowfullscreen` — старый способ разрешить полноэкранный режим. Он разрешает его документу с любого источника, как `allow="fullscreen *"`. А `allow="fullscreen"` разрешает его только источнику из `src`.

`loading` — со значением `lazy` браузер загрузит фрейм, только когда тот приблизится к вьюпорту (видимой области страницы). Так страница загружается быстрее. Если в браузере выключен JavaScript, `lazy` не работает и фрейм загружается сразу.

`width` и `height` — размеры фрейма в пикселях.

`referrerpolicy` — задаёт, какой адрес вашей страницы получит сервер фрейма в [HTTP-заголовке](/tools/http-protocol/) `Referer`. По умолчанию чужой сайт видит только источник, без пути.

Атрибуты `frameborder` и `scrolling` устарели:

- Рамку вместо `frameborder` настраивают в CSS свойством [`border`](/css/border/).
- Прокруткой внутри фрейма управляет CSS вложенного документа. CSS чужой страницы не поменять, поэтому стандарт всё ещё требует от браузеров понимать `scrolling="no"`.

## Подсказки

💡 Не используйте вместе `allow-scripts` и `allow-same-origin`, если документ во фрейме с того же источника, что и ваша страница. Тогда его скрипт может убрать у фрейма атрибут `sandbox` и перезагрузить себя уже без ограничений. Это касается и `srcdoc`.

💡 Фрейм загружает ещё одну страницу внутри вашей. Его содержимое может загрузиться позже, чем ваш сайт.

💡 В `<iframe>` стоит добавить атрибут `title` на случай, если пользователь не видит страницу и пользуется скринридером. Например, так:

```html
<iframe
  title="Страница в Википедии о лемурах"
  src="https://ru.wikipedia.org/wiki/Обыкновенные_лемуры"
>
</iframe>
```
