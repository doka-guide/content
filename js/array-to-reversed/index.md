## Кратко

Метод `toReversed()` возвращает новый массив с элементами в обратном порядке: первый элемент становится последним, а последний — первым. Исходный массив не меняется.

## Пример

```js
const planets = ['Меркурий', 'Венера', 'Земля', 'Марс']
const reversedPlanets = planets.toReversed()
console.log(reversedPlanets)
// ['Марс', 'Земля', 'Венера', 'Меркурий']

// Исходный массив не изменился
console.log(planets)
// ['Меркурий', 'Венера', 'Земля', 'Марс']
```

## Как пишется

Метод вызывают у массива: `array.toReversed()`. Аргументов у него нет.

Возвращает новый массив с элементами в обратном порядке.

## Как понять

У массивов уже есть метод [`reverse()`](/js/array-reverse/), который тоже разворачивает массив. Но `reverse()` меняет исходный массив и возвращает ссылку на него же, а не копию. Потренируемся на кошках:

```js
const cats = ['Мурка', 'Кузя', 'Мурр', 'Чеширский кот']
const reversedCats = cats.reverse()
console.log(reversedCats)
// ['Чеширский кот', 'Мурр', 'Кузя', 'Мурка']

// Исходный массив изменился!
console.log(cats)
// ['Чеширский кот', 'Мурр', 'Кузя', 'Мурка']

// Это один и тот же массив
console.log(reversedCats === cats)
// true
```

Поэтому `toReversed()` выбирают, когда исходный массив ещё нужен в прежнем порядке. Например, массив пришёл в функцию аргументом, и его используют где-то ещё. Или в массиве лежит список товаров, а в обратном порядке его нужно только показать.

Если в исходном массиве лежат объекты, то новый массив содержит ссылки на те же объекты, а не их копии. Поэтому изменения объекта в исходном массиве будут видны в новом массиве и наоборот:

```js
const versions = [
  { name: 'ES6' }, { name: 'ES2016' }, { name: 'ES2017' }
]
const result = versions.toReversed()
console.log(result)
// [{name: 'ES2017'}, {name: 'ES2016'}, {name: 'ES6'}]

// Изменим элемент исходного массива
versions[0].year = 2015

console.log(versions)
// [{name: 'ES6', year: 2015}, {name: 'ES2016'}, {name: 'ES2017'}]

// Изменения тоже видны в новом массиве
console.log(result)
// [{name: 'ES2017'}, {name: 'ES2016'}, {name: 'ES6', year: 2015}]
```

Подробнее об особенностях копирования объектов можно прочитать в статье «[Поверхностное и глубокое копирование](/js/shallow-or-deep-clone/)».

## Подсказки

💡 Если в массиве есть незаполненные элементы, то `toReversed()` вернёт [`undefined`](/js/undefined/) как значение для всех незаполненных элементов:

```js
const poets = ['Эмили Дикинсон']
poets[3] = 'Роберт Фрост'

console.log(poets)
// ['Эмили Дикинсон', <2 empty items>, 'Роберт Фрост']

console.log(poets.toReversed())
// ['Роберт Фрост', undefined, undefined, 'Эмили Дикинсон']
```

💡 Метод `toReversed()` появился в ES2023. С июля 2023 года он работает во всех основных браузерах, а в [Node.js](/tools/nodejs/) — с версии 20. Если вашему коду нужно работать в старых окружениях, используйте копию массива: `[...array].reverse()`. Другой вариант — полифил, то есть код, который добавляет метод туда, где его нет.
