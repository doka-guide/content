🛠 В новом коде используйте только `let` или `const`. По умолчанию объявляйте переменные через `const`. Если значение понадобится изменить, замените `const` на `let`.

🛠 Называйте переменные так, чтобы можно было легко понять, что в них хранится. Например:

```js
const url = 'https://doka.guide'

const now = Date.now()

const user = {
  name: 'John',
  age: 30,
}
```

Исключение — счётчики в циклах `for`: их обычно называют одной буквой, `i`, `j` и так далее.

Имена переменных часто состоят из нескольких слов. Чтобы их было легко читать, в JavaScript используют «верблюжью нотацию» (_camelCase_). В ней каждое слово, начиная со второго, пишется с заглавной буквы:

```js
const fullName = 'John Doe'

const arrayOfNumbers = [1, 2, 3]
```

Имена констант с заранее известными значениями, например настроек приложения, принято писать в _screaming_snake_case_. В этой нотации все слова пишут заглавными буквами и разделяют символом `_`.

```js
const BASE_URL = 'https://doka.guide'

const PORT = 3000

const UNAUTHORIZED_CODE = 401
```
