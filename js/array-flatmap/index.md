## Кратко

Метод `flatMap()` применяет функцию к каждому элементу массива и убирает из результата один уровень вложенности. Это как вызвать [`map()`](/js/array-map/), а затем [`flat()`](/js/array-flat/), только за один шаг.

Метод появился в стандарте ES2019.

## Пример

### Получить плоский список из сложной структуры

Представим, что у нас есть список заказов пользователей, из которого мы хотим понять, какие товары заказывают:

```js
const orders = [
  {
    id: 1,
    products: [
      { name: 'Чизкейк', price: 1.99 },
      { name: 'Бисквит', price: 4.99 },
    ]
  },
  {
    id: 2,
    products: [
      { name: 'Шоколад', price: 5.59 },
      { name: 'Зефир', price: 8.99 },
    ]
  }
];
```

Одним из решений будет сначала дважды вызвать метод `map()`, а затем сделать массив плоским с помощью метода `flat()`.

Сначала воспользуемся методом `map()`:

```js
orders.map(
  (order) => order.products.map(product => product.name)
);
```

Получим следующий результат:

```js
[['Чизкейк', 'Бисквит'], ['Шоколад', 'Зефир']]
```

Обратите внимание на вложенность массивов, нам нужно от неё избавиться. Для этого применим метод `flat()`:

```js
orders
  .map((order) => order.products.map((product) => product.name))
  .flat();
```

```js
['Чизкейк', 'Бисквит', 'Шоколад', 'Зефир']
```

Другое решение этой задачи — сразу вызвать метод `flatMap()` (ведь статья у нас именно про него):

```js
orders.flatMap(
  (order) => order.products.map(product => product.name)
);
```

Результат тот же:

```js
['Чизкейк', 'Бисквит', 'Шоколад', 'Зефир']
```

### Изменить структуру данных

Представим, что мы пишем корзину для интернет-магазина. Товары в корзине храним в виде массива объектов:

```js
const cart = [
  {
    name: 'Телефон',
    count: 1,
    price: 500,
  },
  {
    name: 'Ноутбук',
    count: 1,
    price: 800,
  }
];
```

Если человек покупает телефон, то нужно добавить зарядное устройство. Для этого вызовем `flatMap()` и будем возвращать массив из телефона и зарядного устройства вместо одного объекта с телефоном.

```js
cart.flatMap(
  (item) => {
    if (item.name === 'Телефон') {
      return [item, {
        name: 'Зарядное устройство',
        count: item.count,
        price: 50,
      }];
    }

    return item;
  }
);
```

`flatMap()` сделает массив плоским, и мы получим массив элементов в корзине:

```js
[
  {
    name: 'Телефон',
    count: 1,
    price: 500,
  }, {
    name: 'Зарядное устройство',
    count: 1,
    price: 50,
  }, {
    name: 'Ноутбук',
    count: 1,
    price: 800,
  },
]
```

Эту же задачу можно решить и другим способом, применив метод [`reduce()`](/js/array-reduce/). Но это отразится на читаемости кода, а этим пренебрегать не стоит!

```js
cart.reduce((list, item) => {
  if (item.name === 'Телефон') {
    list.push(item, {
      name: 'Зарядное устройство',
      count: item.count,
      price: 50,
    });
  } else {
    list.push(item);
  }

  return list;
}, []);
```

## Как пишется

Как и другим похожим методам, `flatMap()` нужно передать колбэк, который возвращает значение.

Колбэк принимает три аргумента:

- `currentValue` — текущий элемент массива;
- `index` — индекс текущего элемента в массиве;
- `array` — массив, который мы перебираем.

Колбэк может вернуть один элемент или массив. Массив `flatMap()` развернёт, и все его элементы попадут в результат. Если вернуть пустой массив, элемент пропадёт из результата. Так можно одновременно отфильтровать и преобразовать данные:

```js
const numbers = [1, -2, 3, -4];

const doubledPositive = numbers.flatMap((n) => n > 0 ? [n * 2] : []);

console.log(doubledPositive);
// [2, 6]
```

`flatMap()` разворачивает только один уровень вложенности. Если колбэк вернёт массив массивов, внутренние массивы останутся как есть:

```js
console.log([1, 2].flatMap((n) => [[n, n * 10]]));
// [[1, 10], [2, 20]]
```

`flatMap()` разворачивает только массивы, то есть значения, для которых [`Array.isArray()`](/js/array-isarray/) вернёт `true`. Массивоподобный объект попадёт в результат целиком, хотя у него есть `length` и индексы:

```js
console.log([1].flatMap(() => ({ length: 1, 0: 'x' })));
// [{ 0: 'x', length: 1 }]
```

Вторым аргументом в `flatMap()` можно передать значение [`this`](/js/function-context/) для колбэка:

```js
const range = { min: 2 };

const fromFunction = [1, 2, 3].flatMap(function (n) {
  return n >= this.min ? [n] : [];
}, range);

console.log(fromFunction);
// [2, 3]
```

[Стрелочные функции](/js/arrow-function/) берут `this` из внешнего кода, а второй аргумент игнорируют:

```js
const filter = {
  min: 2,
  pick(numbers) {
    return numbers.flatMap(
      (n) => n >= this.min ? [n] : [],
      { min: 100 }
    );
  },
};

console.log(filter.pick([1, 2, 3]));
// [2, 3]
```

Стрелочная функция взяла `this` из метода `pick()`, то есть объект `filter`. Так же второй аргумент игнорирует функция, привязанная через [`bind()`](/js/bind-call-apply/).

## Как понять

Метод работает как `map().flat()` с параметром `depth = 1`. Поэтому его используют, когда нужно преобразовать данные и убрать один уровень вложенности.

В отличие от связки `map().flat()`, этот метод не создаёт промежуточный массив массивов, поэтому расходует чуть меньше памяти. По скорости они почти не отличаются. Если колбэк возвращает новый массив на каждый элемент, обычный цикл с [`push()`](/js/array-push/) справится быстрее.

### Разница между `map()` и `flatMap()`

Возьмём массив с данными о местоположении. Нужно получить координаты:

```js
const allActivities = [
  { title: 'Офис', coordinates: [50.123, 3.291] },
  { title: 'Спортзал', coordinates: [1.238, 4.292] },
];

const mappedCoordinates = allActivities.map(
  (activity) => activity.coordinates
);

const flatMappedCoordinates = allActivities.flatMap(
  (activity) => activity.coordinates
);
```

Теперь взглянем на результаты с применением `map()`:

```js
[[50.123, 3.291], [1.238, 4.292]]
```

И на результат с `flatMap()`:

```js
[50.123, 3.291, 1.238, 4.292]
```

### Разница между `flat()` и `flatMap()`

Метод `flat()` возвращает новый плоский массив. Глубину задают аргументом, поэтому он справится и с несколькими уровнями вложенности.

Метод `flatMap()` применяет функцию к каждому элементу и убирает ровно один уровень вложенности. Два в одном.

Исходный массив оба метода не меняют.
