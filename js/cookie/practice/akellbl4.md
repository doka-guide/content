🛠 Есть куки, которые нельзя прочитать или записать из JavaScript. Это куки с параметром `HttpOnly`, их устанавливает только сервер.

Обычно в таких куках хранят чувствительную информацию, например токены для авторизации. Браузер сам прикладывает такую куку к запросам на сервер, а сервер её проверяет. Код на JavaScript о ней не знает и узнаёт, авторизован ли пользователь, только по ответу сервера.
