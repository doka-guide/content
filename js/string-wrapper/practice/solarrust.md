🛠 Вызывайте `trim()` до того, как сравнивать или сохранять значение из текстового поля. Пробел, который пользователь случайно скопировал вместе с логином, иначе попадёт в базу, и потом этот логин не найдётся:

```js
const input = document.querySelector('input[name="login"]')
const login = input.value.trim()
```

Поле `type="email"` убирает пробелы по краям само, а `type="text"` и `<textarea>` оставляют их в значении.
