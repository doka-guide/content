🛠 Для работы с промисами используйте `async/await` вместо цепочек [`then()`](/js/promise-then/).

Такой код легче отлаживать.

🛠 Для последовательных асинхронных шагов используйте цикл [`for...of`](/js/for-of/). `await` ставит на паузу только свою функцию, поэтому [`forEach()`](/js/array-foreach/) не ждёт асинхронный колбэк:

```js
// Не ждёт: все запросы стартуют сразу
ids.forEach(async (id) => {
  await fetch(`/api/items/${id}`)
})

// Ждёт каждый запрос по очереди
for (const id of ids) {
  await fetch(`/api/items/${id}`)
}
```

🛠 Если нужно дождаться промиса на верхнем уровне обычного скрипта, подключите [скрипт](/html/script/) как модуль: `<script type="module">`.

Модуль ведёт себя иначе, чем обычный скрипт:

- выполняется после разбора страницы, как скрипт с `defer`;
- работает в [строгом режиме](/js/use-strict/);
- его переменные не попадают в `window`.

Если модуль не подходит, оберните код в асинхронную функцию и сразу вызовите её:

```js
(async () => {
  try {
    const response = await fetch('/api/user')
    console.log(await response.json())
  } catch (err) {
    console.error(err)
  }
})()
```
