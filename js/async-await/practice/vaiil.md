🛠 Используйте [`await Promise.all([...])`](/js/promise-all/), чтобы дождаться результатов нескольких независимых асинхронных функций.

С `async/await` код становится последовательным: ожидаем выполнения одной асинхронной функции и лишь после запускаем другую. В примере ниже `getNews()` запросит новости, только когда `getUser()` вернёт пользователя:

```js
async function getUser() {
  // Возвращает информацию о пользователе
}

async function getNews() {
  // Возвращает список новостей
}

const user = await getUser()
const news = await getNews()
```

Но если вызвать `getNews()`, не дожидаясь `getUser()`, результат в большинстве случаев придёт быстрее. Оба запроса стартуют в момент вызова, а `Promise.all()` дожидается их вместе. Результат получаем, как и раньше, через `await`:

```js
const [user, news] = await Promise.all([
  getUser(),
  getNews()
])
```

Учтите, что `Promise.all()` отклонит промис при первой же ошибке, и результаты остальных запросов потеряются. Сами запросы при этом не отменяются. Если нужны результаты всех запросов, даже когда часть завершилась ошибкой, используйте [`Promise.allSettled()`](/js/promise-allsettled/).

🛠 Не смешивайте синтаксис `async/await` и `then()` внутри одной функции: так код легче читать и поддерживать.
