🛠 Как предотвратить удаление данных из хранилища?

Браузер хранит данные в одном из двух режимов: «временном» или «постоянном».

По умолчанию все хранилища (`localStorage`, `IndexedDB`, `Cache API` и т. д.) работают во временном режиме. В нём браузер может сам удалить данные сайта, если это не помешает пользователю. Например, когда на устройстве мало места.

В постоянном режиме браузер не удалит данные, даже если места не хватает. Очистить хранилище может сам пользователь. Чтобы включить этот режим, сайт должен [запросить постоянное хранение](https://web.dev/articles/persistent-storage).

🛠 Как браузер очищает хранилище?

Когда браузер сам освобождает место, он должен удалить наименее ценные для пользователя данные.

Браузеры на основе Chromium освобождают место последовательно: сначала удаляют данные сайтов, которые пользователь давно не открывал, и продолжают, пока не освободится достаточно места.

Firefox начинает очистку, когда заканчивается свободное место на диске или данные всех сайтов превышают общий лимит браузера. Порядок удаления такой же, как в браузерах на основе Chromium: сначала давно не открытые сайты.

Safari [удаляет все данные сайта](https://webkit.org/blog/10218/full-third-party-cookie-blocking-and-more/), которые записал JavaScript, по правилу 7 дней из раздела «Кратко». У веб-приложений, добавленных на экран «Домой», свой счётчик: он считает дни использования самого приложения, поэтому активное веб-приложение данные не теряет.

С Safari 17 все хранилища одного источника вместе могут занять до 60% диска. Лимит самого `localStorage` при этом прежний: около 5 МБ. Постоянный режим Safari разрешает по своим правилам, например если сайт открыт как веб-приложение с экрана «Домой» ([подробнее в блоге WebKit](https://webkit.org/blog/14403/updates-to-storage-policy/)).

🛠 Как включить режим постоянного хранения данных?

Методы для работы с хранилищем лежат в `navigator.storage`. Постоянный режим включает метод `persist()`:

```js
(async () => {
  // Пытается переключиться на постоянный режим хранения.
  // Возвращает true, если получилось, и false, если нет.
  const persistModeEnabled = await navigator.storage?.persist()
})()
```

Чтобы не вызывать `persist()` лишний раз, сначала проверьте режим методом `persisted()`. Он вернёт `true`, если хранилище уже в постоянном режиме:

```js
(async () => {
  // Включён ли постоянный режим с самого начала
  const isPersisted = await navigator.storage?.persisted()

  if (isPersisted) {
    console.info('Хранилище уже в постоянном режиме.')
    return
  }

  // Удалось ли переключиться на постоянный режим
  const persistModeEnabled = await navigator.storage?.persist()

  if (persistModeEnabled) {
    console.info('Браузер включил постоянный режим.')
    return
  }

  console.info('Браузер не разрешил постоянный режим хранения.')
})()
```

Chrome и Safari решают сами, разрешить ли постоянный режим, например по тому, как часто пользователь заходит на сайт. Firefox спрашивает разрешение у пользователя.
