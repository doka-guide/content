## Кратко

Метод `toSpliced()` удаляет, добавляет или заменяет элементы массива, начиная с указанного индекса. Исходный массив не меняется: метод возвращает новый.

## Пример

Удалим два элемента, начиная с индекса 3:

```js
const months = [
  'Май', 'Июнь', 'Июль', 'Август', 'Сентябрь', 'Октябрь'
];
const newMonths = months.toSpliced(3, 2);

console.log(newMonths);
// ['Май', 'Июнь', 'Июль', 'Октябрь']
```

Заменим два последних элемента:

```js
const versions = [
  'ES2016', 'ES2017', 'ES2018', 'неизвестно', 'неизвестно'
];
const newVersions = versions.toSpliced(-2, 2, 'ES2019', 'ES2020');

console.log(newVersions);
// ['ES2016', 'ES2017', 'ES2018', 'ES2019', 'ES2020']
```

## Как пишется

Метод `toSpliced()` принимает аргументы:

- индекс, позиция начала изменений в исходном массиве;
- количество удаляемых элементов в исходном массиве;
- остальные аргументы — элементы, добавляемые к массиву.

Отрицательный индекс считается с конца массива: `-1` — последний элемент, `-2` — предпоследний.

Если индекс выходит за границы массива:

- отрицательный индекс меньше минус длины массива (`-array.length`) — изменения начинаются с 0-го элемента исходного массива;
- индекс больше или равен длине массива — метод добавит элементы в конец массива и ничего не удалит.

Если количество удаляемых элементов не передать, метод удалит все элементы от индекса до конца массива. Если количество меньше или равно 0, метод ничего не удалит.

Метод `toSpliced()` возвращает новый массив.

## Как понять

Метод `toSpliced()` удаляет, добавляет или заменяет несколько элементов подряд. Исходный массив при этом не меняется. Это удобно, когда исходные данные трогать нельзя: например, массив, который использует другая часть кода.

Добавим три элемента, начиная с индекса 1, и ничего не удалим:

```js
const days = ['ПН', 'ПТ'];
const workDays = days.toSpliced(1, 0, 'ВТ', 'СР', 'ЧТ');
console.log(workDays);
// ['ПН', 'ВТ', 'СР', 'ЧТ', 'ПТ']

// Исходный массив не изменился
console.log(days);
// ['ПН', 'ПТ']
```

В отличие от метода [`splice()`](/js/array-splice/), `toSpliced()` не меняет исходный массив и не возвращает удаляемые элементы:

```js
const numbers = [10, 20, 30, 40];
const newNumbers = numbers.toSpliced(1, 2);
console.log(newNumbers, numbers);
// [10, 40] [10, 20, 30, 40]

// А вот как работает splice()
const deletedNumbers = numbers.splice(1, 2);
console.log(deletedNumbers, numbers);
// [20, 30] [10, 40]
```

## Подсказки

💡 Пустые ячейки массива `toSpliced()` заменяет на `undefined`.

Заменим в массиве последний элемент:

```js
const colors = ['crimson', , , 'purple'];
console.log(colors.toSpliced(-1, 1, 'blueviolet'));
// ['crimson', undefined, undefined, 'blueviolet']

console.log(colors);
// ['crimson', <2 empty items>, 'purple']
```

💡 Метод `toSpliced()` делает [поверхностную копию](/js/shallow-or-deep-clone/) массива. Если элементы — объекты, новый массив содержит ссылки на те же объекты. Изменения такого объекта видны в обоих массивах:

```js
const skills = [
  {name: 'HTML'}, {name: 'CSS'}, {name: 'PHP'}
];

// Добавим новый элемент
const result = skills.toSpliced(2, 0, {name: 'JS'});
console.log(result);
// [
//  {name: 'HTML'}, {name: 'CSS'}, {name: 'JS'}, {name: 'PHP'}
// ]

// Изменим элемент исходного массива
skills[0].year = 2005;
console.log(skills);
// [{name: 'HTML', year: 2005}, {name: 'CSS'}, {name: 'PHP'}]

// Изменения также видны в новом массиве
console.log(result);
// [
//  {name: 'HTML', year: 2005}, {name: 'CSS'},
//  {name: 'JS'}, {name: 'PHP'}
// ]
```

💡 Метод `toSpliced()` появился в ES2023. С июля 2023 года он работает во всех основных браузерах, а в [Node.js](/tools/nodejs/) — с версии 20. Если вашему коду нужно работать в старых окружениях, скопируйте массив и вызовите у копии `splice()`:

```js
const numbers = [1, 2, 3];
const newNumbers = [...numbers];
newNumbers.splice(1, 0, 1.5);

console.log(newNumbers);
// [1, 1.5, 2, 3]
```

Другой вариант — полифил, то есть код, который добавляет метод туда, где его нет.
