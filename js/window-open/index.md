## Кратко

Метод `open()` объекта `window` открывает адрес в новой вкладке, во всплывающем окне или в уже существующем окне или фрейме по имени. Метод возвращает объект открытого окна, через который с ним можно работать.

## Пример

Откроем страницу в новом всплывающем окне размером 500 на 400 пикселей по клику на кнопку. Настройка `noopener` не даст открытой странице получить доступ к нашей:

```js
const button = document.querySelector('button')

button.addEventListener('click', () => {
  window.open(
    'https://doka.guide/',
    '_blank',
    'popup,width=500,height=400,noopener'
  )
})
```

## Как пишется

```js
const newWindow = window.open(url, target, windowFeatures)
```

Все три параметра необязательные.

`url` — строка с абсолютным или относительным [URL](/tools/url/). Если адрес не передать, откроется пустая страница `about:blank`.

`target` — строка с именем окна, в котором откроется адрес. Принимает те же значения, что и [атрибут `target` у тега `<a>`](/html/a/): имя окна или [фрейма](/html/iframe/) либо одно из ключевых слов `_blank`, `_self`, `_parent`, `_top`. По умолчанию `_blank`.

Если окно с таким именем уже есть, адрес откроется в нём, а не в новом окне. Если при этом не передать адрес, окно останется как было.

`windowFeatures` — строка с настройками нового окна. Настройки перечисляют через запятую в формате `имя=значение`. Для логических настроек значение можно не писать: `popup` значит то же, что `popup=true`.

Настройки, которые работают в современных браузерах:

- `popup` — открыть всплывающее окно вместо новой вкладки. `popup=no` или `popup=0` попросит вкладку. Окончательно решает браузер: например, пользователь может попросить в настройках открывать всё во вкладках.
- `width` или `innerWidth`, `height` или `innerHeight` — ширина и высота содержимого окна в пикселях. Слишком маленький размер браузер увеличит, обычно до 100 пикселей.
- `left` или `screenX`, `top` или `screenY` — отступ окна от левого и верхнего края экрана в пикселях.
- `noopener` — новое окно не получит доступ к текущему через `window.opener`. Метод в этом случае вернёт [`null`](/js/null-primitive/), если только `target` не равен `_self`, `_parent` или `_top`. Такое окно потом не найти по имени: следующий вызов с тем же именем откроет новое окно.
- `noreferrer` — браузер не передаст новой странице адрес текущей в [HTTP-заголовке](/tools/http-protocol/) `Referer`. Эта настройка включает и `noopener`.

Всплывающее окно браузер откроет, даже если `popup` не указан: для этого хватит любой другой настройки, кроме `noopener` и `noreferrer`. Например, `'left=100'` тоже откроет всплывающее окно. Без настроек адрес откроется в новой вкладке.

Метод возвращает объект окна. Если окно не открылось, метод вернёт `null`.

## Как понять

Браузеры блокируют новые окна, которые сайт открывает сам. После действия пользователя, например [клика](/js/element-click/), браузер на несколько секунд разрешает открыть одно окно. Поэтому вызывайте `window.open()` прямо в обработчике.

Если вызвать метод после долгого запроса к серверу или второй раз за один клик, браузер окно заблокирует и метод вернёт `null`. Открыть адрес в уже существующем окне по имени можно и без действия пользователя.

Если адрес станет известен только после [запроса к серверу](/js/fetch/), откройте пустое окно сразу, а адрес задайте после ответа. Настройку `noopener` такому окну передавать нельзя: метод вернёт `null`, и сменить адрес будет нечем.

```js
button.addEventListener('click', async () => {
  const newWindow = window.open(
    '',
    '_blank',
    'popup,width=500,height=400'
  )
  const response = await fetch('/api/link')
  const { url } = await response.json()

  if (newWindow) {
    newWindow.location.href = url
  }
})
```

Через возвращённый объект можно управлять новым окном. Если страница открыта с того же источника (протокол, домен и порт совпадают), доступно всё её содержимое:

```js
const newWindow = window.open(
  '',
  'note',
  'popup,width=300,height=200'
)

if (newWindow) {
  newWindow.document.body.textContent =
    'Привет из основного окна!'
}
```

Если страница с другого источника, её содержимое недоступно. С таким окном можно:

- сменить адрес, записав новое значение в [`location.href`](/js/window-location/) (прочитать адрес нельзя);
- закрыть окно методом [`close()`](/js/window-close/);
- проверить через свойство `closed`, закрыто ли оно;
- отправить сообщение через `postMessage()`.

Вторым аргументом `postMessage()` передавайте источник получателя, а не `'*'`. Окно могло уйти на другой сайт, и тогда сообщение достанется ему.

```js
newWindow.postMessage('Привет!', 'https://example.com')
```

Открытое окно тоже получает доступ к странице, которая его открыла, через `window.opener`. Если вы открываете чужой сайт, передайте `noopener`: так чужая страница не сможет, например, подменить адрес исходной вкладки на фишинговый. Ссылки с `target="_blank"` все основные браузеры открывают так по умолчанию, а `window.open()` — нет.

Связь с окном может пропасть совсем. Объект окна у вас останется, но как только новая страница загрузится, `closed` станет `true`, а `postMessage()` и `close()` перестанут работать. Код, который ждёт закрытия окна по `closed`, решит, что пользователь его закрыл. Так ломаются, например, окна входа через сторонние сервисы и окна оплаты.

За это отвечает заголовок `Cross-Origin-Opener-Policy`. Связь пропадёт, если:

- у двух страниц разные значения этого заголовка;
- обе страницы приходят с `same-origin`, но у них разные источники.

Есть исключение: если ваша страница приходит с `same-origin-allow-popups`, а страница в окне приходит без `Cross-Origin-Opener-Policy`, связь сохранится. Поэтому, если на вашей странице не работают окна входа, замените `same-origin` на `same-origin-allow-popups`.

## Подсказки

💡 Для обычных переходов используйте ссылку `<a>`. Пользователь сам решит, где её открыть, а скринридер объявит её как ссылку. Ссылка `<a href="#" onclick="window.open(…)">` ломает и то, и другое.

💡 Проверяйте результат `window.open()`, прежде чем обращаться к новому окну. Если окно не открылось, вместо объекта будет `null`.

💡 Настройки `menubar`, `toolbar`, `location`, `status`, `scrollbars` и `resizable` больше не скрывают панели: адресная строка и полосы прокрутки видны всегда. Спецификация учитывает их только при выборе между вкладкой и всплывающим окном. Чтобы попросить всплывающее окно, используйте `popup`.
