🛠 Всегда подписывайтесь на события с помощью `addEventListener()`. Так вы избежите доработок, когда потребуется повесить несколько обработчиков на одно и то же событие.

🛠 Если нужно обработать все события определённого типа на странице, вызовите метод `addEventListener()` у объекта `window` с настройкой `{ capture: true }`. Тогда обработчик сработает на стадии захвата, раньше обработчиков на элементах. Он поймает и многие события, которые не всплывают, например `focus`:

```js
// Обрабатываем все клики на странице
window.addEventListener('click', function () {
  alert('clicked')
}, { capture: true })
```

Исключение — событие [`load`](/js/event-load/) у элементов, например у картинок, скриптов, стилей и фреймов. До `window` оно не доходит, поэтому ловите его на `document` с той же настройкой.

🛠 Если вы не используете объект события в обработчике, то можно не указывать его в списке параметров обработчика. Вместо `function (event) {…}` пишите `function() {…}`.

🛠 Всплытие событий — важный концепт, поэкспериментируйте с ним, чтобы лучше в нём разобраться.
