🛠 Если нужно установить фокус на элемент сразу после загрузки страницы, то лучше добавить атрибут `autofocus` прямо в вёрстку. Браузер сам переведёт фокус на элемент. Используйте его осторожно: фокус переносится без действия пользователя, и пользователь скринридера пропустит текст перед полем.

```html
<form action="/apply" method="POST">
  <label>
    Имя:
    <input type="text" name="name" autofocus>
  </label>

  <label>
    Почта:
    <input type="email" name="email">
  </label>

  <button type="submit">Подать заявку</button>
</form>
```

🛠 Чтобы программно убрать фокус с элемента, вызовите метод [`blur()`](/js/element-blur/) или переместите фокус на другой элемент. Без JavaScript фокус пропадает, когда пользователь кликает мышью мимо элемента.

🛠 За обводку элемента в фокусе отвечает CSS-свойство [`outline`](/css/outline/). Не скрывайте её, если на сайте нет другого способа выделить элемент в фокусе. Если обводка мешает при кликах мышью, стилизуйте фокус через псевдокласс [`:focus-visible`](/css/focus-visible/): браузер применяет его, когда фокус нужно видеть, например при навигации с клавиатуры.
