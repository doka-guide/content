## Кратко

Метод `with()` возвращает копию массива, в которой заменён один элемент. Исходный массив не меняется.

## Пример

Получим копию массива, в которой `'white'` заменён на `'blue'`:

```js
const colors = ['red', 'green', 'white']
const newColors = colors.with(2, 'blue')
console.log(newColors)
// ['red', 'green', 'blue']

// Исходный массив остался прежним
console.log(colors)
// ['red', 'green', 'white']
```

То же самое с отрицательным индексом:

```js
const colors = ['red', 'green', 'white']
const newColors = colors.with(-1, 'blue')
console.log(newColors)
// ['red', 'green', 'blue']

// Исходный массив остался прежним
console.log(colors)
// ['red', 'green', 'white']
```

## Как пишется

Метод вызывают у массива: `array.with(index, value)`. Он принимает два аргумента:

- индекс элемента, который нужно заменить;
- новое значение элемента.

Индекс элемента может быть:

- Неотрицательный — для доступа к элементам от начала массива. Например, `0` — индекс первого элемента.
- Отрицательный — для доступа к элементам с конца массива. Например, `-1` — индекс последнего элемента, `-2` — предпоследнего и так далее.

`with()` возвращает новый массив с заменённым элементом.

Если массив не пустой, вызов `with()` без аргументов не приведёт к ошибке. Это равнозначно вызову `with(0, undefined)`:

```js
const routes = ['/home', '/settings', '/about']
const newRoutes = routes.with()
console.log(newRoutes)
// [undefined, '/settings', '/about']
```

Допустимый индекс — от `-array.length` до `array.length - 1`. Если индекс за этими границами, `with()` выбросит [ошибку](/js/errors/) `RangeError`:

```js
const authors = ['Ф. Кафка', 'Д. Сэлинджер']

try {
  console.log(authors.with(2, 'К. Воннегут'))
} catch (err) {
  console.error('Поймали ошибку! Вот она:', err.message)
}
// Поймали ошибку! Вот она: Invalid index : 2
// Текст сообщения зависит от браузера
```

## Как понять

Напишем функцию, которая меняет первый элемент массива с помощью `with()`:

```js
const updateFirstItem = (array, value) => {
  return array.with(0, value)
}
```

Проверим, как она работает, и убедимся, что исходный массив остался прежним.

```js
const bears = ['гризли', 'полярный', 'бурый']
const result = updateFirstItem(bears, 'панда')
console.log(result)
// ['панда', 'полярный', 'бурый']

console.log(bears)
// ['гризли', 'полярный', 'бурый']
```

А вот для сравнения функция, меняющая значение первого элемента в исходном массиве:

```js
const updateFirstItemDanger = (array, value) => {
  const result = array
  result[0] = value
  return result
}
```

Эта функция вернёт тот же результат, но изменит исходный массив:

```js
const bears = ['гризли', 'полярный', 'бурый']
const result = updateFirstItemDanger(bears, 'панда')
console.log(result)
// ['панда', 'полярный', 'бурый']

console.log(bears)
// Ой, куда пропал мишка гризли!
// ['панда', 'полярный', 'бурый']
```

`updateFirstItemDanger()` не копирует массив, а создаёт ещё одну ссылку на него же. Подробнее об этом можно почитать в статье «[Хранение по ссылке и по значению](/js/ref-type-vs-value-type/#mutacii-i-neizmenyaemost)».

Функция меняет данные, которые определены вне её. Такое изменение называют побочным эффектом. Функция с побочным эффектом не [чистая](/tools/fp/#chistye-funkcii-i-pobochnye-effekty): её труднее предсказать и тестировать. Обычно такого кода лучше избегать.

## Подсказки

💡 `with()` не меняет (не мутирует) исходный массив. Но копия поверхностная: объекты внутри массива остаются общими для исходного массива и копии.

💡 С `with()` удобно менять элементы с конца массива, например последний. Без него нужно скопировать массив и вычислить индекс последнего элемента через `length - 1`:

```js
const words = ['первый', 'второй', 'третий']
const lastIndex = words.length - 1

// Создаём копию массива
const newWords = [...words]

newWords[lastIndex] = 'последний'

console.log(newWords)
// ['первый', 'второй', 'последний']
```

С `with()` хватит одного вызова:

```js
const words = ['первый', 'второй', 'третий']
console.log(words.with(-1, 'последний'))
// ['первый', 'второй', 'последний']
```

💡 `with()` можно встроить в цепочку вызовов методов массива. Каждый метод в цепочке получает результат работы предыдущего. Например:

```js
const days = ['', 'пн', 'вт', 'ср', 4]

console.log(
  days
    .filter(item => typeof item === 'string')
    .with(0, 'вс')
    .map(item => item.toUpperCase())
)
// ['ВС', 'ПН', 'ВТ', 'СР']
```

💡 Когда `with()` создаёт копию, он заменяет все незаполненные элементы на `undefined`:

```js
const numbers = [0, , 11, 20, , 30]

console.log(numbers.with(2, 10))
// [0, undefined, 10, 20, undefined, 30]
```

💡 Метод `with()` появился в ES2023. С июля 2023 года он работает во всех основных браузерах, а в [Node.js](/tools/nodejs/) — с версии 20.

💡 Если вашему коду нужно работать в старых окружениях, замените элемент в копии массива. Другой вариант — полифил, то есть код, который добавляет метод туда, где его нет.

В копии массива отрицательный индекс не сработает: `copy[-1]` создаст свойство `'-1'`, а последний элемент останется прежним. Поэтому сначала переведите отрицательный индекс в неотрицательный:

```js
const array = ['ночь', 'улица', 'фонарь']
const index = -1
const copy = [...array]

copy[index < 0 ? index + array.length : index] = 'январь'

console.log(copy)
// ['ночь', 'улица', 'январь']
```

В отличие от `with()`, этот код не проверяет границы массива. Индекс за пределами массива не вызовет ошибку. Слишком большой индекс удлинит копию и может оставить в ней пустые места, а слишком маленький создаст свойство вроде `'-2'`.
