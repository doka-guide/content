## Кратко

Свойство `display` задаёт тип отображения элемента: как он ведёт себя среди соседей и как раскладывает дочерние элементы.

По умолчанию почти все элементы в HTML блочные или строчные. Но в вёрстке часто нужно сделать элемент не строчным, а блочным. И наоборот.

Кроме значений `block` (блочное отображение) и `inline` (строчное отображение) есть смешанное значение `inline-block` (строчно-блочное отображение).

Бывают и другие значения, например, `flex`, `grid`, `table-cell`.

## Пример

Частая ситуация: на странице нужно показать иконки соцсетей со ссылками на аккаунты.

```html
<div class="wrapper">
  <ul class="social">
    <li class="social__item twitter">
      <a href="https://twitter.com/username" class="social__link" aria-label="Twitter"></a>
    </li>
    <li class="social__item fb">
      <a href="https://www.facebook.com/username" class="social__link" aria-label="Facebook"></a>
    </li>
    <li class="social__item youtube">
      <a href="https://www.youtube.com/@username" class="social__link" aria-label="YouTube"></a>
    </li>
  </ul>
</div>
```

Обратите внимание, что внутри ссылок ничего не написано. Показываем не название соцсети, а иконку с логотипом. Иконку выводим фоном. Название для скринридеров передаём через [`aria-label`](/a11y/aria-label/).

Выстраиваем пункты списка в ряд, а не друг под другом:

```css
.social__item {
  display: inline-block;
}
```

Превращаем ссылки из строчных в блочные элементы. После этого можем задать высоту и ширину:

```css
.social__link {
  display: block;
  width: 30px;
  height: 30px;
  background-repeat: no-repeat;
  background-position: center;
  background-size: contain;
}
```

Задаём иконки фоном для каждой отдельной ссылки:

```css
.twitter {
  background-image: url(twitter-round-blue.png);
}

.fb {
  background-image: url(fb-square-blue.png);
}

.youtube {
  background-image: url(youtube-red-square.png);
}
```

По умолчанию ссылки строчные. Строчному элементу нельзя задать размеры ([`width`](/css/width/) и [`height`](/css/height/)): его ширина зависит от содержимого. Наши ссылки пустые, поэтому ширина у них нулевая, и фоновую иконку не видно.

У пунктов списка по умолчанию `display: list-item`. Это блочный элемент с маркером. Маркер есть только у `list-item`, поэтому после `inline-block` маркеры пропадают.

## Как понять

У каждого HTML-элемента свой тип отображения по умолчанию. Например, ссылки нужны для оборачивания слов и фраз. Значит, они должны быть строчными, чтобы не разорвать окружающий текст.

Но иногда стандартное отображение не подходит для задачи, и его нужно поменять.

## Как пишется

Пишем имя свойства `display`, а после двоеточия — значение ключевым словом.

Значения свойства, которые встречаются в работе чаще всего:

- `none` — полностью скрывает элемент: он не занимает места на странице, и скринридеры его не читают. Из HTML-разметки элемент при этом не удаляется.
- `block` — элемент ведёт себя как блочный.
- `inline` — элемент ведёт себя как строчный.
- `inline-block` — элемент стоит в строке, как строчный, но ему можно задать ширину и высоту, как блочному.
- `flex` — элемент становится флекс-контейнером, ведёт себя как блочный, а дочерние элементы становятся флекс-элементами. Подробнее — в статье «[Гайд по flexbox](/css/flexbox-guide/)».
- `grid` — элемент становится грид-контейнером. Снаружи грид-контейнер ведёт себя как блочный элемент. Дочерние элементы раскладываются по сетке. Подробнее — в статье «[Гайд по grid](/css/grid-guide/)».

Переключайте значения и смотрите, как меняется раскладка. В демке `block`, `inline` и `inline-block` задаём самим элементам, а `flex` и `grid` — их родителю:

### Двухкомпонентный синтаксис

У привычных однословных значений есть более подробная запись из двух ключевых слов. Первое слово — внешний тип, определяет, как элемент ведёт себя снаружи (как блочный или как строчный). Второе — внутренний, определяет, как ведут себя дочерние элементы:

```css
.element {
  /* Старая запись → новая двухкомпонентная */
  display: block;        /* display: block flow;       */
  display: inline;       /* display: inline flow;      */
  display: inline-block; /* display: inline flow-root; */
  display: flex;         /* display: block flex;       */
  display: inline-flex;  /* display: inline flex;      */
  display: grid;         /* display: block grid;       */
  display: inline-grid;  /* display: inline grid;      */
  display: flow-root;    /* display: block flow-root;  */
}
```

`flow` — обычный поток: дочерние элементы встают друг под другом или в строку, каждый по своему типу. `flow-root` — тот же поток, но с границей: плавающие элементы ([`float`](/css/float/)) изнутри не вылезают наружу, а внешние не заходят внутрь.

Однословная запись никуда не делась, это сокращённая форма. Если указать только внешний тип, браузер добавит внутренний `flow`: `inline` — то же, что `inline flow`. Если указать только внутренний, браузер добавит внешний `block`: `flex` — то же, что `block flex`. Значения `inline-block`, `inline-flex`, `inline-grid` и `inline-table` — тоже краткие формы, но оба типа в них соединены дефисом. Они появились раньше двухкомпонентного синтаксиса.

Двухкомпонентный синтаксис поддерживается во всех основных браузерах с 2023 года (Firefox — с 2019).

Внешний тип определяет, как элемент ведёт себя в обычном потоке, где элементы идут друг за другом в порядке разметки. С `block` элемент становится блочным: занимает отдельную строку, а соседние блоки оказываются выше и ниже. С `inline` — строчным: идёт в одной строке с текстом и другими строчными элементами. Внутри флекс- и грид-контейнера внешний тип дочерних элементов не работает: каждый из них становится флекс- или грид-элементом.

В двухкомпонентной записи внешний и внутренний тип задаются отдельно. Например, меню — блочный флекс-контейнер на всю ширину строки, а список тегов — строчный флекс-контейнер, он стоит в одной строке с текстом:

```css
.menu {
  display: block flex;
}

.tags {
  display: inline flex;
}
```

Дочерние элементы строчного флекс-контейнера остаются флекс-элементами. Но без заданной ширины строчный флекс-контейнер сжимается по содержимому, и свободного места в нём не остаётся. Поэтому [`justify-content`](/css/justify-content/) ничего не меняет.

## Подсказки

💡 Раньше свойство `display` нельзя было анимировать: оно дискретное, у него нет промежуточных значений между `none` и `block`. Теперь это можно обойти при помощи `transition-behavior: allow-discrete`, подробности — в статье про [`transition`](/css/transition/#cherez-display-i-transition-behavior-allow-discrete). Но поддержка пока неполная: переход для `display` работает в Chrome и Edge с версии 117 и в Safari с версии 18. Firefox поддерживает и `allow-discrete`, и [`@starting-style`](/css/starting-style/), но переход для `display` в нём не работает: элемент появляется плавно, а исчезает мгновенно.

💡 Значение по умолчанию у каждого HTML-элемента своё. Если не уверены — загляните в «Инструменты разработчика» в браузере.
