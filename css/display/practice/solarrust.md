🛠 Если выстроить блоки в строку через `display: inline-block`, между ними появятся небольшие зазоры. Это обычные пробелы: браузер отрисовывает переносы строк из разметки так же, как пробелы между словами. Раньше эти зазоры прятали хаком: задавали родителю [`font-size: 0`](/css/font-size/). Хак капризный: дочерним элементам приходится возвращать размер шрифта в `px` или `rem`. В `em` и процентах вернуть его не выйдет: ноль на что ни умножай — ноль.

Сейчас хак не нужен. Сделайте родителя флекс-контейнером, а отступ между блоками задайте через [`gap`](/css/gap/). Пробелы между флекс-элементами браузер не отрисовывает, так что отступы будут ровно такими, какие указаны в `gap`. С гридом это тоже работает, только колонки придётся описать в [`grid-template-columns`](/css/grid-template-columns/):

```css
.list {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}
```

В демке три способа рядом: `inline-block`, хак с `font-size: 0` и флекс с `gap`.

🛠 Если выводите иконки соцсетей фоном ссылок, не забудьте подписать каждую ссылку через атрибут [`aria-label`](/a11y/aria-label/). Текста в такой ссылке нет, и скринридер прочитает в лучшем случае адрес из `href`, а в худшем — просто «ссылка».

🛠 Если нужно вывести на страницу данные в виде таблицы, соберите в разметке [настоящую таблицу](/html/tables/). Не превращайте в таблицу через `display: table` элементы, в которых нет табличных данных. Помните про семантику! ☝️

Семантикой в вёрстке называют подбор тегов по смыслу элемента. Прошли эпохи вёрстки на таблицах и дивах. Теперь почти для всего есть отдельный тег. Например, для меню есть тег [`<nav>`](/html/nav/), а для основного контента страницы — [`<main>`](/html/main/).

🛠 Если нужно плавно показать или спрятать элемент, попробуйте анимировать сам `display`. Раньше элемент прятали через [`visibility`](/css/visibility/) и [`opacity`](/css/opacity/) или переключали стили из JavaScript. Сейчас `display` можно указать в [`transition`](/css/transition/#cherez-display-i-transition-behavior-allow-discrete) с ключевым словом `allow-discrete`. Состояние, с которого начинается появление, задайте в [`@starting-style`](/css/starting-style/). Например, покажем подсказку по нажатию на кнопку:

```html
<button class="toggle" type="button" aria-expanded="false" aria-controls="note">
  Показать подсказку
</button>
<p class="note" id="note">Теперь ты читаешь скрытую подсказку! 🎉</p>
```

```css
.note {
  display: none;
  opacity: 0;
  transition:
    opacity 0.35s,
    display 0.35s allow-discrete;
}

.note.is-open {
  display: block;
  opacity: 1;
}

@starting-style {
  .note.is-open {
    opacity: 0;
  }
}
```

```js
const button = document.querySelector('.toggle')
const note = document.querySelector('.note')

button.addEventListener('click', () => {
  const isOpen = note.classList.toggle('is-open')
  button.setAttribute('aria-expanded', isOpen)
  button.textContent = isOpen ? 'Спрятать подсказку' : 'Показать подсказку'
})
```

При скрытии браузер переключит `display: none` только в конце перехода, когда `opacity` доиграет. В отличие от одной `opacity`, спрятанная подсказка не перехватывает клики, а скринридер не читает её, пока она закрыта.

Переход для `display` пока работает не везде. Chrome и Edge его умеют, Safari — с 18-й версии. А Firefox знает `allow-discrete` и `@starting-style`, но `display` не анимирует. В нём и в Safari до 18-й версии подсказка плавно появится, а исчезнет мгновенно. Пользоваться ею это не мешает, так что приём можно смело брать в проект.

Блок `@starting-style` ставьте после основного правила. Специфичность у него обычная, и правило с тем же селектором ниже по коду перебьёт стартовое состояние, и анимация появления не запустится.

🛠 Очень много задач сегодня решает `display: flex`. С его появлением стали реже использовать значение `inline-block` и свойство [`float`](/css/float/). Например, для вертикального выравнивания раньше колдовали с таблицами, [`line-height`](/css/line-height/) и отрицательным [`margin`](/css/margin/), а теперь хватает одного свойства [`align-items`](/css/align-items/). А чтобы прижать два блока к разным сторонам родителя, раньше нужен был `float` и clearfix — псевдоэлемент с `clear: both` в конце родителя. Без него родитель не видит плавающие дочерние элементы и схлопывается. Теперь достаточно написать [`justify-content: space-between`](/css/justify-content/), и два блока встанут по краям родителя 🤗
