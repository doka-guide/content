Дока

Пока шапка стоит на своём месте, она выглядит как обычный блок в потоке.

Начните прокручивать текст. Шапка прилипнет к верхнему краю, и контейнерный запрос это заметит.

В этот момент сработает @container scroll-state(stuck: top). Шапка станет компактнее, получит тень и синюю границу снизу.

Раньше для такого эффекта нужен был JavaScript с IntersectionObserver или обработчиком прокрутки.

Теперь хватает пары строк CSS: position: sticky с top: 0, container-type: scroll-state и сам запрос.

Прокрутите обратно наверх — шапка вернётся в поток, и стили снова станут обычными.
