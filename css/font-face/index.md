## Кратко

Встроенных в операционные системы шрифтов часто не хватает для создания уникального дизайна сайта. Нестандартные шрифты подключают директивой `@font-face`. С её помощью можно подключить и использовать на странице любой шрифт из файла.

Браузер скачает файл шрифта, когда на странице появится текст, который нужно показать этим шрифтом.

## Пример

Подключим к странице шрифт **Inter** и сделаем его основным шрифтом нашего сайта.

```css
@font-face {
  font-family: "Inter";
  src: url("Inter-Regular.woff2") format("woff2");
  font-weight: normal;
  font-display: swap;
}

body {
  font-family: "Inter", sans-serif;
}
```

## Как пишется

Директива `@font-face` по своей «анатомии» отличается от стандартных CSS-правил, где есть селектор и применяемые к нему правила. Основное отличие в том, что селектора здесь нет. Внутри директивы пишут не свойства, а дескрипторы. Они ничего не меняют у элементов, а описывают сам шрифт: как он называется, где лежит файл, какое в нём начертание.

Обязательных дескрипторов два:

1. Название шрифта, которое используем ниже в CSS: дескриптор [`font-family`](/css/font-family/). Название может отличаться от настоящего названия этого шрифта.
1. Ссылки на файлы, из которых браузер может взять шрифт: дескриптор `src`.

Раньше шрифт подключали сразу в нескольких форматах: TTF, EOT, SVG, WOFF. Так каждый браузер находил файл, который он понимает. Сейчас все браузеры поддерживают формат WOFF2. Он сжимает шрифт лучше остальных, поэтому обычно хватает одного WOFF2-файла. WOFF добавляют, только если сайт должен работать в очень старых браузерах. SVG-шрифты подключать не нужно: Chrome убрал их поддержку, а Firefox не поддерживал никогда.

Внешний файл подключают через [`url("ссылка-на-файл")`](/css/url/). Несколько файлов можно подключить, перечислив эти конструкции несколько раз через запятую. Браузер возьмёт первый файл, который сможет загрузить.

После `url()` оставляют браузеру подсказку в виде записи `format("формат-подключаемого-файла")`. Если браузер не знает этот формат, он даже не станет скачивать файл.

Пользователь может сам установить в систему любой нестандартный шрифт, поэтому нужный нам шрифт уже может быть на его компьютере. Если это так, то браузеру будет удобнее и быстрее взять шрифт из системы, чем читать файл.

Для этого в качестве одного или нескольких значений у дескриптора `src` можно указать конструкцию `local("имя-шрифта-в-системе")`. Нужно указывать локальные названия до ссылок на внешние файлы, чтобы браузер, найдя шрифт в системе под таким именем, даже не пошёл загружать и читать внешние файлы.

Полностью полагаться на `local()` не получится. Safari видит только шрифты, которые поставляются вместе с системой, а шрифты, установленные пользователем, игнорирует. Так браузер защищает пользователя от слежки: по набору шрифтов на компьютере можно отличить одного человека от другого. Поэтому ссылку на файл через `url()` указывайте всегда.

На сайте может использоваться один и тот же шрифт, но в разных начертаниях. Например, жирный [`font-weight: bold`](/css/font-weight/) или курсив [`font-style: italic`](/css/font-style/). В этом случае нужно подключить все эти начертания.

Тут есть три подхода.

Первый — использовать разные `@font-face` для подключения разных начертаний шрифта, называя их разными именами. Например, `"Inter Regular"`, `"Inter Bold"` и `"Inter Italic"`. Выглядеть это будет так:

```css
@font-face {
  font-family: "Inter Regular";
  src: local("Inter Regular"),
    local("Inter-Regular"),
    url("Inter-Regular.woff2") format("woff2");
}

@font-face {
  font-family: "Inter Bold";
  src: local("Inter Bold"),
    local("Inter-Bold"),
    url("Inter-Bold.woff2") format("woff2");
}

@font-face {
  font-family: "Inter Italic";
  src: local("Inter Italic"),
    local("Inter-Italic"),
    url("Inter-Italic.woff2") format("woff2");
}
```

Далее, ниже по коду, используем в разных местах разные начертания шрифтов:

```css
body {
  font-family: "Inter Regular", sans-serif;
}

.title {
  font-family: "Inter Bold", sans-serif;
}

.accent {
  font-family: "Inter Italic", sans-serif;
}
```

У этого подхода есть подвох. Каждую такую директиву браузер считает обычным начертанием, потому что `font-weight` и `font-style` в ней не указаны. Если класс `.title` достанется заголовку, который жирный по умолчанию, браузер дорисует жирность поверх уже жирного файла. С курсивом и тегом `<em>` получится то же самое.

Второй — подключить все файлы начертаний, но использовать для них одно и то же имя шрифта, указав дополнительно, для какого стиля и жирности этот файл. Тогда не нужно будет переопределять шрифт для разных элементов, достаточно будет указывать нужный стиль или жирность шрифта.

Говорим браузеру, что эти файлы используем для обычного начертания:

```css
@font-face {
  font-family: "Inter";
  src: local("Inter Regular"),
    local("Inter-Regular"),
    url("Inter-Regular.woff2") format("woff2");
  font-weight: normal;
}
```

Говорим браузеру, что эти файлы используем для жирного начертания:

```css
@font-face {
  font-family: "Inter";
  src: local("Inter Bold"),
    local("Inter-Bold"),
    url("Inter-Bold.woff2") format("woff2");
  font-weight: bold;
}
```

Говорим браузеру, что эти файлы используем для курсива:

```css
@font-face {
  font-family: "Inter";
  src: local("Inter Italic"),
    local("Inter-Italic"),
    url("Inter-Italic.woff2") format("woff2");
  font-style: italic;
}
```

После этого используем в разных местах разные начертания шрифтов:

```css
body {
  font-family: "Inter", sans-serif;
  font-weight: normal;
}

.title {
  font-weight: bold;
}

.accent {
  font-style: italic;
}
```

Третий подход работает с вариативными шрифтами. В одном таком файле лежат все варианты жирности, поэтому отдельные файлы для обычного и жирного начертания не нужны. Inter как раз вариативный: жирность у него меняется от 100 до 900. Курсив у Inter лежит в отдельном вариативном файле. Его подключают вторым `@font-face` с `font-style: italic`.

В `@font-face` вместо одного значения `font-weight` указываем диапазон жирности, которая есть в файле:

```css
@font-face {
  font-family: "Inter";
  src: url("Inter-Variable.woff2") format("woff2");
  font-weight: 100 900;
}
```

Теперь у `font-weight` можно указать любое число из этого диапазона, например `font-weight: 350`. Браузер не будет подделывать начертание, а возьмёт его из файла.

## Подсказки

💡 Пока файл шрифта загружается, браузер решает, показывать ли текст. Этим управляет дескриптор [`font-display`](/css/font-display/). Значение `swap` из примера почти сразу показывает текст запасным шрифтом и подменяет его, когда файл загрузится.

💡 Шрифты можно брать и с другого источника, например с CDN. Тогда сервер должен разрешить такой запрос заголовком `Access-Control-Allow-Origin`, иначе браузер заблокирует файл по правилам безопасности запросов с разными источниками ([CORS](/tools/cors/)). Другой источник — это уже другой протокол, домен или порт. Даже `cdn.example.com` для сайта на `example.com` считается чужим.

💡 `@font-face` сработает, даже если объявить его ниже правил, которые используют этот шрифт. Но принято подключать шрифты в самом начале файла стилей (после всех [`@import`](/css/import/)), чтобы их было легко найти. Если два `@font-face` описывают одно и то же начертание, браузер сначала проверит последнее. Символы, которых в нём нет, он возьмёт из предыдущего.

💡 `@font-face` нельзя вложить в правило с селектором, даже с CSS-вложенностью.

💡 Важно использовать в точности то название подключённого шрифта, которое вы задаёте внутри `@font-face`. Иначе браузер не найдёт шрифт и покажет запасной.
