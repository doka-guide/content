CSS-функция `color()` позволяет указать цвет в конкретном цветовом пространстве.

Можно использовать как значение для любых свойств, где нужен цвет. Например, [`color`](/css/color/), [`border-color`](/css/border-color/) или [`accent-color`](/css/accent-color/).

У функции два способа использования:

- _абсолютное значение_ для указания цвета в цветовом пространстве, отличном от sRGB;
- _относительное значение_ для вычисления нового цвета из исходного.

## Абсолютное значение

В CSS много способов [обозначения цвета](/css/web-colors/) в зависимости от нужного цветового пространства. Цветовых пространств становится всё больше. Пока не для каждого пространства существуют отдельные функции типа `rgb()` или `hsl()`, и некоторые цвета можно описать при помощи `color()`.

Например, цвета из пространства Display P3 можно указать через эту функцию с параметром `display-p3`. P3-цвета можно указывать и через другие функции, например, `oklch()` (подробнее об этом в [статье про OKLCH](https://web-standards.ru/articles/oklch-in-css-why-quit-rgb-hsl/)), однако способ с `color()` проще и нагляднее. Так записывается более яркий аналог цвета `#00bbff`:

```css
.block {
  background-color: color(display-p3 0 0.72 1);
}
```

<aside>

🍏 Display P3 — это одна из реализаций цветового пространства P3, которую разработала Apple для своих дисплеев. Они показывают более насыщенные цвета, чем sRGB.

</aside>

Если ваш монитор поддерживает пространство Display P3, вы увидите разницу в демке.

### Параметры для абсолютного значения

Параметры функции `color()` для абсолютного значения:

1. Цветовое пространство. Ключевое слово для нужного пространства:
  - `srgb`;
  - `srgb-linear`;
  - `display-p3`;
  - `display-p3-linear`;
  - `a98-rgb`;
  - `prophoto-rgb`;
  - `rec2020`;
  - `xyz`;
  - `xyz-d50`;
  - `xyz-d65`.
2. Компоненты цвета, или каналы. Три значения через пробел: число, процент или ключевое слово `none`. Для RGB-пространств `0` и `0%` — минимум компонента, `1` и `100%` — максимум.
3. Альфа-канал (необязательное значение). Позволяет задавать прозрачность цвета. Его пишут после слэша `/`.

Пространство `xyz` — короткая запись `xyz-d65`. Пространство `display-p3-linear` — это Display P3, в котором значения компонентов растут пропорционально яркости. Так же `srgb-linear` устроено для sRGB. Браузеры поддерживают `display-p3-linear` с января 2026 года.

### Пространства и компоненты цвета

Укажем цветовое пространство `a98-rgb` и компоненты цвета `0.29`, `0.73` и `1`. Получится цвет, близкий к P3-цвету из примера выше: он тоже не помещается в sRGB.

```css
.block {
  background-color: color(a98-rgb 0.29 0.73 1);
}
```

А так записывается обычный `#00bbff` в пространстве `srgb-linear`: компоненты `0`, `0.5` и `1`.

```css
.block {
  background-color: color(srgb-linear 0 0.5 1);
}
```

### Альфа-канал

Добавим всем цветам альфа-канал со значением `0.5`, сделаем цвет полупрозрачным:

```css
.block-1 {
  background-color: color(display-p3 0 0.72 1 / 0.5);
}

.block-2 {
  background-color: color(a98-rgb 0.29 0.73 1 / 0.5);
}

.block-3 {
  background-color: color(srgb-linear 0 0.5 1 / 0.5);
}
```

## Относительное значение

Относительное значение пригодится, когда нужно получить новый цвет из исходного: сделать его прозрачнее, темнее или заменить один из компонентов.

### Параметры для относительного значения

Параметры функции `color()`:

1. `from` плюс исходный цвет. Для относительного значения обязательно писать ключевое слово и цвет, который хотим преобразовать.
2. Цветовое пространство. Ключевое слово, указывающее, в какое из цветовых пространств переводим цвет:
  - `srgb`;
  - `srgb-linear`;
  - `display-p3`;
  - `display-p3-linear`;
  - `a98-rgb`;
  - `prophoto-rgb`;
  - `rec2020`;
  - `xyz`;
  - `xyz-d50`;
  - `xyz-d65`.
3. Компоненты цвета. Три значения: ключевое слово компонента, число, процент, `none` или вычисление через `calc()`.
4. Альфа-канал (необязательное значение). В нём указываете прозрачность цвета через слэш `/`.

### Цветовые пространства и компоненты

При относительном значении браузер раскладывает любой цвет на три компонента в выбранном цветовом пространстве. Если в одном из компонентов не нужны вычисления, укажите его в виде буквы:

- `r`, `g` и `b`: для цветовых пространств `srgb`, `srgb-linear`, `display-p3`, `display-p3-linear`, `a98-rgb`, `prophoto-rgb` и `rec2020`;
- `x`, `y` и `z`: для цветовых пространств `xyz`, `xyz-d50` и `xyz-d65`.

За альфа-канал отвечает слово `alpha`. Если в исходном цвете прозрачности нет, `alpha` равно `1`.

### Перевод в другое цветовое пространство

Переведём цвет `hotpink` в цветовое пространство `display-p3` и добавим прозрачность `0.8`:

```css
.block {
  background-color: color(from hotpink display-p3 r g b / 0.8);
}
```

Сам цвет при переводе не меняется, ярче он не станет. Браузер только пересчитывает значения компонентов под новое пространство. Пространство важно, когда вы меняете компоненты: в `display-p3` и `srgb` одна и та же правка даст разный результат.

### Изменение компонентов цвета

Переведём тот же цвет в пространство `a98-rgb`. Первый компонент `r` оставим неизменным, второй `g` заменим на `1`, а третий `b` — на `0`:

```css
.block {
  background-color: color(from hotpink a98-rgb r 1 0 / 0.8);
}
```

Если хотите, можете заменить два, три или все четыре компонента цвета и получить совершенно новый цвет. Но тогда встаёт вопрос: зачем такие сложности?

### `calc()` для вычислений

Можно использовать функцию [`calc()`](/css/calc/) для вычислений внутри `color()`. Затемним всё тот же `hotpink`: умножим каждый компонент на `0.6`.

```css
.block {
  background-color: color(from hotpink srgb calc(r * 0.6) calc(g * 0.6) calc(b * 0.6));
}
```

Важно использовать целые или дробные числа без единиц измерения при вычислениях. Если сложить компонент с `%` или добавить `deg`, браузер посчитает объявление ошибочным и пропустит его.

## Пропущенный компонент

Вместо компонента цвета можно использовать ключевое слово `none`. При отрисовке браузер подставит вместо него `0` с нужными единицами измерения.

Эти две записи приведут к одному результату:

```css
.block {
  color: color(display-p3 0 0.72 1 / 0.5);
  background-color: color(display-p3 none 0.72 1 / 0.5);
}
```

И в этом случае цвет получится одинаковым:

```css
.block {
  color: color(from hsl(none 100% 50%) srgb r g b / 0.8);
  background-color: color(from hsl(0deg 100% 50%) srgb r g b / 0.8);
}
```

Разница между `none` и `0` появляется при смешивании цветов в градиентах, анимациях и [`color-mix()`](/css/color-mix/). Пропущенный компонент браузер берёт у другого цвета. Так можно смешать только синий компонент:

```css
.block {
  background-color: color-mix(
    in srgb,
    color(srgb none none 1),
    color(srgb 1 0.4 0)
  );
}
```

Красный и зелёный компоненты браузер возьмёт у оранжевого цвета, а синий смешает: получится `color(srgb 1 0.4 0.5)`.

## Использование кастомных свойств

Чаще всего в проектах набор цветов хранится в виде переменных. Внутри функции `color()` можно использовать [кастомные свойства](/css/custom-properties/).

Предположим, что есть набор из трёх цветов, и нужно добавить каждому из них альфа-канал:

```css
:root {
  --text-color: white;
  --background-color: #2E9AFF;
  --accent-color: hsl(346 81% 78%);
}

.block {
  color: color(from var(--text-color) srgb r g b / 0.9);
  border: 1px solid color(from var(--accent-color) display-p3 r g b / 0.75);
  background-color: color(from var(--background-color) xyz x y z / 0.2);
}
```

## Проверка поддержки

Абсолютное значение `color()` работает во всех браузерах с мая 2023 года. С ноября 2025 года оно входит в Baseline Widely available, так что фолбэк для него уже не нужен.

Относительное значение с `from` появилось позже: во всех браузерах оно работает с сентября 2024 года. Если ваша аудитория сидит на старых версиях браузеров, оставьте для него запасной цвет.

### Прогрессивное улучшение

Директива [`@supports`](/css/supports/) проверяет, поддерживает ли конкретный браузер новый синтаксис. Когда поддерживает, можно вычислить полупрозрачный вариант цвета из кастомного свойства:

```css
:root {
  --accent-color: hotpink;
}

.block {
  background-color: rgb(255 105 180 / 0.5);
}

@supports (color: color(from red srgb r g b)) {
  .block {
    background-color: color(from var(--accent-color) srgb r g b / 0.5);
  }
}
```

Директива [`@media`](/css/media/) с условием `color-gamut` проверяет, умеет ли экран показывать цвета из пространства P3:

```css
.block {
  color: hotpink;
}

@media (color-gamut: p3) {
  .block {
    color: color(display-p3 1 0.2 0.6);
  }
}
```

### Постепенная деградация

Можно пойти с другого конца и изначально всем показывать цвет, записанный через `color()`. А если синтаксис не поддерживается, то показывать запасной цвет.

```css
.block {
  background-color: rgb(255 105 180 / 0.5);
  background-color: color(from hotpink srgb r g b / 0.5);
}
```

В примере выше, если браузер умеет читать относительное значение, применится второе объявление, поскольку оно ниже по коду. Если браузер с ним не знаком, он откинет его и применит первое объявление с полупрозрачным розовым.

Если внутри `color()` есть [`var()`](/css/var/), такой приём не сработает. Браузер проверяет значение с кастомным свойством только после подстановки. Старый браузер не откинет второе объявление, а сбросит фон в `transparent`. Для цветов из кастомных свойств используйте `@supports`.
