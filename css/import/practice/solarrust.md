🛠 Кроме импорта файлов внутри проекта директиву часто используют, чтобы подключить шрифты с сайта Google Fonts. Это один из предложенных на их сайте вариантов подключения.

```css
@import url("https://fonts.googleapis.com/css2?family=Inter&display=swap");
```

После этого в коде ниже можно использовать подключённый шрифт. Минимум усилий — максимум результата.

Хотя это быстрый способ подключить шрифт, лучше его не использовать. Браузеру потребуется больше времени для отрисовки страницы. Особенно это будет заметно, если скорость интернета не очень высокая.

Из двух предложенных на сайте Google Fonts вариантов подключения шрифта выбирайте тот, что через `<link>`.

А ещё лучше скачайте файлы шрифта и подключите их со своего сервера через [`@font-face`](/css/font-face/). Так браузеру не придётся ходить на другой домен, а IP-адреса ваших посетителей не попадут на серверы Google. Для сайтов, которые работают с посетителями из Евросоюза, это ещё и вопрос соблюдения GDPR — европейского закона о защите персональных данных.

🛠 В большом проекте стили удобно разложить по файлам: разметка, типографика, формы и кнопки. Основной файл _style.css_ тогда состоит только из импортов. Так всегда знаешь, в какой файл залезть, чтобы что-нибудь поправить.

Такие проекты обычно собирают [_сборщиком_](/tools/bundlers/). Он склеивает все импортированные файлы в один, и браузеру не нужно делать лишние запросы. Без сборщика старайтесь обходиться небольшим числом импортов.
