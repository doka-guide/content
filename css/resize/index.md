## Кратко

Свойство `resize` указывает, может ли пользователь изменять размеры элемента и в каком направлении. Если может, в одном из углов элемента появится уголок-треугольник. Пользователь тянет за него и меняет размер.

Чаще всего `resize` нужен для [`<textarea>`](/html/textarea/). Её размер по умолчанию можно менять: потяните за нижний правый угол.

<iframe title="Простая textarea" src="demos/resize-textarea/" height="250"></iframe>

Чтобы запретить менять размер `<textarea>`, задайте ей `resize: none`.

Другим элементам одного `resize` мало: нужен ещё [`overflow`](/css/overflow/) со значением `auto`, `scroll` или `hidden`. У `<textarea>` браузер заранее задал `overflow: auto`. У большинства других элементов стоит `overflow: visible`, поэтому добавьте `overflow`:

```css
.panel {
  overflow: auto;
  resize: both;
}
```

## Пример

Переключайте значения `resize` и тяните уголок-треугольник, чтобы увидеть, в каком направлении меняется размер блока.

<iframe title="Песочница resize" src="demos/resize-playground/" height="500"></iframe>

Когда пользователь тянет уголок, браузер записывает новые [`width`](/css/width/) и [`height`](/css/height/) в атрибут `style` элемента. Если тянуть можно только в одну сторону, браузер записывает одно из свойств. Учтите: `width` или `height` с [`!important`](/css/important/) перебьют эти значения, и размер не изменится.

Картинку ([`<img>`](/html/img/)) или видео ([`<video>`](/html/video/)) растянуть через `resize` не получится ни в одном браузере. С фреймом ([`<iframe>`](/html/iframe/)) иначе: Chrome и Safari разрешают тянуть его без обёртки, Firefox — нет. Чтобы растянуть картинку, оберните её в [`<div>`](/html/div/) и задайте обёртке `overflow: auto` и `resize`.

<iframe title="resize для картинки" src="demos/resize-image/" height="500"></iframe>

## Как пишется

- `none` — размеры изменить нельзя. Это значение по умолчанию для большинства элементов, но у `<textarea>` браузеры на компьютерах ставят `both`.
- `both` — размеры можно изменять по горизонтали и вертикали.
- `horizontal` — размер можно изменять по горизонтали.
- `vertical` — размер можно изменять по вертикали.
- `block` — размер можно изменять в блочном направлении: по вертикали при горизонтальном письме.
- `inline` — размер можно изменять в строчном направлении: по горизонтали при горизонтальном письме.

Блочное и строчное направления зависят от направления письма, которое задаёт свойство [`writing-mode`](/css/writing-mode/). При вертикальном письме `resize: block` позволит менять ширину, а `resize: inline` — высоту. Подробнее о направлениях — в статье про [логические свойства](/css/logical-properties/).

## Подсказки

💡 Можно ограничить минимальную и максимальную ширину и высоту с помощью свойств `max-width`, `min-width`, `max-height`, `min-height`.

💡 Строчным элементам с [`display: inline`](/css/display/) свойство `resize` не поможет: к ним не применяется `overflow`.

💡 В Chrome и Safari уголок-треугольник можно стилизовать с помощью нестандартного псевдоэлемента `::-webkit-resizer`.

💡 Уголок-треугольник двигают только мышью или пальцем: с клавиатуры размер не поменять. На iOS и в Firefox для Android `resize` не работает совсем, даже у `<textarea>`. Не делайте изменение размера единственным способом увидеть весь контент блока.
