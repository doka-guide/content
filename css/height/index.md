## Кратко

Пустой блочный HTML-элемент без отступов и рамок по высоте равен нулю. Обычно элемент подстраивается по высоте под свой контент. Но что делать, если дизайнер придумал иначе, или если внутри вообще ничего нет?

При помощи свойства `height` можно задать высоту блочному (`block`) или строчно-блочному (`inline-block`) элементу, [флекс-](/css/flexbox-guide/) и [грид-элементу](/css/grid-guide/), а также картинке, видео или полю ввода. Высоту можно задавать как в абсолютных единицах (пикселях `px`), так и в относительных (проценты, `vh`, `vmin`, `rem` и так далее).

Помимо фиксированной высоты можно задать минимальную высоту элемента — `min-height`. Элемент растянется, если контенту нужно больше места. Но не станет ниже значения `min-height`.

Максимальную высоту задаёт `max-height`. Элемент растягивается по высоте, пока не достигнет этого значения. И дальше не растянется ни на пиксель.

## Пример

```html
<div class="container">
  <div class="item"></div>
</div>
```

```css
.container {
  /* высота родителя */
  height: 150px;
  padding: 25px;
  background-color: #AFC9DA;
}

.item {
  /* высота вложенного блока */
  height: 50px;
  margin: 0 10px;
  background-color: #FFFFFF;
}
```

Оба блока, `.container` и `.item`, пустые, поэтому без стилей их высота была бы равна нулю.

Добавим в элемент `.item` текст и внутренние отступы [`padding: 25px`](/css/padding/). А ещё [`box-sizing: border-box`](/css/box-sizing/): с ним отступы входят в высоту `50px`, а не прибавляются к ней.

<iframe title="Высота для блока с текстом" src="demos/basic-w-text/" height="200"></iframe>

Из-за фиксированной высоты контент выпадает из блока. Как можно это исправить? Заменить `height` на `min-height`!

```css
.item {
  /* Меняем фиксированную высоту на минимальную */
  min-height: 50px;
  padding: 25px;
  box-sizing: border-box;
  margin: 0 10px;
  background-color: #FFFFFF;
}
```

Если контента нет, высота блока — `50px`. Как только появится контент, блок растянется и уместит его целиком! Сам `.container` при этом не вырастет: у него по-прежнему фиксированная высота `150px`.

## Как понять

Без `height` высота блока зависит от контента: сколько текста и вложенных элементов, такой и высота. Свойство `height` отвязывает высоту от контента: блок будет нужной высоты, даже если внутри пусто или контента больше, чем помещается в блок.

## Как пишется

Свойства `height`, `min-height` и `max-height` можно писать по одному или вместе.

Значение — число, а за ним без пробела единица измерения: `px`, `%`, `vh`, `rem`, `em` или любую другую [единицу измерения](/css/numeric-types/), доступную в вебе.

```css
div {
  height: 50vh;
  min-height: 200px;
  max-height: 600px;
}
```

Вместо числа можно написать ключевое слово:

- `auto` — браузер сам рассчитает высоту по контенту.
- `min-content`, `max-content` и `fit-content` — высота по контенту. В обычном блоке с горизонтальным текстом они дают ту же высоту, что и `auto`.

Разница видна у флекс- и грид-элементов. При `height: auto` такой элемент растягивается на высоту строки флекс-контейнера или ряда грида. С `min-content`, `max-content` или `fit-content` он не растягивается.

## Подсказки

💡 Свойство высоты не наследуется.

💡 Значение по умолчанию — `auto`.

Это ключевое слово бывает полезно, когда нужно _сбросить_ высоту, заданную ранее. Например, оно пригодится при доработке сайта, к исходным стилям которого нет доступа.

Исходные стили с фиксированной высотой, которые нельзя изменить:

```css
.container {
  height: 150px;
}
```

Ваши стили перезаписывают предыдущее значение: теперь высота подстраивается под контент.

```css
.container {
  height: auto;
}
```

💡 Не задавайте фиксированную высоту блокам, в которых есть контент. Если контента станет больше, то блок не растянется и контент из него выпадет. Не надо так. Если без высоты никак не обойтись, то используйте `min-height`.

💡 Строчные элементы вроде `<span>` или `<a>` не реагируют на `height`. Чтобы задать им высоту, поменяйте [`display`](/css/display/) на `block` или `inline-block`.

Исключения:

- картинки, видео и поля ввода — им высоту задать можно;
- строчные элементы внутри флекс- или грид-контейнера — у них `height` сработает.

💡 Пишете `height: 100%` и ничего не работает? Проценты считаются от высоты родителя. Они сработают, только если высота родителя известна заранее:

- задана через `height`;
- растянута флекс- или грид-контейнером.

Если высота родителя рассчитана по контенту или задана через `min-height`, проценты не сработают.

Отношения родительского и дочернего элементов проще показать на примере.

```html
<div class="parent">
  <div class="child child-1">
    <div class="grandchild"></div>
  </div>
  <div class="child"></div>
  <div class="child"></div>
</div>
```

В примере выше элемент с классом `parent` — родительский для элементов с классом `child`, а они — дочерние для него.

Для элемента с классом `grandchild` родительским будет элемент с классом `child-1`.

Здесь `height: 100%` у элемента `grandchild` рассчитается от высоты элемента `child-1`. Если у `child-1` высота не задана, `100%` не сработает.

Исключение — элементы с [`position: absolute`](/css/position/): у них проценты считаются от ближайшего предка, у которого `position` не `static`, даже если его высота рассчитана по контенту.
