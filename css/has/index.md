## Кратко

Функция-псевдокласс `:has()` выбирает элемент, если внутри него или после него есть элемент, подходящий под условие. Поэтому `:has()` часто называют «родительским селектором».

## Пример

Применяем стили ко всем ссылкам, которые содержат картинки:

```css
a:has(img) {
  /* Стили */
}
```

Стили применятся только к такому `<dt>`, за которым сразу следует элемент `<dd>`:

```css
dt:has(+ dd) {
  /* Стили */
}
```

В демке `:has()` вместе с [`:checked`](/css/checked/) проверяет, есть ли в задаче отмеченный чекбокс. Отмеченная задача зачёркивается, а когда отмечены все, меняется вся карточка:

## Как пишется

Браузер ищет `selector2` внутри `selector1` или после него:

```css
selector1:has(selector2) {
  /* Стили */
}
```

`selector1` можно не указывать. Тогда подойдёт любой элемент с нужным потомком или соседом. Например, `:has(img)` выберет всех предков картинки вплоть до `<html>`.

Аргумент может начинаться с [комбинатора](/css/combined-selectors/). Без комбинатора браузер ищет любого потомка:

```css
/* Внутри статьи есть картинка на любом уровне вложенности */
article:has(img) {}

/* Картинка — прямой потомок статьи */
article:has(> img) {}

/* Сразу за заголовком идёт абзац */
h2:has(+ p) {}

/* Где-то после заголовка на том же уровне есть абзац */
h2:has(~ p) {}
```

В скобках можно перечислить несколько селекторов через запятую. Правило сработает, если найдётся хотя бы один из них.

## Как понять

`:has()` работает как условие. Стили получает элемент перед `:has()`, а не то, что нашлось в скобках.

В этом отличие от [`:is()`](/css/is/) и [`:where()`](/css/where/). Они проверяют сам элемент: `a:is(.active)` — это ссылка с классом `active`. А `a:has(.active)` — это ссылка, внутри которой есть элемент с классом `active`.

## Подсказки

💡 `:has()` добавляет к [специфичности](/css/specificity/) селектора вес самого специфичного аргумента. Неважно, какой аргумент совпал с элементом. В примере ниже к весу `article` всегда добавляется вес `#intro`, даже если внутри нашёлся только `.note`:

```css
article:has(.note, #intro) {
  /* Стили */
}
```

💡 Чтобы проверить сразу несколько условий, поставьте несколько `:has()` подряд. Браузер применит стили к статье, только если внутри есть и картинка, и видео:

```css
article:has(img):has(video) {
  /* Стили */
}
```

💡 Псевдокласс `:has()` нельзя вкладывать в другой `:has()`. Такой селектор невалидный, и браузер отбросит правило.

💡 [Псевдоэлементы](/css/pseudoelements/) вроде `::before` нельзя передать в `:has()` и нельзя поставить перед ним. Селекторы `p:has(::before)` и `p::before:has(img)` не сработают.

💡 Список селекторов у `:has()` не прощает ошибок. Если хотя бы один селектор в нём невалидный, браузер отбросит всё правило.

В примере ниже `:unknown` — несуществующий псевдокласс. Стили не применятся, даже если внутри есть `.note`:

```css
article:has(.note, :unknown) {
  /* Эти стили не применятся */
}
```

Вместе с правилом пропадут и соседи по списку: в `a:has(:unknown), .card {}` стили потеряет и `.card`.

Если в списке есть селектор, который браузер может не знать, оберните список в `:is()`. Он принимает «прощающий» список селекторов и просто пропускает невалидные:

```css
article:has(:is(.note, :unknown)) {
  /* Стили применятся, если внутри есть .note */
}
```

Комбинатор ставьте перед `:is()`, а не внутри. `:is()` молча отбрасывает селектор, который начинается с комбинатора:

```css
/* Ничего не выберет */
h2:has(:is(+ p)) {}

/* Сработает */
h2:has(+ :is(p, :unknown)) {}
```
