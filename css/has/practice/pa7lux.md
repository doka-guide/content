🛠 Бывает, что HTML-код какого-то блока страницы собирает из Markdown-разметки генератор сайтов вроде [11ty](https://www.11ty.dev). В такой HTML-код нельзя добавить классы, идентификаторы или data-атрибуты. Псевдокласс `:has()` помогает, когда генератор неожиданно оборачивает элементы.

Вот типовой кусок разметки Markdown:

```markdown
## Как заварить чай

Подогрейте чайник кипятком, чтобы стенки прогрелись.
Затем слейте воду и насыпьте заварку.

![Заварочный чайник](https://example.com/teapot.jpg)

Залейте заварку водой температурой около 90 градусов
и подождите три-четыре минуты.

Приятного чаепития!
```

Эта разметка превратится в такой HTML (я поместил его в секцию, так ближе к реальной вёрстке):

```html
<section class="content">
  <h2>Как заварить чай</h2>
  <p>
    Подогрейте чайник кипятком, чтобы стенки прогрелись.
    Затем слейте воду и насыпьте заварку.
  </p>
  <p>
    <img
      src="https://example.com/teapot.jpg"
      alt="Заварочный чайник"
    >
  </p>
  <p>
    Залейте заварку водой температурой около 90 градусов
    и подождите три-четыре минуты.
  </p>
  <p>Приятного чаепития!</p>
</section>
```

Генератор оборачивает изображение в абзац, и это мешает стилизации. Например, мы хотим поставить изображение справа от первого абзаца, а остальные абзацы не трогать.

Сделаем секцию гридом с двумя колонками. По умолчанию каждый элемент занимает обе колонки:

```css
.content {
  display: grid;
  grid-template-columns: 1fr 300px;
  gap: 20px;
}

.content > * {
  grid-column: 1 / -1;
}
```

Выбираем абзац, следом за которым сразу идёт другой абзац с вложенным изображением, и ставим его в левую колонку:

```css
.content p:has(+ p > img) {
  grid-column: 1;
}
```

Теперь выберем абзац с вложенным изображением и поставим его в правую колонку. Грид разместит его в той же строке, что и предыдущий абзац:

```css
.content p:has(img) {
  grid-column: 2;
}
```

Подгоним изображение под ширину колонки:

```css
.content img {
  display: block;
  width: 100%;
}
```
