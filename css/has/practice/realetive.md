🛠 `:has()` заменяет JavaScript там, где стиль родителя зависит от потомков: поле с ошибкой (`.field:has(:user-invalid)`), карточка с отмеченным чекбоксом, корзина без товаров (`.cart:not(:has(li))`). Раньше CSS умел только частные случаи вроде [`:focus-within`](/css/focus-within/) и [`:empty`](/css/empty/).
