## Кратко

Свойство `font-stretch` устанавливает узкое, нормальное или широкое начертание шрифта. Браузер не рисует буквы заново, а выбирает подходящее начертание из описанных в [`@font-face`](/css/font-face/) или из системного шрифта.

Вариативный шрифт — один файл, в котором ширину, жирность и другие параметры можно менять плавно. Каждый такой параметр называют осью. В таком шрифте браузер выставляет нужное значение на оси ширины `wdth`.

Узкое начертание помогает уместить длинный заголовок или текст в узкой колонке, не уменьшая размер шрифта.

## Пример

```css
h1 {
  font-family: "Roboto Flex", sans-serif;
  font-stretch: 75%;
}
```

## Как пишется

У некоторых шрифтов есть дополнительные начертания, в которых буквы у́же (`condensed`) или шире (`expanded`) нормальной ширины. Если у шрифта нет таких начертаний, `font-stretch` ничего не изменит. Спецификация запрещает браузеру искусственно сжимать или растягивать буквы.

**Возможные значения:**

- `normal` — нормальная, или «текстовая», ширина шрифта (значение по умолчанию);
- `semi-condensed`, `condensed`, `extra-condensed`, `ultra-condensed` — сжатое начертание разной степени;
- `semi-expanded`, `expanded`, `extra-expanded`, `ultra-expanded` — расширенное начертание разной степени;
- проценты — ширина относительно нормальной, без отрицательных значений; границы диапазона зависят от шрифта.

![Примеры шрифтов](./images/example.png)
Пример двух разных шрифтов со значениями, указанными в процентах

**Каким процентам соответствуют ключевые слова:**

- `ultra-condensed` — `50%`;
- `extra-condensed` — `62.5%`;
- `condensed` — `75%`;
- `semi-condensed` — `87.5%`;
- `normal` — `100%`;
- `semi-expanded` — `112.5%`;
- `expanded` — `125%`;
- `extra-expanded` — `150%`;
- `ultra-expanded` — `200%`.

<aside>

⚠️ Некоторые шрифты поддерживают не все значения. Так, у Roboto Flex диапазон от 25 до 151%, и в примере ниже браузер отрисует текст шириной 151%, а не 200%, как ожидалось. В инструментах разработчика при этом останется значение 200%.

```css
p {
  font-family: "Roboto Flex", sans-serif;
  font-stretch: ultra-expanded;
}
```

Посмотреть, какой диапазон ширины поддерживает шрифт, можно на [Google Fonts](https://fonts.google.com/variablefonts?vfaxis=wdth).

</aside>

## Подсказки

💡 В спецификации CSS Fonts 4 свойство переименовали в `font-width`, а `font-stretch` оставили его псевдонимом. Значения у них одинаковые. Но `font-width` пока понимают только Safari 18.4+ и Firefox 155+, а в Chrome его нет. Так что пишите `font-stretch`: оно работает во всех браузерах.

💡 Если вы подключаете вариативный шрифт сами, укажите в `@font-face` диапазон ширины, который поддерживает шрифт. Так браузер знает, какие ширины покрывает файл, а старые версии Chrome без диапазона ширину вообще не меняли:

```css
@font-face {
  font-family: "Roboto Flex";
  src: url("roboto-flex.woff2") format("woff2");
  font-stretch: 25% 151%;
}
```

Google Fonts добавляет этот диапазон сам, если запросить шрифт с осью `wdth`.

💡 Ширину вариативного шрифта можно задать и через [`font-variation-settings`](/css/font-variation-settings/): `"wdth" 75`. Но `font-stretch` удобнее: оно понимает ключевые слова и работает с обычными шрифтами, где каждое начертание лежит в отдельном файле. А `font-variation-settings` целиком заменяет список осей, заданный выше по каскаду, и перебивает `font-stretch`.

💡 Ширину можно указать и в шорткате [`font`](/css/font/), но только ключевым словом: `font: condensed 16px sans-serif`. Проценты шорткат не принимает.
