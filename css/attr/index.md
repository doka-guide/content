## Кратко

`attr()` — это CSS-функция, которая умеет получать значение любого атрибута элемента и использовать его прямо в стилях.

## Пример

```html
<div class="element" title="На самом деле внутри нет никакого текста"></div>
```

```css
div::before {
  content: "Элемент с классом " attr(class);
}

div::after {
  content: "Подсказка: " attr(title);
}
```

## Как понять

Долгое время браузеры понимали `attr()` только внутри свойства [`content`](/css/content/), и функция возвращала там строку. Поэтому `attr()` использовали в псевдоэлементах [`::before`](/css/before/) и [`::after`](/css/after/).

Спецификация CSS Values 5 разрешила `attr()` в любом свойстве и добавила функции тип. Браузер читает атрибут, разбирает его значение как длину, цвет, угол или число и подставляет результат в любое свойство. Так можно передавать в стили настройки прямо из разметки, например, через [data-атрибуты](/html/data-attributes/):

```html
<div class="bar" data-progress="75" data-color="tomato"></div>
```

```css
.bar {
  width: attr(data-progress %, 0%);
  background-color: attr(data-color type(<color>), gray);
}
```

Раньше для этого приходилось писать JavaScript или передавать значения через [кастомные свойства](/css/custom-properties/) в атрибуте `style`.

В демке ширина и цвет каждой полоски берутся из её атрибутов. Кнопка меняет только атрибуты, а стили обновляются сами:

## Как пишется

Без типа функция возвращает значение атрибута как строку:

```css
div::before {
  content: attr(data-title);
}
```

Вторым аргументом через запятую передают фолбэк, то есть запасное значение. Браузер подставит его, если у элемента нет такого атрибута. Для пустого атрибута `data-title=""` браузер фолбэк не берёт и выводит пустую строку.

```css
div::before {
  content: attr(data-title, "Без названия");
}
```

Тип указывают после имени атрибута через пробел:

- `type(<тип>)` — браузер разбирает значение как указанный тип CSS: `<length>`, `<color>`, `<number>`, `<angle>`, `<custom-ident>` (произвольное имя, например, имя анимации) и другие. Можно перечислить несколько вариантов через `|`: `type(<length> | auto)`.
- единица измерения — `px`, `%`, `deg`, `s` и другие. В атрибуте должно лежать число, а браузер добавит к нему единицу. Из `data-size="20"` запись `attr(data-size px)` сделает `20px`.
- `raw-string` — значение атрибута целиком, как обычная строка, без разбора по правилам CSS. Так же браузер поступает и без типа, поэтому `raw-string` пишут редко.

```css
.card {
  padding: attr(data-space type(<length>), 16px);
  rotate: attr(data-angle deg, 0deg);
  background-color: attr(data-color type(<color>), #2E9AFF);
  animation-name: attr(data-animation type(<custom-ident>), none);
}
```

Если атрибута нет или его значение не подходит под тип, браузер возьмёт фолбэк. Если у `attr()` с типом нет фолбэка, объявление станет недействительным уже после разбора стилей. Свойство получит унаследованное или начальное значение, как с `unset`. К объявлению того же свойства выше по коду браузер не вернётся, поэтому фолбэк лучше указывать всегда.

## Подсказки

💡 Строковая `attr()` в `content` работает во всех браузерах. Фолбэк для неё поддерживают все современные браузеры с весны 2025 года.

💡 `attr()` в любом свойстве, типы и единицы измерения работают в Chrome и Edge с версии 133 и в Firefox с версии 155. В Safari их пока нет, поддержка ожидается в версии 27.3. Браузер без поддержки отбрасывает такое объявление ещё при разборе стилей. Поэтому запасное объявление можно написать строкой выше:

```css
.bar {
  width: 50%;
  width: attr(data-progress %, 50%);
}
```

Для целого блока стилей проверьте поддержку через [`@supports`](/css/supports/): `@supports (x: attr(x type(*)))`.

💡 Из атрибута нельзя собрать адрес. Типа `<url>` в `attr()` нет, а каждое значение из `attr()` браузер помечает как «полученное из атрибута». Если такое значение попадает в адрес, объявление становится недействительным. Метка сохраняется и при передаче через кастомное свойство и [`var()`](/css/var/), так что обойти запрет не получится. Так браузеры защищают пользователей: иначе стили могли бы отправлять значения атрибутов на чужой сервер.

💡 Не храните важные данные только в стилях. Текст из `content` нельзя выделить, а скринридеры читают его не везде. Значение, которое нужно пользователю, оставьте в разметке.
