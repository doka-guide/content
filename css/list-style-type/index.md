## Кратко

Свойство `list-style-type` меняет маркер у пунктов списков [`<ul>`](/html/ul/) и [`<ol>`](/html/ol/): точку, цифру или букву. Вариантов у него больше, чем у атрибута `type`. Часто маркер убирают совсем: список выглядит как обычный блок, а теги списка остаются.

Готовых ключевых слов у `list-style-type` несколько десятков. Если их не хватает:

- [`list-style-image`](/css/list-style-image/) ставит картинку вместо маркера;
- директива [`@counter-style`](/css/counter-style/) создаёт свой счётчик с любыми символами и правилами нумерации.

## Пример

По умолчанию у маркированных списков значение `list-style-type: disc` (маркер в виде точки), а у нумерованных — `decimal` (арабские цифры с точкой):

<iframe title="Списки по умолчанию" src="demos/basic/" height="290"></iframe>

Свойство `list-style-type` можно задать самому `<ul>` или `<ol>`. Оно наследуется, поэтому пункты получат то же значение. Можно задать его и отдельному [`<li>`](/html/li/) или любому элементу со значением `list-item` у свойства [`display`](/css/display/).

## Как пишется

```css
ul {
  list-style-type: square;
}
```

Значения `list-style-type` делятся на несколько _типов_. Типам этих **счётчиков** посвящён [целый раздел спецификации](https://drafts.csswg.org/css-counter-styles-3). Пощёлкайте по значениям в демке:

### Числовые

- `decimal` западные десятичные числа (1, 2, 3, ..., 98, 99, 100);
- `decimal-leading-zero` десятичные числа с предшествующим нулём (01, 02, 03, ..., 98, 99, 100).

- `lower-roman` строчная римская нумерация (i, ii, iii, ..., xcviii, xcix, c);
- `upper-roman` заглавная римская нумерация (I, II, III, ..., XCVIII, XCIX, C);
- `arabic-indic` арабские (индийские) цифры (١‎, ٢‎, ٣‎, ٤‎, ..., ٩٨‎, ٩٩‎, ١٠٠‎);

### Алфавитные

- `lower-alpha` / `lower-latin` строчные латинские буквы (a, b, c, ..., z, aa, ab);
- `upper-alpha` / `upper-latin` заглавные латинские буквы (A, B, C, ..., Z, AA, AB).

Другие алфавиты в других языковых культурах:

- `lower-greek` строчные греческие буквы (α, β, γ, ..., ω, αα, αβ);
- `hiragana` буквы японской слоговой азбуки хирагана в алфавитном порядке (あ, い, う, ..., ん, ああ, あい);
- `hiragana-iroha` буквы японской слоговой азбуки хирагана в порядке ироха (い, ろ, は, ..., す, いい, いろ);
- `katakana` буквы японской слоговой азбуки катакана в алфавитном порядке (ア, イ, ウ, ..., ン, アア, アイ);
- `katakana-iroha` буквы японской слоговой азбуки катакана в порядке ироха (イ, ロ, ハ, ..., ス, イイ, イロ).

### Символьные

- `disc` точка, похожая на символ • U+2022 BULLET;
- `circle` кружок, похожий на символ ◦ U+25E6 WHITE BULLET;
- `square` закрашенный квадрат, похожий на символ ▪ U+25AA BLACK SMALL SQUARE;
- `disclosure-open` и `disclosure-closed` треугольники раскрытого и свёрнутого блока, как у элемента [`<details>`](/html/details/).

### Строка

Вместо ключевого слова можно написать строку в кавычках. Она станет маркером каждого пункта:

```css
ul {
  list-style-type: "→ ";
}
```

Пробел в конце строки нужен, чтобы маркер не прилип к тексту пункта.

### Функция `symbols()`

Функция `symbols()` задаёт счётчик прямо в значении свойства, без отдельной директивы `@counter-style`:

```css
ul {
  list-style-type: disc;
  list-style-type: symbols(cyclic "◆" "◇");
}
```

Маркеры будут чередоваться: ◆, ◇, ◆, ◇ и так далее. Функцию поддерживают Firefox с версии 35, Chrome и Edge — с версии 155. Safari её пока не понимает, поэтому перед ней стоит запасное значение `disc`.

## Список без маркеров

Иногда нужна семантика списка, но без маркеров: меню, карточки товаров, список статей. Если мы зададим списку `list-style-type: none`, то уберём «лишнее» оформление, но не смысл. Скринридер в Chrome или Firefox сообщит, что это список и сколько в нём пунктов:

```html
<nav>
  <ul style="list-style-type: none">
    <li>
      <a href="/articles">Статьи</a>
    </li>
    <li>
      <a href="/authors">Авторы</a>
    </li>
    <li>
      <a href="/contacts">Контакты</a>
    </li>
  </ul>
</nav>
```

<iframe title="Список без маркера" src="demos/ul-no-marker/" height="250"></iframe>

Пример вёрстки списка статей или товаров:

```html
<ol style="list-style-type: none">
  <li>
    <article>
      <h2>Обзор кафе «Тарелко эль Торреро»</h2>
      <p class="author">Григорий Гаспатчев</p>
    </article>
  </li>
  <li>
    <article>
      <h2>Заказываем пиццу из «Саранчи»</h2>
      <p class="author">Мария Пепперони</p>
    </article>
  </li>
  <li>
    <article>
      <h2>Где попробовать тэппанъяки?</h2>
      <p class="author">Василиса Васаби</p>
    </article>
  </li>
</ol>
```

<iframe title="Список статей без номеров" src="demos/ol-no-marker/" height="380"></iframe>

Без стандартного маркера можно нарисовать свой через псевдоэлемент [`::before`](/css/before/). Не забудьте свойство [`content`](/css/content/), без него псевдоэлемент не появится:

```html
<ul>
  <li>Милый маленький грибочек</li>
  <li>Сколопендровый листочек</li>
  <li>Жёлтой пыльки чуть</li>
</ul>
```

```css
ul {
  list-style-type: none;
}

li {
  position: relative;
  padding-left: 50px;
}

li::before {
  content: "";
  position: absolute;
  top: 7px;
  left: 0;
  width: 15px;
  height: 15px;
  background-color: #2E9AFF;
}
```

<iframe title="Пример со свойством content" src="demos/empty-content/" height="270"></iframe>

Почему не [`::marker`](/css/marker/)? Ему доступны только некоторые свойства, например цвет, шрифт и `content`. Маркер можно увеличить через [`font-size`](/css/font-size/), но ширину, высоту и фон у него не задать.

Скринридер VoiceOver в Safari не считает списком `<ul>` или `<ol>` без видимых маркеров. Исключение — список внутри [`<nav>`](/html/nav/). Поэтому меню выше обёрнуто в `<nav>`.

В остальных случаях добавьте тегу списка атрибут [`role="list"`](/a11y/role-list/). Это касается и списка с маркерами через `::before`. Тогда VoiceOver назовёт количество пунктов.

## Кастомные счётчики с `@counter-style`

Пример счётчика из эмодзи:

```css
@counter-style emoji {
  system: fixed;
  symbols: 😁 😇 😋 🤪 😎;
  suffix: " ";
}

.list {
  list-style-type: emoji;
}
```

<iframe title="Кастомные маркеры" src="demos/custom/" height="340"></iframe>

С `system: fixed` каждый символ достаётся одному пункту. Шестой пункт получит обычную цифру 6. Чтобы символы повторялись по кругу, используйте `system: cyclic`.

Директиву `@counter-style` поддерживают все браузеры, Safari — с версии 17.
