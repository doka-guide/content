## Кратко

Свойство `text-indent` управляет отступом строк в начале абзаца, по умолчанию только первой. Положительное значение сдвигает первую строку внутрь блока, отрицательное — за его край. Отступ первой строки выделяет начало абзаца, когда между абзацами нет пустого места.

## Пример

Первая строка абзаца сдвигается на три размера шрифта:

```css
p {
  text-indent: 3em;
}
```

## Как пишется

### Ключевые слова

Ключевые слова пишут вместе со значением отступа в любом порядке. Во всех основных браузерах они работают с 2026 года: Chrome и Edge добавили их последними, в версии 146.

- `hanging` — переворачивает отступ: его получают все строки, кроме первой.
- `each-line` — отступ получает первая строка блока и каждая строка после принудительного переноса. Принудительный перенос — это [`<br>`](/html/br/) или перевод строки в коде, если его сохраняет [`white-space: pre-line`](/css/white-space/) или похожее значение. Строки после обычного переноса текста отступа не получают.

Вместе `hanging each-line` переворачивают и это правило: отступ получают только строки после обычного переноса. Так удобно оформлять стихи, где длинная строка продолжается с отступом.

С `hanging` оформляют, например, списки литературы:

```css
.bibliography li {
  text-indent: 2em hanging;
}
```

Браузер, который не знает ключевых слов, отбросит объявление с ними целиком. Для `each-line` замены нет. Для `hanging` есть: отрицательный отступ, он работает и в старых браузерах.

Отрицательный отступ сдвигает первую строку за край блока. Без внутреннего отступа такая строка ляжет на маркер списка или уйдёт за край экрана. Поэтому добавьте блоку [`padding-inline-start`](/css/padding/) такой же величины:

```css
.bibliography li {
  padding-inline-start: 2em;
  text-indent: -2em;
}
```

Выберите один из способов. Если добавить в это правило `text-indent: 2em hanging`, в новых браузерах отступы сложатся: остальные строки сдвинутся на `4em`.

### Единицы измерения

Значение задают в любых [единицах длины](/css/numeric-types/) или в процентах. Проценты считаются от ширины области содержимого блока, без внутренних отступов и рамки.

При [вертикальном письме](/css/writing-mode/) отступ идёт по вертикали, а проценты считаются от высоты блока.

## Подсказки

💡 Свойство наследуется. Если внутри абзаца с отступом есть элемент с [`display: inline-block`](/css/display/), например ссылка, оформленная как кнопка, первая строка внутри него тоже получит отступ. Сбросьте его: `text-indent: 0`.
