## Кратко

С помощью свойства `counter-set` можно указать конкретное числовое значение определённому счётчику.

## Пример

Допустим, нам нужно изменить нумерацию глав в учебнике, чтобы после третьей главы шла сразу девятая:

```html
<article>
  <h1>Учебник по вёрстке</h1>
  <h2>HTML и CSS</h2>
  <h2>Создание стилей и таблиц стилей</h2>
  <h2>Селекторы: выбор форматируемых элементов</h2>
  <h2 class="jump">Механизм наследования стилей</h2>
  <h2>Управление сложной структурой стилей: каскад</h2>
  <h2>Поля, отступы, границы</h2>
</article>
```

На элементе [`<article>`](/html/article/) создаём счётчик с именем `chapter` и начальным значением 0:

```css
article {
  counter-reset: chapter 0;
}
```

Увеличиваем значение счётчика `chapter` на элементах [`<h2>`](/html/h1-h6/) свойством [`counter-increment`](/css/counter-increment/). Для четвёртой главы с классом `.jump` задаём точное значение, а номер выводим функцией [`counter()`](/css/counter-counters/):

```css
h2 {
  counter-increment: chapter 1;
}

.jump {
  counter-set: chapter 9;
}

h2::before {
  content: "Глава " counter(chapter) ": ";
}
```

На четвёртой главе работают сразу два свойства. Сначала `counter-increment` увеличивает счётчик до 4, потом `counter-set` заменяет это значение на 9.

## Как понять

Счётчик можно сбросить и через [`counter-reset`](/css/counter-reset/), но это свойство каждый раз создаёт новый счётчик. Если у предка уже есть счётчик с тем же именем, новый окажется вложенным в него. Это видно, когда номер собирают функцией `counters()`: она выведет номера всех вложенных счётчиков через разделитель, который передают вторым аргументом.

`counter-set` новый счётчик не создаёт, а меняет значение того, что уже действует на элементе. Поэтому нумерация продолжается дальше с нового числа, как в примере с главами.

## Как пишется

В значении свойства укажите имя счётчика и, по желанию, число. Без числа счётчик получит значение 0. Здесь значение счётчика `example` будет равно 0:

```css
li {
  counter-set: example;
}
```

Чтобы не изменять числовое значение счётчика, можно указать ключевое слово `none` — это значение по умолчанию.

В значении можно указать один или несколько счётчиков. Их перечисляют через пробел:

```css
li {
  counter-set: chapter -1 section 99;
}
```

Если одно имя встречается в значении несколько раз, сработает последнее. Здесь счётчик `chapter` получит значение 5:

```css
li {
  counter-set: chapter 1 chapter 5;
}
```

Имена счётчиков чувствительны к регистру. Например, `example` и `EXAMPLE` — это два разных, не связанных между собой счётчика.

Именем счётчика не может быть `none`, `default` и [общие ключевые слова](/css/global-keywords/) вроде `initial`, `inherit`, `unset` и `revert`. Этот запрет действует в любом регистре: `None` и `INHERIT` тоже не подойдут.

## Подсказки

💡 Создавать счётчики может не только `counter-reset`. Допустим, у элемента есть только свойство `counter-set` с именем несуществующего счётчика:

```css
li {
  counter-set: new 2;
}
```

Тогда браузер создаст на элементе [`<li>`](/html/li/) новый счётчик `new` со значением 0 и сразу установит ему значение 2. Но лучше создавать счётчики явно через `counter-reset`: так код проще читать.
