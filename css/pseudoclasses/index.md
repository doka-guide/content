## Кратко

Псевдоклассы — особый вид селектора, который уточняет тип или состояние. Обычно это признак элемента: реакция на наведение курсора, порядок следования и другие.

## Пример

Подсветим строку таблицы при наведении курсора.

В обычном состоянии фон тёмный:

```css
tr {
  background-color: #18191C;
}
```

При наведении курсора цвет фона изменится на голубой:

```css
tr:hover {
  background-color: #123E66;
}
```

## Как понять

Псевдокласс добавляет к селектору условие. Это может быть состояние элемента (`:hover`, `:checked`), его место в дереве (`:first-child`) или признак, который нельзя выразить селектором по атрибуту. Правило сработает, только когда элемент **подходит** под это условие.

## Как пишется

```css
.button:hover {
  color: red;
}
```

Селектор может и отсутствовать. Тогда правило применится ко всем элементам, которые могут иметь признак этого псевдокласса. Например, CSS-правило `:focus {}` применится к любому элементу, который будет в фокусе.

```css
:focus {
  outline: 2px solid #2E9AFF;
}
```

### `:active`

[Основная статья](/css/active/).

Применяется к элементу, пока пользователь его активирует. Например, держит на нём зажатую кнопку мыши или палец. Вместе с элементом `:active` получают и все его предки.

### `:is()`

[Основная статья](/css/is/).

Позволяет сгруппировать схожие селекторы вместо последовательного перечисления через запятую.

Вместо:

```css
h1 a, h2 a, h3 a, h4 a, h5 a, h6 a {
  /* … */
}
```

с `:is()` это можно описать так:

```css
:is(h1, h2, h3, h4, h5, h6) a {
  /* … */
}
```

[Специфичность](/css/specificity/) `:is()` равна специфичности самого специфичного селектора в скобках. Если нужно сгруппировать селекторы и при этом не повышать специфичность, используйте [`:where()`](/css/where/): его специфичность всегда нулевая.

### `:any-link`, `:link`, `:visited`

- [Основная статья про `:link`](/css/link/);
- [Основная статья про `:visited`](/css/visited/).

Применяется к ссылкам [`<a>`](/html/a/) и [`<area>`](/html/area/) с атрибутом `href`. `:any-link` выбирает любую такую ссылку, посещённую или нет. `:link` выбирает ссылки на ещё не посещённые страницы, `:visited` — наоборот, на посещённые. Из соображений приватности для `:visited` браузер разрешает менять только цвета, а JavaScript не узнает, применились ли эти стили.

### `:checked`

[Основная статья](/css/checked/).

Применяется к отмеченным чекбоксам и радиокнопкам и к выбранным пунктам [`<option>`](/html/option/). Псевдокласс следит за текущим состоянием элемента, а не за атрибутом `checked` в разметке: если пользователь снимет отметку, стили пропадут.

### `:default`

[Основная статья](/css/default/).

Применяется к чекбоксам и радиокнопкам с атрибутом `checked` в разметке и к пунктам `<option>` с атрибутом `selected`. А ещё к кнопке, которая отправит форму по нажатию <kbd>Enter</kbd>. Это первая кнопка отправки в форме:

- [`<button>`](/html/button/) без `type` или с `type="submit"`;
- `<input type="submit">`;
- `<input type="image">`.

Подсветим подпись у чекбокса, который отмечен **по умолчанию**:

```css
:default + span {
  color: #2E9AFF;
}
```

### `:dir()`

[Основная статья](/css/dir/).

Выбирает элементы по направлению текста, которое задаёт атрибут `dir` у самого элемента или у предка. Например, `:dir(rtl)` найдёт блоки, где текст идёт справа налево, как в арабском.

По самому тексту направление определяется только при `dir="auto"` и у [`<bdi>`](/html/bdi/). Арабский текст без `dir` подойдёт под `:dir(ltr)`. С конца 2023 года псевдокласс [поддерживается во всех основных браузерах](https://caniuse.com/css-dir-pseudo).

### `:disabled`, `:enabled`

[Основная статья](/css/disabled-enabled/).

`:disabled` выбирает отключённые элементы формы, `:enabled` — включённые. Это не то же самое, что `[disabled]` и `:not([disabled])`:

- `:enabled` выбирает только элементы, которые можно отключить: `<button>`, `<input>`, [`<select>`](/html/select/), `<textarea>`, `<option>`, `<optgroup>` и [`<fieldset>`](/html/fieldset/). А `:not([disabled])` выберет и любой `<div>`.
- Псевдоклассы видят унаследованное отключение. Внутри `<fieldset disabled>` `:disabled` найдёт все элементы формы, кроме тех, что лежат в его первом [`<legend>`](/html/legend/).

### `:empty`

[Основная статья](/css/empty/).

Применяется к элементам, у которых внутри нет других тегов или текста. Даже пробел или перенос строки внутри элемента отменяют `:empty`, а HTML-комментарии не мешают.

Подсветим пустые клетки в крестиках-ноликах:

Так же можно найти кнопку без текста и иконки и задать ей минимальные размеры. Не забудьте дать такой кнопке `aria-label`, иначе скринридер прочитает просто «кнопка».

### Псевдоклассы группы child

[Основная статья](/css/child/).

Селекторы элемента по его положению относительно родителя (первый, последний, n-й, единственный).

### Псевдоклассы группы type

[Основная статья](/css/nth-of-type/).

Селектор по типу внутри одного родителя.

### `:fullscreen`

[Основная статья](/css/fullscreen/).

Признак того, что элемент развернули на весь экран с помощью JavaScript-метода `requestFullscreen()`. Полноэкранный режим браузера по <kbd>F11</kbd> псевдокласс не включает.

Растянем видео в развёрнутом плеере на весь экран без обрезки:

```css
.player:fullscreen video {
  width: 100%;
  height: 100%;
  object-fit: contain;
}
```

### `:focus`, `:focus-visible` и `:focus-within`

[Основная статья про `:focus`](/css/focus/).
[Основная статья про `:focus-visible`](/css/focus-visible/).
[Основная статья про `:focus-within`](/css/focus-within/).

- `:focus` — элемент в фокусе.
- `:focus-visible` — элемент в фокусе, если браузер считает, что фокус нужно показать. Например, при переходе по <kbd>Tab</kbd>, но не при клике мышкой по кнопке.
- `:focus-within` — элемент, который сам в фокусе или содержит элемент в фокусе.

### `:has()`

[Основная статья](/css/has/).

Выбирает элемент по тому, что лежит внутри него или после него. Например, `.card:has(img)` выберет карточки, в которых есть картинка. Стили получит сама `.card`, а не `img` из скобок.

Специфичность `:has()` равна специфичности самого специфичного селектора в скобках, как у `:is()` и `:not()`. С конца 2023 года [поддерживается всеми основными браузерами](https://caniuse.com/css-has).

### `:hover`

[Основная статья](/css/hover/).

Состояние элемента, когда на него навели курсор.

### `:indeterminate`

Элементы, которые могут находиться в _промежуточном_ состоянии:

- `<input type="checkbox">`, который показывает, что в группе отмечены не все пункты;
- группа `<input type="radio">` с одинаковым `name`, в которой не отмечена ни одна радиокнопка;
- [`<progress>`](/html/progress/) без атрибута `value`.

Для чекбокса [`<input>`](/html/input/) состояние `indeterminate` можно задать только через JavaScript.

### `:in-range` и `:out-of-range`

[Основная статья](/css/in-range-out-of-range/).

Применяется к `<input>` с ограничением диапазона: числам, датам и времени с атрибутом `min` или `max`, а ещё к ползунку `type="range"`. Введённое значение соответствует (`:in-range`) или нет (`:out-of-range`) этому диапазону. Поля с `disabled` или `readonly` не подходят ни под один из двух псевдоклассов.

<iframe title="Стили для диапазона" src="demos/range/" height="290"></iframe>

### `:lang()`

[Основная статья](/css/lang/).

Выбирает элементы по языку, который задаёт атрибут `lang`. Язык наследуется, поэтому селектор найдёт и элемент с атрибутом `lang`, и всех его потомков.

Например, в арабском языке нет переносов:

```css
:lang(ar) {
  hyphens: none;
}
```

### `:not()`

[Основная статья](/css/not/).

Находит элемент, который **не соответствует** селектору в скобках. Специфичность `:not()` равна специфичности самого специфичного селектора в скобках.

Выделим красной рамкой все [`<img>`](/html/img/), которым забыли прописать атрибут `alt`:

```css
img:not([alt]) {
  outline: 2px solid red;
}
```

### `:optional` и `:required`

[Основная статья про `:required`](/css/required/).
[Основная статья про `:optional`](/css/optional/).

`:optional` находит поля `<input>`, `<select>` и [`<textarea>`](/html/textarea/), у которых не установлен атрибут [`required`](/html/required/). А `:required` — наоборот, те поля, у которых есть этот атрибут.

### `:read-only` и `:read-write`

`:read-write` выбирает элементы, которые можно редактировать: поля для ввода текста и элементы с атрибутом `contenteditable`. `:read-only` — все остальные: поля с атрибутами `disabled` или [`readonly`](/html/readonly/), чекбоксы, кнопки и даже обычные абзацы. Поэтому без уточнения вроде `input:read-only` селектор затронет почти всю страницу.

### `:root`

[Основная статья](/css/root/).

Соответствует корневому элементу документа. Для HTML это [`<html>`](/html/html/), для отдельного SVG-файла — [`<svg>`](/html/svg/). Специфичность селектора `:root` выше, чем у селектора по тегу.

### `:target`

[Основная статья](/css/target/).

Выбирает элемент, чей `id` совпадает с фрагментом адреса страницы — частью после `#`. Например, после клика по ссылке `#contacts` псевдокласс получит элемент с `id="contacts"`:

### `:valid` и `:invalid`

[Основная статья](/css/invalid-valid/).

`:valid` выбирает поле формы, значение которого проходит HTML-валидацию: по типу поля и атрибутам вроде `required`, `pattern`, `min` и `max`. Для `<fieldset>` и `<form>` проверяются все поля внутри.

`:invalid` срабатывает при ошибке валидации, причём сразу при загрузке страницы. Например, на пустом поле с `required`. Чтобы показывать ошибку только после того, как пользователь поработал с полем, используйте [`:user-valid` и `:user-invalid`](/css/user-valid-invalid/).

## Подсказки

💡 Псевдоклассы пишутся с одним двоеточием впереди.

💡 Если задать псевдокласс элементу-родителю, то можно стилизовать дочерний элемент при изменении состояния у родителя.

Если курсор находится внутри [`<nav>`](/html/nav/), подчеркнём вложенные ссылки:

```css
nav:hover a {
  text-decoration: underline;
}
```
