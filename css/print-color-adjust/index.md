## Кратко

Свойство `print-color-adjust` говорит браузеру, как обращаться с цветами при печати. Можно сохранить цвета как есть, а можно разрешить браузеру менять их, чтобы сэкономить чернила и сделать текст читаемее.

## Пример

Оранжевый блок сохранит фон при печати, а синий напечатается так, как решит браузер:

```html
<div class="keep-color">Цвет останется при печати</div>
<div class="economy-color">Цвет может измениться при печати</div>
```

```css
.keep-color {
  background: #FF8630;
  color: #000000;
  print-color-adjust: exact;
}

.economy-color {
  background: #2E9AFF;
  color: #000000;
  print-color-adjust: economy;
}
```

## Как пишется

```css
.chart {
  print-color-adjust: exact;
}
```

Поддерживает два значения:

- `economy` — значение по умолчанию. Браузер может менять оформление при печати, чтобы сэкономить чернила и сделать текст читаемее. Чаще всего он не печатает [фоновые цвета](/css/background-color/) и [фоновые картинки](/css/background-image/), а слишком светлый текст затемняет, чтобы его было видно на белой бумаге. Явно `economy` пишут, чтобы отменить `exact`, который элемент унаследовал от родителя.
- `exact` — браузер не меняет цвета и печатает фон элемента, даже если в диалоге печати выключена печать фона. Изменить цвета он может, только если об этом попросил сам пользователь.

Без префикса свойство поддерживают все браузеры. Последними его добавили Chrome и Edge в версии 136 (апрель 2025), а до этого они понимали только `-webkit-print-color-adjust`. Если важно, чтобы цвета печатались и в более старых версиях Chrome, Edge и Safari, напишите обе строки:

```css
.chart {
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;
}
```

## Как понять

По умолчанию браузеры не печатают фон: в диалоге печати эта опция выключена. Так страница с тёмной темой не изведёт весь картридж. Но иногда фон несёт смысл: цветные плашки в диаграмме, отметки в календаре, логотип на цветной подложке.

Задайте `print-color-adjust: exact` только таким элементам, а остальные браузер напечатает как обычно. Если задать `exact` всей странице, принтер потратит чернила на фон, который читателю не нужен. Свойство [наследуется](/css/inheritance/), поэтому значение действует и на всех потомков элемента.

## Подсказки

💡 Свойство — только подсказка браузеру. Оно не управляет принтером: на чёрно-белом принтере или в режиме печати в оттенках серого фон с `exact` напечатается, но серым.

💡 Если у [`<html>`](/html/html/) нет своего фона, фон [`<body>`](/html/body/) браузер растягивает на всю страницу. Печать такого фона зависит от значения у `<html>`, а не у `<body>`.

💡 Чтобы напечатать фон страницы, задайте `exact` элементу `<html>`. Значение унаследуют все элементы. Фонам, которые печатать не нужно, верните `economy`:

```css
html {
  print-color-adjust: exact;
}

.sidebar {
  print-color-adjust: economy;
}
```
