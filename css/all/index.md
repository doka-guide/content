## Кратко

Свойство `all` сбрасывает значения всех CSS-свойств, кроме `direction` и `unicode-bidi`. [Кастомные свойства](/css/custom-properties/) оно тоже не трогает.

## Как пишется

У `all` шесть возможных значений. Все они — [глобальные ключевые слова](/css/global-keywords/) CSS:

- `initial` — сбрасывает все свойства элемента до значений по умолчанию, описанных в спецификации.
- `inherit` — элемент будет наследовать все стили родителя, даже те, которые обычно не наследуются.
- `unset` — элемент наследует все наследуемые стили родителя, а остальные сбрасывает до значений по умолчанию.
- `revert` — действие зависит от источника стилей: браузер, пользователь или сайт.
- `revert-layer` — откатывает стили к предыдущему каскадному слою.
- `revert-rule` — отбрасывает объявления текущего CSS-правила. Другие правила, в том числе из того же слоя, продолжают работать. Браузеры поддерживают его с сентября 2026 года. В более старых версиях браузеров такое объявление не сработает.

### `revert`

Действие значения `revert` зависит от источника стилей.

1. Браузерные стили: действие аналогично `unset`.
1. Пользовательские стили: откатываемся по каскаду к браузерным стилям (словно пользовательских для этого свойства не существует).
1. Авторские стили: откатываемся по каскаду к пользовательским стилям (словно авторских для этого свойства не существует).

### `revert-layer`

Значение `revert-layer` работает с [каскадными слоями](/css/layer/). Браузер отбрасывает объявления текущего слоя и берёт значения из предыдущих слоёв.

```css
@layer base, theme;

@layer base {
  p {
    font-family: "Roboto", sans-serif;
    font-size: 18px;
    line-height: 1.6;
    color: #FFFFFF;
  }
}

@layer theme {
  p {
    font-size: 21px;
    font-weight: 500;
    font-style: italic;
    color: #18191C;
  }

  .reverted p {
    all: revert-layer;
  }
}
```

Абзацы внутри `.reverted` получат стили из слоя `base`, словно слоя `theme` нет. Если свойство не задано ни в одном предыдущем слое, браузер откатывает его как при `revert`. В демке так ведут себя `font-weight` и `font-style` из слоя `theme`. В браузерных стилях у абзаца их нет, поэтому значения наследуются от родителя.

<iframe src="demos/revert-layer/" title="Пример с revert-layer" height="560"></iframe>

Стили вне `@layer` браузер собирает в неявный слой и ставит его после всех остальных. Поэтому `all: revert-layer` в стилях вне `@layer` откатывает элемент к слоям из `@layer`. Каждое свойство берёт значение из самого позднего слоя, где оно задано.

## Пример

Для начала создадим базовый блок с контентом.

```html
<p>Поговорим о многоножках:</p>
<p><!-- Тут текст про многоножек --></p>
```

```css
p {
  font-family: "Roboto", sans-serif;
  font-size: 18px;
  line-height: 1.6;
  color: #FFFFFF;
}
```

<iframe src="demos/basic/" title="Базовый вид" height="520"></iframe>

Сбросим стили абзаца с помощью `all: initial`:

```css
p {
  all: initial;
}
```

<iframe src="demos/initial/" title="Пример с initial" height="400"></iframe>

Все свойства сбросились до значений по умолчанию. Больше всего бросаются в глаза изменения [`font-family`](/css/font-family/), [`font-size`](/css/font-size/), [`display`](/css/display/).

## Подсказки

💡 Чтобы вернуть элементу браузерный вид, используйте `all: revert`. `initial` берёт значения по умолчанию из спецификации, а не из браузерных стилей. Например, у `display` значение по умолчанию — `inline`, поэтому абзацы в примере выше склеились в строку.

💡 Не сбрасывайте стили кнопок и ссылок через `all: unset` или `all: initial` без замены. Вместе с остальными стилями пропадёт браузерная обводка фокуса, и пользователи клавиатуры не увидят, на каком элементе сейчас фокус. `all: revert` обводку сохраняет. Если всё же сбрасываете, задайте свои стили для [`:focus-visible`](/css/focus-visible/).
