## Кратко

Псевдокласс `:read-only` выбирает элементы, которые пользователь не может редактировать. Чаще всего его используют для полей ввода с атрибутом [`readonly`](/html/readonly/). Данные в таком поле пользователь не может изменить или удалить. Но поле получает фокус, а текст в нём можно выделить и скопировать.

Обратный псевдокласс — `:read-write`. Он выбирает поля, в которые можно вводить текст, и редактируемые элементы с атрибутом [`contenteditable`](/html/global-attrs/#contenteditable) вместе с их потомками.

## Пример

Стилизуем текстовые поля только для чтения, чтобы они отличались от обычных:

```css
.field:read-only {
  border-style: dashed;
  background-color: transparent;
}
```

```html
<input class="field" type="text" value="DK-2026-0042" readonly>
<textarea class="field" readonly>улица Пушкина, дом 1</textarea>
<input class="field" type="text" placeholder="Напишите, если нужно">
```

## Как пишется

После селектора ставим двоеточие и пишем ключевое слово `read-only`, как в примере выше.

Псевдокласс выбирает не только поля с атрибутом `readonly`, но и:

- поля с атрибутом [`disabled`](/html/disabled/);
- поля, к которым `readonly` не относится: чекбоксы, радиокнопки, кнопки, ползунки `type="range"`, выпадающие списки [`<select>`](/html/select/);
- все обычные элементы, которые нельзя редактировать: абзацы, заголовки, блоки, в том числе с `contenteditable="false"`.

Поэтому `:read-only` без уточнения выберет почти всю страницу, а `input:read-only` — ещё и все чекбоксы с кнопками. Ограничивайте псевдокласс классом, как в примере выше.

Селектор `.field:read-only` выберет текстовые поля и с `readonly`, и с `disabled`. Если нужны только поля с `readonly`, выбирайте их по атрибуту:

```css
input[readonly],
textarea[readonly] {
  border-style: dashed;
}
```

Префикс `-moz-read-only` больше не нужен: Firefox поддерживает `:read-only` без префикса с версии 78.

## Как понять

Поле только для чтения показывает данные, которые пользователь должен видеть, но не должен менять: номер заказа, автоматически рассчитанную сумму, заполненный ранее адрес.

Поля с атрибутами `readonly` и `disabled` оба подходят под `:read-only`, но ведут себя по-разному:

- поле с `readonly` получает фокус, а его значение уйдёт на сервер вместе с формой;
- поле с `disabled` не получает фокус, а его значение не отправляется с формой.

Поэтому для отключённых полей есть свой псевдокласс [`:disabled`](/css/disabled-enabled/).

## Подсказки

💡 Не ставьте полям только для чтения [`cursor: not-allowed`](/css/cursor/). Такой курсор обещает, что с полем ничего нельзя сделать, хотя текст из него можно скопировать.

💡 Атрибут `readonly` не защищает данные. Значение поля можно изменить через DevTools, и оно уйдёт на сервер вместе с формой. Поэтому проверяйте или заново рассчитывайте такие значения на сервере.

💡 Не убирайте у полей только для чтения стили фокуса. Пользователь с клавиатуры попадает в такое поле так же, как в обычное, и должен видеть, где он сейчас.
