## Кратко

Свойство `overflow` определяет, что делать с содержимым блока, если оно не помещается в его размеры: показать снаружи или обрезать, с полосами прокрутки или без. Свойство работает у элементов с [`display`](/css/display/) `block`, `inline-block`, `flex`, `grid` и похожими.

## Пример

Если содержимое не помещается в блок, оно обрежется:

```css
.article {
  /* Задаём ограничения по размеру блока */
  width: 300px;
  height: 300px;
  overflow: hidden;
}
```

Переключите значения в демке и посмотрите, как меняется блок с текстом. `hidden` и `clip` выглядят одинаково: они отличаются прокруткой, а не внешним видом.

## Как пишется

```css
.gallery {
  overflow: auto;
}

.card {
  overflow: hidden;
}
```

## Как понять

В `overflow` можно задать два значения — для оси _x_ и оси _y_. Если указано одно значение, оно действует по обеим осям. То же самое можно сделать отдельными свойствами `overflow-x` и `overflow-y`.

```css
.carousel {
  /* По горизонтали прокрутка, по вертикали обрезаем */
  overflow: auto hidden;
}
```

Не все пары значений браузер оставляет как есть. Если по одной оси стоит `hidden`, `scroll` или `auto`, браузер поменяет значение по другой оси:

- `visible` станет `auto`: `overflow: visible hidden` превратится в `auto hidden`;
- `clip` станет `hidden`: `overflow: clip scroll` превратится в `hidden scroll`.

Второе правило спецификация уже отменила: `clip` по одной оси можно сочетать с прокруткой по другой. Chrome начал включать такое поведение с версии 156, остальные браузеры пока заменяют `clip` на `hidden`.

## Значения

- `visible` — содержимое отображается снаружи блока, если не помещается в него. Это значение по умолчанию.
- `hidden` — содержимое, выходящее за пределы блока, обрезается по внутреннему краю рамки, полос прокрутки нет. Пользователь прокрутить блок не может, но из JavaScript его прокрутить можно. Браузер тоже прокрутит блок сам, например, при переходе по ссылке-якорю или фокусе на элементе внутри.
- `clip` — похоже на `hidden`, но прокрутить блок нельзя вообще, даже из JavaScript. У блока нет своей области прокрутки, поэтому он не мешает работе [`position: sticky`](/css/position/) у вложенных элементов.
- `scroll` — содержимое обрезается так же, как при `hidden`, но его можно прокрутить. Браузер показывает полосы прокрутки, даже если всё помещается. Исключение — системы, где полосы прокрутки появляются поверх содержимого только во время прокрутки, например, в iOS, Android и обычно в macOS.
- `auto` — как `scroll`, но полосы прокрутки появляются, только когда содержимое не помещается.

Насколько далеко за границей блока с `clip` ещё видно содержимое, задаёт свойство `overflow-clip-margin`. Safari его не поддерживает, а Chrome учитывает, только если `clip` задан по обеим осям.

В старом коде можно встретить `overflow: overlay`. В Chrome и Safari это значение рисовало полосы прокрутки поверх содержимого. Теперь во всех браузерах оно работает как `auto`.

## Подсказки

💡 Чтобы блок можно было прокрутить, его содержимое должно быть выше самого блока. Для этого задайте блоку с `overflow` высоту через [`height`](/css/height/) или `max-height`.

💡 Во [флекс-раскладке](/css/flexbox-guide/) прокрутка часто не появляется из-за предка — флекс-элемента. По умолчанию он не сжимается меньше своего содержимого вдоль главной оси. Добавьте такому предку `min-height: 0` в колонке или `min-width: 0` в строке.

💡 Не меняйте `hidden` на `clip` механически. В отличие от `hidden`, `clip` не создаёт новый блочный контекст форматирования. Поэтому внешние отступы вложенных элементов могут схлопнуться с отступами самого блока.

💡 Блок с `clip` браузер не прокрутит к элементу в фокусе. Если ссылка или кнопка окажется за краем блока, пользователь клавиатуры её не увидит.

💡 Если задаёте блоку высоту `100%` или `100vh` и добавляете [`padding`](/css/padding/), включите [`box-sizing: border-box`](/css/box-sizing/). Без него внутренние отступы и рамка прибавятся к высоте. Блок станет выше родителя, и прокрутка появится у родителя или у страницы.

💡 Блок с прокруткой должен быть доступен с клавиатуры. Если внутри нет ссылок и кнопок, Chrome и Firefox сами дают блоку фокус, а Safari — нет. Добавьте такому блоку [`tabindex="0"`](/html/tabindex/), [`role="region"`](/a11y/role-region/) и подпись в [`aria-label`](/a11y/aria-label/).
