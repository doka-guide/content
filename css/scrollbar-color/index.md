## Кратко

`scrollbar-color` меняет цвета полосы прокрутки, или скроллбара: ползунка и дорожки, по которой он двигается.

## Пример

Изменим цвета ползунка и дорожки.

```css
html {
  scrollbar-color: #2E9AFF #F498AD;
}
```

<iframe title="Цветная полоса прокрутки" src="demos/basic/" height="400"></iframe>

В macOS и на телефонах полосы прокрутки обычно появляются поверх содержимого и только во время прокрутки. У таких полос цвет дорожки чаще всего не виден: браузер показывает только ползунок. Поэтому не делайте дизайн, который держится на цвете дорожки.

Чтобы увидеть оба цвета в macOS, включите в настройках системы показ полос прокрутки всегда.

## Как пишется

Свойство принимает два цвета: первый — для ползунка, второй — для дорожки. Подойдут любые [корректные значения](/css/color/#kak-pishetsya) цвета.

Один цвет указать нельзя, даже если ползунок и дорожка должны быть одного цвета. Браузер посчитает это синтаксической ошибкой.

Значение по умолчанию — `auto`: браузер сам выбирает цвета, например, с учётом [`color-scheme`](/css/color-scheme/).

Цвета можно задавать отдельно для каждого блока. Свойство красит и вертикальные, и горизонтальные полосы прокрутки.

<iframe title="Несколько полос прокрутки с разными цветами" src="demos/multiple/" height="400"></iframe>

У контейнера с жёлтой дорожкой две полосы прокрутки, вертикальная и горизонтальная, а у вложенного блока с фиолетовой — одна вертикальная. Дело в [`overflow`](/css/overflow/): контейнеру мы задали `overflow: scroll`, а вложенному блоку — `overflow-y: scroll`. У нижнего блока с коричневой дорожкой `overflow-x: scroll`, поэтому полоса прокрутки у него только горизонтальная.

## Подсказки

💡 Свойство наследуется. Если задать его для [`html`](/html/html/), цвета получат полосы прокрутки страницы и всех вложенных блоков, у которых не задан свой `scrollbar-color`.

💡 Подбирайте цвета с достаточным контрастом между ползунком и дорожкой. Если ползунок сливается с дорожкой, пользователю сложно понять, сколько ещё осталось прокрутить.

💡 В Chrome, Edge и Safari стили через псевдоэлементы [`::-webkit-scrollbar`](/css/scrollbar/) перестают работать, если у блока `scrollbar-color` или [`scrollbar-width`](/css/scrollbar-width/) не равны `auto`. Важно итоговое значение с учётом наследования.

Если задать `scrollbar-color` для `html`, `::-webkit-scrollbar` перестанет работать у всех блоков страницы. Чтобы вернуть эти стили отдельному блоку, задайте ему `scrollbar-color: auto`. У этого блока `scrollbar-width` тоже должно быть `auto`.
