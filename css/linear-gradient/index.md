## Кратко

Функция `linear-gradient()` рисует фон в виде плавного перехода между цветами вдоль прямой линии.

## Пример

```css
.element {
  background-image: linear-gradient(#6E4AFF, #49A16C);
}
```

## Как понять

В отличие от картинки, у градиента нет собственных размеров. Поэтому по умолчанию фоновый градиент занимает элемент целиком до внутреннего края рамки.

Эту область задаёт свойство [`background-origin`](/css/background-origin/). Размер градиента меняет свойство [`background-size`](/css/background-size/).

## Как пишется

Самый простой вид градиента — переход между двумя цветами:

```css
.element {
  background-image: linear-gradient(#2E9AFF, #F498AD);
}
```

### Количество цветов

Градиент может состоять из любого количества цветов. Укажите нужное количество значений через запятую внутри круглых скобок.

Цвета можно указать в любом формате. Подробнее о возможных значениях цветов в статье «[Цвета в вебе](/css/web-colors/)».

### Точки остановки цвета

После цвета через пробел можно указать начальную и конечную точки цвета в любых единицах длины или в процентах:

- в начальной точке заканчивается плавный переход из предыдущего цвета;
- в конечной точке начинается плавный переход в следующий цвет.

<iframe title="Линейный градиент с остановками цвета" src="demos/gradient-stops/" height="300"></iframe>

Если конечная точка предыдущего цвета и начальная точка следующего совпадают, то переход будет в виде чёткой линии.

```css
.element {
  background-image: linear-gradient(
    #F498AD 25%,
    #2E9AFF 25% 50%,
    #FFD829 75%
  );
}
```

По умолчанию градиент рисуется сверху вниз. Вот что происходит по высоте:

- от 0 до 25% — розовый `#F498AD`;
- на 25% конечная точка розового совпадает с начальной точкой голубого `#2E9AFF`, поэтому граница чёткая;
- от 25 до 50% — голубой;
- от 50 до 75% — плавный переход из голубого в жёлтый `#FFD829`;
- от 75% и до конца — жёлтый.

![Линейный градиент из розового, голубого и жёлтого цветов](images/gradient-stops.png)

### Направление градиента

Первым параметром можно передать угол в любых единицах (`deg`, `turn`, `rad`, `grad`), и тогда линия, вдоль которой строится градиент, повернётся на нужный угол:

```css
.element-1 {
  background-image: linear-gradient(-30deg, #2E9AFF, #F498AD);
}

.element-2 {
  background-image: linear-gradient(0.25turn, #2E9AFF, #FFD829);
}
```

<iframe title="Линейный градиент с поворотом" src="demos/gradient-rotate/" height="300"></iframe>

Направление градиента задают и ключевыми словами с приставкой `to`: `to left`, `to top`, `to right`, `to bottom` (по умолчанию). Им соответствуют углы:

- `to top` — `0deg`;
- `to bottom` — `180deg`;
- `to right` — `90deg`;
- `to left` — `270deg`.

Ключевые слова можно сочетать, чтобы направить градиент в нужный угол элемента: `to top left` будет рисовать градиент из правого нижнего в левый верхний угол.

### Цветовое пространство

Плавный переход между цветами браузер рассчитывает в каком-то цветовом пространстве — математической модели, которая описывает цвета числами. Подробнее о них можно прочитать в статье «Цвета в вебе».

Пространство по умолчанию зависит от того, как заданы цвета:

- `srgb` — если все цвета заданы привычными способами: HEX, названием, `rgb()`, `hsl()` или `hwb()`;
- `oklab` — если хотя бы один цвет задан другим способом, например через `oklch()`, `lab()` или [`color()`](/css/color-function/).

В `srgb` и `oklab` браузер ведёт цвет по прямой от одного цвета к другому. Если цвета лежат на противоположных сторонах цветового круга, как голубой и жёлтый, прямая проходит рядом с серым, и середина тускнеет. `oklab` выравнивает переход по яркости, но от серости не спасает.

В `oklch` браузер идёт по кругу оттенков, поэтому середина остаётся насыщенной. Середина иногда выходит насыщеннее, чем может показать обычный монитор. Тогда браузер немного её приглушит.

Пространство можно выбрать: напишите `in` и название пространства в первом параметре, до первой запятой. Если в градиенте есть направление, `in` можно поставить до или после него.

```css
.banner {
  background-image: linear-gradient(
    to right in oklch, #2E9AFF, #FFD829
  );
}
```

Для пространств с оттенком, вроде `oklch` и `hsl`, можно выбрать, по какой дуге цветового круга идти от цвета к цвету:

- `shorter hue` — по короткой дуге, значение по умолчанию;
- `longer hue` — по длинной дуге;
- `increasing hue` — по возрастанию оттенка;
- `decreasing hue` — по убыванию оттенка.

С `longer hue` градиент пройдёт через все цвета радуги, что лежат на длинной дуге. Дугу пишут после названия пространства: `in oklch longer hue`.

<iframe title="Цветовое пространство градиента" src="demos/gradient-interpolation/" height="370"></iframe>

Выбор цветового пространства поддерживают все браузеры: последним в июне 2024 года его добавил Firefox 127. Старые браузеры не поймут такой градиент и проигнорируют всё объявление. Для них напишите строкой выше запасное значение без `in`:

```css
.banner {
  background-image: linear-gradient(to right, #2E9AFF, #FFD829);
  background-image: linear-gradient(
    to right in oklch, #2E9AFF, #FFD829
  );
}
```

## Подсказки

💡 Плавно анимировать сам градиент через [`transition`](/css/transition/) пока не получится: браузеры переключают один градиент на другой скачком. Чтобы анимация была плавной:

1. Вынесите цвет в [пользовательское свойство](/css/custom-properties/).
1. Зарегистрируйте его через `@property` с типом `<color>`.
1. Задайте анимацию для этого свойства.

```css
@property --start {
  syntax: "<color>";
  inherits: false;
  initial-value: #2E9AFF;
}

.button {
  background-image: linear-gradient(
    var(--start, #2E9AFF), #F498AD
  );
  transition: --start 0.3s;
}

.button:hover {
  --start: #FFD829;
}
```

`@property` работает во всех браузерах с июля 2024 года. Браузер постарше не зарегистрирует `--start`, и у свойства не будет начального значения. Тогда градиент возьмёт запасной цвет из [`var()`](/css/var/), а без него пропадёт. Цвет при наведении в таком браузере сменится скачком.
