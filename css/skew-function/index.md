## Кратко

`skew()` — функция для CSS-трансформаций ([`transform`](/css/transform/)), которая наклоняет элемент вдоль осей _x_ и _y_: прямоугольник превращается в параллелограмм. Так делают кнопки в форме параллелограмма, ленточки и диагональные разделители между секциями. Для наклона по одной оси есть функции `skewX()` и `skewY()`, и спецификация рекомендует именно их.

<aside>

📖 О других функциях CSS-трансформаций можно узнать из статьи «[Функции CSS-трансформации](/css/transform-function/)».

</aside>

## Пример

Наклоняем элемент на 20 градусов вдоль оси _x_:

```css
.box {
  transform: skew(20deg);
}
```

## Как пишется

Функция принимает один или два угла в [единицах измерения углов](/css/numeric-types/#edinicy-izmereniya-uglov), чаще всего в градусах `deg`. Ноль можно писать без единиц.

- Первый угол наклоняет элемент вдоль оси _x_: верхняя и нижняя стороны остаются горизонтальными, а боковые наклоняются.
- Второй угол необязательный и наклоняет элемент вдоль оси _y_: боковые стороны остаются вертикальными, а верхняя и нижняя наклоняются. Если его нет, наклона по _y_ не будет.

```css
/* Наклон по x на 20 градусов */
.skew-x {
  transform: skew(20deg);
}

/* Наклон по y на 10 градусов */
.skew-y {
  transform: skew(0, 10deg);
}

/* Наклон сразу по обеим осям */
.skew-both {
  transform: skew(20deg, 10deg);
}
```

### `skewX()` и `skewY()`

Функции `skewX()` и `skewY()` наклоняют элемент вдоль одной оси. Спецификация [CSS Transforms](https://drafts.csswg.org/css-transforms/#funcdef-transform-skew) рекомендует их для нового кода, а `skew()` оставляет ради обратной совместимости. Браузеры поддерживают все три функции, так что старый код продолжит работать.

```css
/* То же, что skew(20deg) */
.skew-x {
  transform: skewX(20deg);
}

/* То же, что skew(0, 20deg) */
.skew-y {
  transform: skewY(20deg);
}
```

Запись `skew(20deg, 30deg)` не равна цепочке `skewX(20deg) skewY(30deg)`. В `skew()` оба угла применяются одновременно. В цепочке каждая следующая функция работает в системе координат, которую уже наклонила предыдущая. Поэтому `skewX(20deg) skewY(30deg)` ещё и растягивает элемент по горизонтали, а `skewY(30deg) skewX(20deg)` — по вертикали:

## Как понять

`skewX()` сдвигает каждую точку элемента по горизонтали. Чем дальше точка от центра по вертикали, тем сильнее сдвиг. Сдвиг равен этому расстоянию, умноженному на тангенс угла. Например, у 45° тангенс равен 1, и при `skewX(45deg)` точка на 40 пикселей выше центра сдвигается на 40 пикселей влево. `skewY()` так же сдвигает точки по вертикали, а `skew()` с двумя углами — сразу по обеим осям.

По умолчанию точка трансформации — центр элемента, её меняет свойство [`transform-origin`](/css/transform-origin/).

Прямые линии остаются прямыми, а параллельные — параллельными. При наклоне по оси _x_ высота элемента не меняется, а на экране он становится шире.

Ось _y_ в CSS направлена вниз. Поэтому при положительном угле `skewX()` верхняя сторона уходит влево, а нижняя — вправо. Положительный угол в `skewY()` поднимает левую сторону и опускает правую.

Как и другие трансформации, `skew()` не влияет на раскладку страницы: соседние элементы остаются на своих местах. Функцию можно сочетать с другими функциями трансформации, например с `rotate()` или `translate()`.

## Подсказки

💡 Наклон действует на весь элемент вместе с содержимым, например текстом. Чтобы текст остался прямым, задайте вложенному элементу обратный наклон: `skewX(-20deg)` для родителя со `skewX(20deg)`. Вложенный элемент должен быть блочным или строчно-блочным: к строчным элементам вроде [`<span>`](/html/span/) трансформации не применяются.

💡 Не берите углы близко к 90°. Тангенс такого угла огромный, и элемент вытягивается в длинную тонкую полосу. Уже при 89° квадрат 80 × 80 пикселей становится шире 4000 пикселей, и у страницы появляется горизонтальная прокрутка. При 90° полоса становится такой тонкой, что её не видно.

💡 `skew(45deg, 45deg)` сплющивает элемент в линию нулевой толщины, и его не видно. Так бывает всегда, когда произведение тангенсов двух углов равно 1. Если произведение больше 1, элемент отражается зеркально. С цепочкой `skewX()` и `skewY()` такого не бывает.
